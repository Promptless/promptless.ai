## Overview

Add Promptless to ChatGPT as a custom MCP server to work on your docs from a ChatGPT conversation. Ask ChatGPT to start a documentation task, follow it to a docs pull request, review suggestions, or edit the docs on an open suggestion. Each member of a Promptless organization connects their own account. On a ChatGPT Business, Enterprise, or Edu workspace, an admin publishes the plugin for the workspace first. When you finish, Promptless is connected and you have run a test prompt.

For Claude, see [Use Promptless from Claude](/docs/for-docs/work-the-queue/claude). To check the server, sign-in, and tools before you approve the plugin, see the [Claude and ChatGPT connector reference](/docs/for-docs/reference/claude-and-chatgpt-connector).

## Before you connect

- A Promptless organization that has [finished setting up Promptless](https://app.gopromptless.ai/configuration). Any active member of the organization can connect.
- Read [what a connection can access](/docs/for-docs/reference/claude-and-chatgpt-connector#data-access). The connection acts with your Promptless access in the organization that you select. It can start documentation tasks, and change suggestions and the files on their branches.
- A ChatGPT plan that supports custom MCP servers. The plan controls which Promptless tools run:

## Add Promptless to ChatGPT

ChatGPT adds custom MCP servers as plugins. Use ChatGPT on the web for these steps. {/* TODO(verify): OpenAI documents custom MCP servers for ChatGPT on the web. Confirm whether a plugin added on the web also runs in the ChatGPT desktop app. */}

<Steps>
  1. Go to [chatgpt.com/plugins](https://chatgpt.com/plugins).

  2. Select **+**, and then select **Add custom MCP server**.

  3. In the name field, enter `Promptless`.

  4. Optional. In the description field, enter a short description, such as `Start and track Promptless documentation tasks, and search, read, and edit our docs.` ChatGPT uses this text to decide when to call Promptless.

  5. Under **Connection**, enter `https://api.gopromptless.ai/mcp/with-direct-edits`.

  6. For authentication, select **OAuth**. ChatGPT registers itself with Promptless automatically.

  7. Read the risk warning, and then select **I understand and want to continue**.

  8. Select **Create as a plugin**. A Promptless tab opens. {/* TODO(verify): Confirm in a live ChatGPT account that the OAuth tab opens at this step. Also confirm whether the plugin must be installed before use. OpenAI's developer guide says "Install it before using it in a conversation." */}

  9. Approve the connection. See [Approve the connection](#approve-the-connection).
</Steps>

ChatGPT shows the Promptless tools that it found. Then Promptless is ready to use.

Use the URL `https://api.gopromptless.ai/mcp/with-direct-edits`. It adds the tools that search, read, and edit your documentation, which a chat app needs because it has no local copy of your repository.

## Share Promptless with your workspace

On a Business, Enterprise, or Edu workspace, only admins and owners publish a plugin for the workspace. After an admin publishes Promptless, each member connects their own Promptless account. On Enterprise and Edu, an admin can let selected members add custom MCP servers with the **Create plugins with MCPs** permission. For workspace controls, see the OpenAI [custom MCP guide](https://help.openai.com/en/articles/12584461-creating-custom-mcp-apps-in-chatgpt).

## Approve the connection

When you create the plugin or connect your account, a Promptless tab opens. On this page, you approve the connection. Promptless uses OAuth, so ChatGPT never gets your Promptless password.

<Steps>
  1. If the page asks you to sign in, sign in with your Promptless account.

  2. Find the **Returns to** row. For ChatGPT, the address is `chatgpt.com`.

  3. If the address is different, select **Cancel**. The app sets its own name, and Promptless does not verify it, so check the address, not the name.

  4. In the organization picker, select the Promptless organization to connect. The picker selects your active organization by default. The page also shows your role in the organization.

  5. Select **Authorize as \{your email}**.
</Steps>

The tab returns you to ChatGPT, and Promptless shows as connected. You can close the tab.

If you are not a member of a Promptless organization, the approval page asks for an organization name. The button reads **Create organization and authorize as \{your email}**. When you select it, Promptless creates the organization. Before you start documentation tasks, [finish setting up Promptless](https://app.gopromptless.ai/configuration).

## Use Promptless in a conversation

In the message box, enter `@` and select Promptless. The selection applies only to the message that you send. For a follow-up message that needs Promptless, select Promptless again.

Before a tool that changes data runs, ChatGPT asks you to confirm it. Read the action, and then allow or deny it. The [MCP tools reference](/docs/for-docs/reference/mcp-tools) shows which tools change data. For permission settings, see the OpenAI guide to [managing app permissions](https://help.openai.com/en/articles/20001495-managing-app-permissions-in-chatgpt).

## Test the connection

Start a new conversation, and select Promptless with `@` in each message. Then enter these prompts:

| Prompt                                     | Tool                   | Expected result                                                                                                               |
| ------------------------------------------ | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `List my Promptless doc collections.`      | `list_doc_collections` | The doc collections of the organization, by name. To see setup steps that remain, enter `What is my Promptless setup status?` |
| `Show my recent Promptless tasks.`         | `list_recent_tasks`    | Recent tasks, newest first, including tasks from Slack, GitHub, and the dashboard. A new organization might have no tasks.    |
| `Search my Promptless docs for "install".` | `search_documentation` | Lines that contain "install", with their file paths.                                                                          |

If the first two prompts give results, the connection works.

To see the full flow, run a real task. This step is optional and starts real work in your organization:

```text
@Promptless fix any typos on the quickstart page in my docs collection, and follow the task until it finishes.
```

ChatGPT asks you to confirm `submit_documentation_task`. Then ChatGPT follows the task with `wait_for_task_update` for some minutes and shows messages from Promptless. The final result is a suggestion with a docs pull request link, or a statement that no change is necessary. To remove the result, enter `@Promptless close that suggestion.`

## Reconnect or disconnect

A connection lasts 90 days from approval. During this time, ChatGPT refreshes its access automatically. After 90 days, ChatGPT asks you to connect again.

- To connect again, go to [chatgpt.com/plugins](https://chatgpt.com/plugins), select **Promptless**, and connect your account.
- To disconnect, go to [chatgpt.com/plugins](https://chatgpt.com/plugins), select **Promptless**, and remove it from its menu. A workspace admin can turn off the plugin for all members in the workspace settings. {/* TODO(verify): Confirm the ChatGPT menu labels for reconnecting and removing a custom MCP plugin in the Plugins experience. */}

Each member disconnects their own connection in ChatGPT.

## Troubleshooting

- **The approval page says that the request is no longer valid**: The request expired after 30 minutes. Or you opened a request that you already approved or canceled. Connect the plugin again.
- **The approval page says that the request has already been answered**: You selected **Authorize** or **Cancel** a second time, for example in a second tab. If ChatGPT still waits for approval, connect the plugin again.
- **You canceled on the approval page**: ChatGPT shows that the connection was declined. To try again, connect the plugin again.
- **The organization is not in the picker**: You are not an active member of the organization. Ask an admin of the Promptless organization to invite you.
- **A prompt says that a documentation tool does not exist**: The plugin uses `https://api.gopromptless.ai/mcp`, which has no tools to search, read, or edit documentation. Remove the plugin. Then add it again with `https://api.gopromptless.ai/mcp/with-direct-edits`.
- **Promptless tools do not run in a conversation**: Select Promptless with `@` in the message. On a plan limited to read actions, tools that change data do not run.
- **You connected the wrong organization**: Disconnect Promptless. Connect again, and select the correct organization on the approval page.

For errors that Promptless tools return after you connect, see [Tool errors](/docs/for-docs/reference/mcp-tools#tool-errors) in the MCP tools reference. To report a problem from the conversation, ask ChatGPT to message Promptless support, which uses the [`message_promptless_support`](/docs/for-docs/reference/mcp-tools#message_promptless_support) tool. For other problems, send an email to [help@gopromptless.ai](mailto\:help@gopromptless.ai).
