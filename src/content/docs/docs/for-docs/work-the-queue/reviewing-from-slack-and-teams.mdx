## Overview

Start documentation work from the Slack or Microsoft Teams conversation where a change comes up, and refine the suggestion without leaving the thread. Promptless reads the thread, including attached images and files, drafts the documentation update, and replies with the suggestion for you to review.

Start Promptless in one of these ways:

| Method                    | When to use it                                             | Section                                                             |
| ------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------- |
| Message action            | You don't want to interrupt the conversation.              | [Use a message action](#use-a-message-action)                       |
| Channel mention           | You want to give instructions in the thread.               | [Mention Promptless in a channel](#mention-promptless-in-a-channel) |
| Direct message            | The request is private, or you have detailed instructions. | [Send a direct message](#send-a-direct-message)                     |
| Passive channel listening | A channel's discussions often reveal documentation needs.  | [Passive channel listening](#passive-channel-listening)             |

The sections below describe Slack. For the Teams equivalents, see [Microsoft Teams](#microsoft-teams).

## Before you start

- For Slack, the Promptless Slack app, installed in your workspace. See [Connect Slack](/docs/for-docs/connect/triggers/slack-messages#connect-slack).
- For Microsoft Teams, the Promptless Teams app, installed and linked to your Promptless organization. See [Connect Microsoft Teams](#connect-microsoft-teams).

## Request documentation in Slack

### Use a message action

<Steps>
  1. On any Slack message, open the message actions menu (⋯).

     <figure>
       <img src="https://promptless-customer-doc-assets.s3.amazonaws.com/docs-images/org_2lvkgU9erOFxYhtEVVC0ymPrPdF/1756962237-slack-context-menu-promptless-integrations.png" alt="Slack context menu with Promptless options including Update Docs, Create task in Notion, and Create an Issue" style={{maxWidth: '250px'}} />

       <figcaption>Slack message actions menu showing Promptless integrations</figcaption>
     </figure>

  2. Select **Update Docs**. If you don't see it, select **More message shortcuts** and search for Promptless.
</Steps>

Promptless analyzes the full thread, drafts the documentation updates, and sends you a direct message when it's done.

### Mention Promptless in a channel

<Steps>
  1. If this is the first time you're tagging Promptless in the channel, add the Promptless app to the channel.

  2. In a new message or a thread reply, tag @Promptless with instructions for the docs update. You can include internal and external links, Slack links, and images.
</Steps>

Promptless analyzes the whole thread to understand the discussion. Point it to specific pages, or let it infer them from the context. It replies in the thread when it's done drafting, and you can [refine the suggestion in the same thread](#thread-auto-reply).

For example:

```txt wordWrap
@Promptless please also add a troubleshooting section covering the error cases we discussed earlier in this thread
```

```txt wordWrap
@Promptless make sure to mention that this feature is only available in the Enterprise plan
```

```txt wordWrap
@Promptless create a mermaid chart for the system architecture discussed in this thread
```

### Send a direct message

<Steps>
  1. In Slack, open the Promptless app from the **Apps** section.

  2. Describe your request, or paste the content you want turned into documentation. You can include internal and external links, Slack links, and images. You don't need to tag Promptless.
</Steps>

Promptless sends the documentation updates to you in a direct message.

## Add images, files, and screenshots

### Attach images and files

Attach screenshots, diagrams, design mockups, API responses, or configuration files in the thread where you tag @Promptless or use **Update Docs**. Promptless reviews all text and attached files in the thread. When an image or file is relevant to the documentation, Promptless adds it to the suggestion.

For example:

```txt wordWrap
@Promptless please document this new export feature. I've attached a screenshot showing the new export dialog.
```

```txt wordWrap
@Promptless update the technical architecture page with this new system diagram (attached)
```

```txt wordWrap
@Promptless we need to add troubleshooting docs for this error. See the screenshot above for the exact error message users are seeing.
```

```txt wordWrap
@Promptless here's the design spec for the new onboarding flow (PDF attached). Please create documentation that matches this flow.
```

For how Promptless processes and stores images, see the [Slack integration](/docs/for-docs/reference/integrations/slack).

### Request screenshot captures

If your organization has screenshot capture set up, ask Promptless to capture fresh screenshots from your staging or production environment. Promptless navigates to your web application, captures the UI, and adds the screenshot to the documentation.

For example:

```txt wordWrap
@Promptless capture a screenshot of the user settings page from staging and add it to the account management docs
```

```txt wordWrap
@Promptless the dashboard screenshot in our getting started guide is outdated. Can you capture a fresh one from production?
```

```txt wordWrap
@Promptless we need screenshots of the new onboarding flow. Please capture the welcome screen, the team setup page, and the final confirmation from staging.
```

<Aside type="note">
  Screenshot capture needs the feature enabled for your organization and your environment configured. See [Screenshots](/docs/for-docs/get-the-most-out/screenshots), or contact your Promptless admin or [help@gopromptless.ai](mailto\:help@gopromptless.ai).
</Aside>

## Passive channel listening

With passive listening, Promptless monitors the Slack channels you select and creates documentation suggestions from their messages, with no mention or message action needed. Use it for documentation-focused or support channels, where discussions often reveal documentation needs. It's opt-in: Promptless monitors only the channels you list, and you can add or remove channels at any time.

To turn it on, add a `slack_listen` trigger on the [Configuration page](https://app.gopromptless.ai/configuration):

```yaml
triggers:
  support-channels:
    trigger_type: slack_listen
    match:
      - channels:
          - customer-support
          - docs-feedback
```

Channel names don't need the `#` prefix. For the full setup, see [Set up passive channel listening](/docs/for-docs/connect/triggers/slack-messages#set-up-passive-channel-listening).

When new messages arrive in a thread Promptless already processed, Promptless updates its existing suggestion for that thread. You see one suggestion that changes as the thread grows, without a separate suggestion for each message. To have Promptless act on a monitored thread right away, @mention it there. For choosing channels and tuning what Promptless documents, see [Get the most out of passive channel listening](/docs/for-docs/get-the-most-out/passive-channel-listening).

## Thread auto-reply

After a message action, mention, direct message, or passive listening triggers Promptless in a Slack thread, it keeps reading new replies there. You don't need to tag `@Promptless` again to refine the suggestion, add context, or share images and files.

Promptless decides whether each reply is actionable, so not every reply produces a documentation update. To have Promptless ignore a message, start it with `aside` or `/aside`:

```txt wordWrap
aside @InlinePizza are these the ones your thing found or were there more?
```

### Configure thread replies

The thread reply trigger mode applies to your whole organization. To change it, open **Settings**, select **Organization**, and under **Slack Thread Reply Trigger Mode**, choose a mode:

- **Listen to all replies in participating threads (opt out with aside)** (default): Promptless processes every reply in threads where it has posted or been mentioned.
- **Require @promptless**: Promptless processes only replies that mention it.

For details, see [Change the thread reply trigger mode](/docs/for-docs/connect/triggers/slack-messages#change-the-thread-reply-trigger-mode).

## Read citations in research replies

Some research questions need Promptless to fetch external URLs, such as documentation sites, articles, or video transcripts. Its reply then cites each fact with an inline link to its source. The linked phrase is the specific claim or number, not the whole sentence.

For example, if you ask about API rate limits and Promptless fetches your docs and source code, the reply might look like this:

> The hard rate limit on `/v1/embed` is **60 requests per minute per API key**, enforced by the gateway's `rate_limiter.py` config.

Each bolded term links to its source. The rate limit links to your API reference, and the file name links to the repository.

If a fetch fails, Promptless says so and still links the URL it tried:

> **Live status:** unverified. Your status page returned 503 when I checked, so I can't confirm whether you're currently throttled.

Only sources that shaped the answer appear as citations.

## Microsoft Teams

<Aside type="note">
  The Microsoft Teams integration is in beta. Contact [help@gopromptless.ai](mailto\:help@gopromptless.ai) to enable it for your organization.
</Aside>

Promptless works the same way in Microsoft Teams as in Slack. You start it from a conversation, and it drafts documentation updates for you to review.

<MicrosoftTeamsConnect />

### Use Promptless in Microsoft Teams

Start Promptless from Teams in any of these ways:

- **Use a message action.** Open the menu on any Teams message and select **Update docs with Promptless**. Optionally, add instructions, such as "Focus on the error handling steps." Teams confirms the request, and the suggestion typically appears within a few minutes.
- **Tag @Promptless in a channel.** Mention @Promptless in a Teams channel with your instructions. Promptless analyzes the conversation and drafts relevant updates.
- **Send a direct message.** Message @Promptless directly for private documentation requests.
- **Listen to channels passively.** Add an `msteams_listen` trigger to monitor selected channels and draft suggestions without a mention. Like Slack listening, it's opt-in and covers only the channels you select. See [Passive channel listening](/docs/for-docs/get-the-most-out/passive-channel-listening).

Once Teams is connected, @Promptless mentions work with no further configuration. Thread replies work the same way as in Slack. See [Thread auto-reply](#thread-auto-reply).

### Act from the suggestion card

When Promptless creates a suggestion from Teams, it replies in the thread with a suggestion card. The card shows the title, description, status, creation date, branch, and affected files. Use its buttons to act without leaving Teams:

- **Publish**: Merges the docs PR and publishes the changes. The card updates to show the result.
- **Create PR**: Opens a docs pull request. The card refreshes to show the new PR link.
- **View PR**: Opens the docs PR in your browser.
- **Review in Promptless**: Opens the suggestion in the Promptless dashboard.

If your organization [turns off suggestion detail cards](/docs/for-docs/tune/notifications#turn-off-suggestion-detail-cards), the reply has no card or buttons. Act on the suggestion from the Promptless dashboard.

Publishing behavior and notifications follow your [policies configuration](/docs/for-docs/reference/configuration-reference#policies).
