The Promptless MCP server connects your coding agent, such as Claude Code, Cursor, Codex, or VS Code, to Promptless. When you finish a code change, ask for the matching docs update in the same conversation. For example: "Update the docs for the retry setting I just added." Promptless drafts the edit in your documentation repository and opens a docs pull request. Your agent reports the outcome and the pull request link back to you. You don't need to open the docs repository, the dashboard, or Slack.

This page covers what you can do over MCP and how to connect. For each tool's arguments, results, and errors, see the [MCP reference](/docs/for-docs/connect/triggers/mcp). To connect the Claude.ai or ChatGPT web app, see [Use Promptless from Claude.ai or ChatGPT](/docs/for-docs/work-the-queue/claude-and-chatgpt).

[MCP](https://modelcontextprotocol.io) (Model Context Protocol) is an open protocol that AI clients use to connect to external tools. Any client with an MCP servers setting can connect to Promptless. You sign in once in the browser, with no API key and no `promptless.yaml` entry to set up.

## What you can ask for

Ask in plain language. Your agent picks the Promptless tool that matches the request.

| You ask your agent to                                                                                          | Promptless                                                                                                                                                                    |
| -------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| "Document the new `--dry-run` flag in the CLI reference."                                                      | Starts a documentation task, drafts the change, and opens a docs pull request. Your agent follows the task in the conversation and reports the outcome and pull request link. |
| "Tell Promptless to also cover the error responses."                                                           | Adds the instruction to the task that's still running.                                                                                                                        |
| "Revise suggestion `<id>` to also cover single sign-on."                                                       | Updates that suggestion and its existing docs pull request.                                                                                                                   |
| "Search open suggestions for webhook retries."                                                                 | Lists matching suggestions, so you can check whether a change is already covered before you ask for it.                                                                       |
| "Assign suggestion `<id>` to @alex and open its docs PR." or "Close suggestion `<id>`, we won't document this." | Updates the suggestion's labels, assignees, or title, opens its pull request, or closes it.                                                                                   |
| "What's the status of task `<id>`?" or "What are my recent Promptless tasks?"                                  | Reports the status of any task in your organization, including tasks started from Slack, a GitHub pull request, or the dashboard.                                             |

When a task needs more information, Promptless asks one clarifying question in the conversation. Answer it there, and Promptless continues the work.

Each tool that queues or changes work asks you to approve it before it runs. Your agent can auto-approve the read-only tools, such as status checks and searches.

## Ask for docs edits while you code

Your coding agent already knows what you changed, so it can write a specific request for Promptless. Promptless takes the request from there:

1. Your agent starts a task with your request. Name the change and, if you know it, the page or collection it belongs in. Your agent can include links to a spec, design file, or screenshot.
2. Promptless routes the task across your doc collections, applies your [relevance filtering](/docs/for-docs/tune/noise-and-relevance-filtering), and drafts the change in the [style and structure of your existing docs](/docs/for-docs/connect/doc-locations/how-promptless-learns-your-docs).
3. Promptless opens a docs pull request for review. A task usually takes several minutes, and your agent waits for it in the same conversation.
4. Your agent reports the outcome. If you want changes, ask for a revision, and Promptless updates the same pull request.

Your agent can also stop following a task at any time. The task keeps running, and you can check it later by its ID.

## Choose a server URL

Promptless has two server URLs. Each is a separate connection that you authorize on its own.

| Server URL                                          | Use it when                                                                                                                                                                                                         |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `https://api.gopromptless.ai/mcp`                   | You want Promptless to draft the docs changes. Use this URL in your editor day to day.                                                                                                                             |
| `https://api.gopromptless.ai/mcp/with-direct-edits` | You want your agent to read, search, and edit doc files itself, on an open suggestion's branch. Chat apps such as Claude.ai and ChatGPT need this URL. The extra tools use more of your agent's context window. |

With the direct-edit URL, name the edit and the suggestion to put it on. For example: "Find the pages that say webhook retries default to 3. Change them to 5 on the open webhook retries suggestion, show me the diff, and open the PR." Each edit is a commit on the suggestion's branch, attributed to you and your client. For the content tools, see [Read and edit documentation directly](/docs/for-docs/connect/triggers/mcp#read-and-edit-documentation-directly).

## Connect your editor

Before you start, your organization must have [finished setting up Promptless](https://app.gopromptless.ai/configuration).

Add the server in your editor with the command for that editor:

| Editor      | Add the server                                                                                                                                                        |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude Code | `claude mcp add --transport http promptless https://api.gopromptless.ai/mcp`, then run `/mcp` and pick **promptless**.                                                |
| Cursor      | Add `{"mcpServers": {"promptless": {"url": "https://api.gopromptless.ai/mcp"}}}` to `mcp.json`, then select **Needs login**.                                          |
| Codex CLI   | `codex mcp add promptless --url https://api.gopromptless.ai/mcp`, then run `codex mcp login promptless`.                                                              |
| VS Code     | `code --add-mcp "{\"name\":\"promptless\",\"type\":\"http\",\"url\":\"https://api.gopromptless.ai/mcp\"}"`, then run **MCP: List Servers** and start **promptless**. |

Your editor opens a browser tab to the Promptless consent page. Choose your organization, check that the **Returns to** row matches the editor you're connecting, and select **Authorize as \{your email}**.

For the full steps for each editor, including the Cursor deep link and the Claude custom connector, see [Connect the server](/docs/for-docs/connect/triggers/mcp#connect-the-server). The same command also appears in the dashboard under **Settings**, in the **Editor connection (MCP)** section.

To check the connection, ask your agent: "List my Promptless doc collections." A list of your collections means the connection works.

<Aside type="note">
  An approved connection acts with your access. Any active member of your organization can connect, and the connection can revise, update, or close any suggestion in the organization. For the full list of what a connection can do, see [Authorize in the browser](/docs/for-docs/connect/triggers/mcp#authorize-in-the-browser).
</Aside>

## Find your MCP tasks in the dashboard

On the [Triggers page](https://app.gopromptless.ai/triggers), a task started over MCP shows an **MCP Task** pill and the name of the client that submitted it. When the suggestion is ready for review, Promptless can send you a Slack direct message. See [Direct messages to MCP submitters](/docs/for-docs/tune/notifications#direct-messages-to-mcp-submitters).

For errors and connection problems, see [Troubleshooting](/docs/for-docs/connect/triggers/mcp#troubleshooting) in the MCP reference.
