Connect Promptless to Claude or ChatGPT to do documentation work from a conversation. After you connect, you can:

- Start a documentation task and follow it to a docs pull request.
- Check the status of recent tasks.
- Search and read the documentation of your organization.
- Review, revise, edit, or close a suggested documentation change.

Choose your chat app to set it up. If you use Claude Code, Cursor, or another editor, see [MCP triggers](/docs/for-docs/connect/triggers/mcp) instead.
