Connect Promptless to Claude or ChatGPT to do documentation work from a conversation. Ask Promptless to update your docs, and follow the task to a docs pull request. You can also check recent tasks, search and read your docs, and review, edit, or close suggestions.

This page is for members of a Promptless organization who use Claude, on the web or in the desktop app, or ChatGPT. On a Claude Team or Enterprise plan, or on a ChatGPT workspace, an Owner or admin adds Promptless first. When you finish, Promptless is connected and has answered a test prompt.

If you use Claude Code, Cursor, or another editor, see [MCP triggers](/docs/for-docs/connect/triggers/mcp) instead.

## Before you start

- **A Promptless account.** Any active member of a Promptless organization can connect. If you don't have an organization yet, you can create one when you [approve the connection](#approve-the-connection).
- **Claude** on any plan. On a Team or Enterprise plan, an Owner adds Promptless for the organization first. {/* TODO(verify): directory connectors are available on the Claude Free plan. Check claude.com/docs/connectors/getting-started. */}
- **ChatGPT** on a Business, Enterprise, or Edu workspace, which runs all Promptless tools. Other plans run fewer tools or none. See [Connect ChatGPT](#connect-chatgpt).

## What the connection can access

A connection acts as the person who approved it, in the one Promptless organization that they selected. There are no narrower permissions to select. A connection can:

- Read all documentation tasks, doc collections, and suggestions in the organization. This includes work that started from Slack, GitHub, the dashboard, or the API.
- Start documentation tasks, which can open docs pull requests.
- Revise, retitle, label, assign, and close any suggestion in the organization, not only yours.
- Search and read your documentation, and edit files on the branch of an open suggestion. It does not write to the default branch of your documentation repository.
- Create links that connect an integration, such as GitHub, to the organization.
- Send a report to the Promptless support team.

Claude and ChatGPT ask you before a tool that changes data runs, unless you change the tool permissions. Promptless checks your organization membership on each call. If you are no longer an active member, the connection stops working.

For more about access, see [Authorize in the browser](/docs/for-docs/connect/triggers/mcp#authorize-in-the-browser). For data handling, see the [Promptless privacy policy](/docs/for-docs/security/privacy-policy).

## Connect Claude

These steps work in Claude.ai and in the Claude desktop app. After you connect in one, Promptless is available in the other, and in the Claude mobile app.

Promptless is in the Claude connectors directory. {/* TODO(verify): the directory listing uses https://api.gopromptless.ai/mcp/with-direct-edits. Check the listing in claude.ai/directory/manage. */}

### Individual plans

Free, Pro, and Max are individual plans.

<Steps>
  1. Go to [**Customize** > **Connectors**](https://claude.ai/customize/connectors). In the desktop app, select **Customize** in the sidebar, and then select **Connectors**.

  2. Select **Discover**, and search for `Promptless`.

  3. Select **Promptless**. The Promptless connector page opens.

  4. Select **Connect to Claude**. The Promptless approval page opens. In Claude.ai, it opens in the same tab. In the desktop app, it opens in your browser.

  5. Approve the connection. See [Approve the connection](#approve-the-connection).
</Steps>

Promptless shows under **Your connectors** with the status **Connected**.

### Organization plans

Team and Enterprise are organization plans. An Owner adds Promptless for the organization one time. Then each member connects their own Promptless account. So each connection has the Promptless access of that member only.

If you are an Owner:

<Steps>
  1. Go to **Customize** > **Connectors**, select **Discover**, and select **Promptless**.

  2. Select **Connect for your team**. Promptless becomes available to all members of the organization.

  3. To connect your own account, select **Connect to Claude**, and then [approve the connection](#approve-the-connection).
</Steps>

If you are a member:

<Steps>
  1. Go to **Customize** > **Connectors**, select **Discover**, and select **Promptless**.

  2. Select **Connect to Claude**.

  3. Approve the connection. See [Approve the connection](#approve-the-connection).
</Steps>

If you see **Request** instead of **Connect to Claude**, an Owner has not added Promptless yet. On a Team plan, select **Request** to send a request to the Owners of your organization.

An Owner can block specific tools for all members in **Organization settings** > **Connectors**. {/* TODO(verify): Owner-level tool blocking in Organization settings > Connectors (carried from the 2026-09-29 version of this page). */}

For more about directory connectors, see the Anthropic guide [Get started with connectors](https://claude.com/docs/connectors/getting-started).

### If Promptless isn't in your directory

You can add Promptless as a custom connector instead. Use the steps in the Anthropic guide [Add a connector by URL](https://claude.com/docs/connectors/custom/add-unlisted#add-a-connector-by-url), with these values:

- **Name**: `Promptless`
- **Remote MCP server URL**: `https://api.gopromptless.ai/mcp/with-direct-edits`
- **OAuth client**: **Register automatically**, if the dialog shows this setting. Claude registers itself with Promptless, so it does not need a client ID or secret.

### Turn on Promptless in a conversation

<Steps>
  1. In the message box, select **+**.

  2. Select **Connectors**.

  3. Turn on **Promptless**.
</Steps>

Before Claude runs a Promptless tool, it can ask for your approval. Select **Allow once**, or select **Always allow** to stop the prompts for that tool.

To change the permission of a tool later, go to **Customize** > **Connectors** and select **Promptless**. Under **Tool permissions**, set the tool to **Always allow**, **Needs approval**, or **Blocked**. We recommend these settings:

- Set read-only tools, such as `list_doc_collections` and `get_task_status`, to **Always allow**.
- Keep tools that start or change work, such as `submit_documentation_task` and `edit_documentation_file`, on **Needs approval**.

[Tools](#tools) shows which tools are read-only.

## Connect ChatGPT

ChatGPT runs Promptless as a custom MCP server. The ChatGPT plan controls which Promptless tools can run:

| Plan            | Promptless tools that run                                                                                                              | Who adds Promptless                                                                        |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Business        | All tools, including tools that change data                                                                                            | An admin or owner                                                                          |
| Enterprise, Edu | All tools, including tools that change data                                                                                            | An admin or owner, or a member that an admin gives permission to through role-based access |
| Plus, Pro       | OpenAI documents Pro as limited to read and fetch actions. Tools that change data, such as `submit_documentation_task`, might not run. | The user                                                                                   |
| Free            | None. The Free plan does not support custom MCP servers.                                                                               | Not available                                                                              |

### Add Promptless in ChatGPT

Do these steps in ChatGPT on the web. {/* TODO(verify): every label in these steps, and whether the Promptless tab opens at "Create as a plugin" or at install. The steps follow OpenAI's Plugins flow as summarized on 2026-10-16; help.openai.com could not be fetched directly. */}

<Steps>
  1. Go to [chatgpt.com/plugins](https://chatgpt.com/plugins).

  2. Select **+**, and then select **Add custom MCP server**.

  3. In the name field, enter `Promptless`.

  4. In the description field, enter a short description. For example: `Start and track Promptless documentation tasks, and search, read, and edit our docs.` ChatGPT uses this text to decide when to call Promptless.

  5. Under **Connection**, enter `https://api.gopromptless.ai/mcp/with-direct-edits`.

  6. For authentication, select **OAuth**. ChatGPT registers itself with Promptless, so it does not need a client ID or secret.

  7. Accept the risk warning, and select **Create as a plugin**.

  8. Find **Promptless** in your plugins, and install it. A Promptless tab opens.

  9. Approve the connection in the Promptless tab. See [Approve the connection](#approve-the-connection).
</Steps>

If your account shows **Apps** instead of **Plugins**, your account uses the earlier layout. Open **Settings**, and turn on **Developer mode**. The toggle is under **Security and login** or **Apps** > **Advanced settings**. Then go to **Settings** > **Apps**, select **Create**, and enter the same values.

On a Business, Enterprise, or Edu workspace, an admin can publish Promptless to the workspace. After the admin publishes it, other members can connect to it. ChatGPT keeps the list of Promptless tools that it read when the admin approved it. When Promptless adds tools, an admin refreshes the tool list in the workspace app settings.

### Use Promptless in a ChatGPT conversation

In a new conversation, select Promptless from the tools menu below the message box. You can also @-mention Promptless by name. The selection applies only to the message that you send. For a follow-up message that needs Promptless, select or mention Promptless again.

Before a tool that changes data runs, ChatGPT shows a confirmation card. Read the action, and then allow or deny it. For app permission settings, see the OpenAI [developer mode guide](https://help.openai.com/en/articles/12584461-developer-mode-and-full-mcp-apps-in-chatgpt-beta).

## Approve the connection

When you connect in Claude or ChatGPT, a Promptless page opens. On this page, you approve the connection. Promptless uses OAuth, so the chat app does not get your Promptless password.

<Steps>
  1. If you are not signed in to Promptless, sign in with your Promptless account. The page **Connect \{app name} to Promptless** opens.

  2. Find the **Returns to** row. It shows the address that gets access when you approve. For Claude, the address is `claude.ai` or `claude.com`. For ChatGPT, the address is `chatgpt.com`.

  3. If the address does not match the app that you connect, select **Cancel**. Promptless does not verify the app name, so check the address, not the name.

  4. In **Organization**, select the Promptless organization to connect. Your active organization is selected by default. **Your role** shows your role in that organization.

  5. Select **Authorize as \{your email}**.
</Steps>

The page says that it is returning you to your editor. You can close the tab. In Claude or ChatGPT, Promptless shows as connected, and its tools are ready.

If you are not a member of a Promptless organization, the page asks for an organization name. Select **Create organization and authorize as \{your email}** to create the organization. Before you start documentation tasks, [finish setting up Promptless](https://app.gopromptless.ai/configuration). To see what is left to set up, ask the chat app: `What's left to set up in my Promptless account?`

## Test the connection

Use these prompts to make sure that the connection works. Start a new conversation with Promptless turned on. In ChatGPT, select or @-mention Promptless in each message.

| Prompt                                                                                                                 | Expected result                                                                                                                                                                                                                                         |
| ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `List my Promptless doc collections.`                                                                                  | A list of the doc collections of the organization, by name. If the organization has not finished setup, the result tells you to [finish setting up Promptless](https://app.gopromptless.ai/configuration).                                              |
| `Show my recent Promptless tasks.`                                                                                     | A list of recent tasks, newest first. The list includes tasks from Slack, GitHub, and the dashboard. A new organization might have no tasks.                                                                                                            |
| `Search my Promptless docs for "install".`                                                                             | Lines that contain "install", with their file paths.                                                                                                                                                                                                    |
| `Ask Promptless to fix any typos on the quickstart page in my docs collection, and follow the task until it finishes.` | The app asks you to approve `submit_documentation_task`. Then the app follows the task for some minutes and shows messages from Promptless. The final result is a suggestion with a docs pull request link, or a statement that no change is necessary. |

If the first two prompts give results, the connection works. The last prompt is optional. It starts real work in the organization. To remove the result, enter `Close that Promptless suggestion.`

## Reconnect or disconnect

A connection lasts 90 days from approval. During this time, the app refreshes its access automatically. After 90 days, the app asks you to connect again.

In Claude, go to **Customize** > **Connectors** and select **Promptless**:

- To connect again, select **Reconnect** or **Connect**, and then approve the connection.
- To sign Claude out of Promptless, select **Disconnect**. Promptless stays in your list of connectors.
- To remove Promptless, open the three-dot menu and select **Remove**. On a Team or Enterprise plan, an Owner can remove Promptless for all members in **Organization settings** > **Connectors**.

In ChatGPT, go to **Plugins**, or **Settings** > **Apps** on the earlier layout, and select **Promptless**. Connect your account again, or disconnect it from its menu. A workspace admin can turn off Promptless for all members in the admin settings of the workspace. {/* TODO(verify): ChatGPT reconnect and disconnect labels in the Plugins layout. */}

The Promptless dashboard does not have a control to disconnect a chat app. Each member disconnects their own connection in the chat app.

## Troubleshooting

- **The page says that the authorization request is no longer valid**: Approval requests expire after 30 minutes. The page tells you to run the connect command in your editor. Instead, start the connection again from Claude or ChatGPT.
- **The page says that the request has already been answered**: You already approved or canceled the request. If the app still waits for approval, start the connection again.
- **You canceled on the approval page**: The app shows that the connection was declined. To try again, select **Connect to Claude** in Claude, or connect Promptless again in ChatGPT.
- **The organization is not in the picker**: You are not an active member of the organization. Ask an admin of the Promptless organization to invite you.
- **You see Request instead of Connect to Claude**: An Owner of your Claude organization has not added Promptless. Select **Request**, or ask an Owner.
- **Promptless tools do not run in a Claude conversation**: Turn on Promptless from **+** > **Connectors** in the conversation. Then make sure that the tool is not set to **Blocked** in **Customize** > **Connectors**.
- **Promptless tools do not run in a ChatGPT conversation**: Select or @-mention Promptless in the message. On a plan limited to read actions, tools that change data do not run. On the earlier layout, make sure that developer mode is on.
- **The app says that `search_documentation` or another file tool does not exist**: The connector uses `https://api.gopromptless.ai/mcp`, which does not have the file tools. Remove the connector. Then add it again with `https://api.gopromptless.ai/mcp/with-direct-edits`.
- **You connected the wrong organization**: Disconnect Promptless. Connect again, and select the correct organization on the approval page.

For errors that Promptless tools return after you connect, see [Troubleshooting](/docs/for-docs/connect/triggers/mcp#troubleshooting) on the MCP triggers page. For other problems, send an email to [help@gopromptless.ai](mailto\:help@gopromptless.ai).

## Reference

This section is for Owners, admins, and reviewers who need the technical details of the connection.

### Server details

| Item                  | Value                                                                         |
| --------------------- | ----------------------------------------------------------------------------- |
| Server URL            | `https://api.gopromptless.ai/mcp/with-direct-edits`                           |
| Authentication        | OAuth 2.1 authorization code flow with PKCE (`S256`)                          |
| Client registration   | Dynamic client registration. No client ID or client secret is necessary.      |
| Access token lifetime | 8 hours. The app refreshes the token automatically.                           |
| Connection lifetime   | 90 days from approval. After 90 days, the user approves the connection again. |
| Data scope            | One Promptless organization, which the user selects on the approval page      |
| Account               | A Promptless account. No API key is necessary.                                |
| Privacy policy        | [Promptless privacy policy](/docs/for-docs/security/privacy-policy)           |
| Support               | [help@gopromptless.ai](mailto\:help@gopromptless.ai)                          |

Chat apps must use this server URL. A chat app has no local copy of the documentation repository, so this URL adds tools to search, read, and edit the documentation directly. Editors use `https://api.gopromptless.ai/mcp`, which does not have these tools. Both URLs use the same sign-in and the same access. The connection uses the [Model Context Protocol](https://modelcontextprotocol.io) (MCP).

### Tools

The chat app selects the Promptless tool that matches your request. Each tool has MCP annotations (`readOnlyHint` and `destructiveHint`) that tell the app if the tool changes data. The **Type** column shows these annotations:

- **Read-only**: The tool does not change data.
- **Changes data**: The tool adds work or input. It does not change or remove existing content.
- **Changes existing content**: The tool changes or closes an existing suggestion or file.

| Tool                         | Action                                                                                             | Type                     |
| ---------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------ |
| `list_doc_collections`       | Lists the doc collections of the organization.                                                     | Read-only                |
| `list_recent_tasks`          | Lists the recent tasks of the organization, newest first.                                          | Read-only                |
| `get_task_status`            | Gets the status and conversation of one task.                                                      | Read-only                |
| `wait_for_task_update`       | Waits up to 30 seconds for new messages or a status change on one task.                            | Read-only                |
| `search_suggestions`         | Finds suggestions by keyword, status, or label.                                                    | Read-only                |
| `get_suggestion_diff`        | Shows the changes that a suggestion proposes.                                                      | Read-only                |
| `list_documentation_files`   | Lists the files in a doc collection.                                                               | Read-only                |
| `search_documentation`       | Finds text in the documentation files.                                                             | Read-only                |
| `read_documentation_file`    | Reads one documentation file.                                                                      | Read-only                |
| `get_account_status`         | Shows the setup status and connected integrations of the organization.                             | Read-only                |
| `submit_documentation_task`  | Starts a documentation task. The task can open a docs pull request.                                | Changes data             |
| `send_task_message`          | Adds an instruction to a task that is in progress.                                                 | Changes data             |
| `answer_task_question`       | Sends the answer to a question that a task asked.                                                  | Changes data             |
| `request_changes`            | Asks Promptless to revise a suggestion.                                                            | Changes data             |
| `connect_integration`        | Creates a link that a person opens to connect an integration, such as GitHub, to the organization. | Changes data             |
| `message_promptless_support` | Sends a report to the Promptless support team. Replies do not come back through the tool.          | Changes data             |
| `update_suggestion`          | Sets the title, labels, or assignees of a suggestion, or opens its docs pull request.              | Changes existing content |
| `close_suggestion`           | Closes a suggestion and its docs pull request.                                                     | Changes existing content |
| `write_documentation_file`   | Creates or replaces one file on the branch of an open suggestion.                                  | Changes existing content |
| `edit_documentation_file`    | Replaces specific text in one file on the branch of an open suggestion.                            | Changes existing content |

The two file tools write only to the branch of an open suggestion, as one commit for each call. They cannot edit a closed suggestion.

For the arguments and results of each tool, see [Available tools](/docs/for-docs/connect/triggers/mcp#available-tools).
