Promptless works through docs pull requests. You set up [triggers](/docs/for-docs/connect/triggers) for the events that should update your docs, such as a merged code change. For each change, Promptless opens a docs pull request, and you [review and revise it on GitHub](/docs/for-docs/work-the-queue/reviewing-prs) the same way you review code. GitLab merge requests work the same way.

If your team plans and reviews docs work somewhere else, you can give Promptless instructions and review its suggestions from these tools:

- Slack and Microsoft Teams. See [Review from Slack and Teams](/docs/for-docs/work-the-queue/reviewing-from-slack-and-teams).
- Jira. See [Jira](/docs/for-docs/connect/triggers/jira).
- The Promptless dashboard. See [Review in the dashboard](/docs/for-docs/work-the-queue/reviewing-prs#review-in-the-dashboard).
- Claude.ai and ChatGPT. This page shows how to set them up.
- Editors such as Claude Code and Cursor. See [MCP triggers](/docs/for-docs/connect/triggers/mcp).

After you connect Claude.ai or ChatGPT, you can do this work from a conversation:

- Start a documentation task and follow it to a docs pull request.
- Check the status of recent tasks.
- Search and read the organization's documentation.
- Review, revise, or close a suggested documentation change.

The connection uses the Promptless [MCP](https://modelcontextprotocol.io) (Model Context Protocol) server. For the arguments and results of each tool, see [MCP triggers](/docs/for-docs/connect/triggers/mcp).

## Server details

| Item                  | Value                                                                         |
| --------------------- | ----------------------------------------------------------------------------- |
| Server URL            | `https://api.gopromptless.ai/mcp/with-direct-edits`                           |
| Authentication        | OAuth 2.1 authorization code flow with PKCE (`S256`)                          |
| Client registration   | Dynamic client registration. No client ID or client secret is necessary.      |
| Access token lifetime | 8 hours. The app refreshes the token automatically.                           |
| Connection lifetime   | 90 days from approval. After 90 days, the user approves the connection again. |
| Data scope            | One Promptless organization, which the user selects on the approval page      |
| Account               | A Promptless account. No API key is necessary.                                |
| Privacy policy        | [Promptless privacy policy](/docs/for-docs/security/privacy-policy)           |
| Support               | [help@gopromptless.ai](mailto\:help@gopromptless.ai)                          |

Chat apps must use the server URL in this table. A chat app has no local copy of the documentation repository. So this URL adds tools to search, read, and edit the documentation directly. Editors use `https://api.gopromptless.ai/mcp`, which does not have these tools. Both URLs use the same sign-in and the same access.

## Requirements

- A Promptless organization that has [finished setting up Promptless](https://app.gopromptless.ai/configuration). Any active member of the organization can connect.
- Claude.ai on any plan. The Free plan allows one custom connector. On a Team or Enterprise plan, an Owner must add the connector for the organization first.
- ChatGPT on a paid plan, with developer mode on. On a Business, Enterprise, or Edu workspace, an admin or owner controls developer mode and custom apps.

## Add Promptless to Claude.ai

The steps are different for individual plans and organization plans. Free, Pro, and Max are individual plans. Team and Enterprise are organization plans.

### Individual plans

<Steps>
  1. In Claude.ai, go to **Customize** > **Connectors**.

  2. Select **+**.

  3. Select **Add custom connector**.

  4. In the name field, enter `Promptless`.

  5. In the URL field, enter `https://api.gopromptless.ai/mcp/with-direct-edits`.

  6. Do not change **Advanced settings**. Claude registers itself with Promptless, so it does not need an OAuth client ID or secret.

  7. Select **Add**.

  8. On the **Promptless** connector, select **Connect**. A Promptless tab opens.

  9. Approve the connection in the Promptless tab. See [Approve the connection](#approve-the-connection).
</Steps>

Some accounts show a two-step version of the **Add custom connector** dialog. The first screen asks for the name and URL. The second screen shows authentication options. On the second screen, keep the OAuth defaults.

### Organization plans

An Owner adds the connector one time for the organization. Then each member connects their own Promptless account.

<Steps>
  1. Owner: In Claude.ai, go to **Organization settings** > **Connectors**.

  2. Owner: Select **Add**, point to **Custom**, and then select **Web**.

  3. Owner: Enter the URL `https://api.gopromptless.ai/mcp/with-direct-edits`.

  4. Owner: Select **Add**.

  5. Member: Go to **Customize** > **Connectors**. Find the **Promptless** connector, which has the label **Custom**.

  6. Member: Select **Connect**. A Promptless tab opens.

  7. Member: Approve the connection in the Promptless tab. See [Approve the connection](#approve-the-connection).
</Steps>

Each member approves their own connection. So each connection has the Promptless access of that member only. An Owner can block specific tools for all members in **Organization settings** > **Connectors**.

### Use Promptless in a Claude.ai conversation

<Steps>
  1. In a conversation, select **+** at the lower left of the message box.

  2. Select **Connectors**.

  3. Turn on **Promptless**.
</Steps>

Claude asks the user to approve the first call to each Promptless tool. To change this for one tool, go to **Customize** > **Connectors** and select **Promptless**. Then set the tool to **Ask each time**, **Always allow**, or **Blocked**.

Recommended settings:

- Set read-only tools, such as `list_doc_collections` and `get_task_status`, to **Always allow**.
- Keep tools that start or change work, such as `submit_documentation_task` and `edit_documentation_file`, on **Ask each time**.

For more about connector settings, see the Anthropic [custom connectors guide](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).

## Add Promptless to ChatGPT

ChatGPT runs custom MCP servers as apps in developer mode. OpenAI labels developer mode and full MCP support as beta. Some accounts show app settings under **Apps**. Other accounts show them under **Plugins**.

The ChatGPT plan controls which Promptless tools can run:

| Plan                      | Promptless tools that run                                                                                                              | Who turns on developer mode                                                                                                    |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Business, Enterprise, Edu | All tools, including tools that change data                                                                                            | An admin or owner. On Enterprise and Edu, an admin can also give developer mode to specific members through role-based access. |
| Plus, Pro                 | OpenAI documents Pro as limited to read and fetch actions. Tools that change data, such as `submit_documentation_task`, might not run. | The user                                                                                                                       |
| Free                      | None. The Free plan does not support custom apps.                                                                                      | Not available                                                                                                                  |

<Steps>
  1. In ChatGPT, open **Settings**.

  2. Turn on **Developer mode**. The toggle is under **Security and login**. On accounts with the earlier layout, the toggle is under **Apps** > **Advanced settings**.

  3. Go to [chatgpt.com/plugins](https://chatgpt.com/plugins), or go to **Settings** > **Apps**.

  4. Select **Create** or **+**.

  5. In the name field, enter `Promptless`.

  6. In the description field, enter a short description. For example: `Start and track Promptless documentation tasks, and search, read, and edit our docs.` ChatGPT uses this text to decide when to call the app.

  7. In the MCP server URL field, enter `https://api.gopromptless.ai/mcp/with-direct-edits`.

  8. For authentication, select **OAuth**. ChatGPT registers itself with Promptless, so it does not need a client ID or secret.

  9. Select **Create**. A Promptless tab opens.

  10. Approve the connection in the Promptless tab. See [Approve the connection](#approve-the-connection).
</Steps>

ChatGPT reads the Promptless tool list. Then ChatGPT adds the app with a **Dev** label. On a Business, Enterprise, or Edu workspace, an admin can publish the app from the app drafts of the workspace. After the admin publishes the app, other members can connect to it.

### Use Promptless in a ChatGPT conversation

In a new conversation, select Promptless from the tools menu below the message box. You can also @-mention Promptless by name. The selection applies only to the message that you send. For a follow-up message that needs Promptless, select or mention Promptless again.

Before a tool that changes data runs, ChatGPT shows a confirmation card. Read the action, and then allow or deny it. For app permission settings, see the OpenAI [developer mode guide](https://help.openai.com/en/articles/12584461-developer-mode-and-full-mcp-apps-in-chatgpt-beta).

## Approve the connection

After you select **Connect** in Claude.ai or **Create** in ChatGPT, a Promptless tab opens. On this page, you approve the connection. Promptless uses OAuth, so the chat app does not get your Promptless password.

<Steps>
  1. If you are not signed in to Promptless, sign in with your Promptless account. The approval page opens.

  2. Find the web address that the page shows. The page sends the connection to this address. For Claude, the address is `claude.ai` or `claude.com`. For ChatGPT, the address is `chatgpt.com`.

  3. If the address does not match the app that you connect, select **Cancel**. The app sets its own name, so check the address, not the name.

  4. In the organization picker, select the Promptless organization to connect. The picker selects your active organization by default. The page also shows your role in the organization.

  5. Select **Authorize as \{your email}**.
</Steps>

The tab shows that it is returning you to the app. You can close the tab. In Claude.ai or ChatGPT, Promptless shows as connected, and its tools are ready.

If you are not a member of a Promptless organization, the approval page asks for an organization name. When you authorize, Promptless creates the organization. Before you start documentation tasks, [finish setting up Promptless](https://app.gopromptless.ai/configuration).

## Tools

The chat app selects the Promptless tool that matches the user's request. Each tool has MCP annotations that tell the app if the tool is read-only or changes data. The **Type** column shows these annotations:

- **Read-only**: `readOnlyHint` is true. The tool does not change data.
- **Changes data**: `readOnlyHint` is false and `destructiveHint` is false. The tool adds work or input, and does not change or remove existing content.
- **Changes existing content**: `readOnlyHint` is false and `destructiveHint` is true. The tool changes or closes an existing suggestion or file.

| Tool                        | Action                                                                                             | Type                     |
| --------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------ |
| `list_doc_collections`      | Lists the doc collections of the organization.                                                     | Read-only                |
| `list_recent_tasks`         | Lists the recent tasks of the organization, newest first.                                          | Read-only                |
| `get_task_status`           | Gets the status and conversation of one task.                                                      | Read-only                |
| `wait_for_task_update`      | Waits up to 30 seconds for new messages or a status change on one task.                            | Read-only                |
| `search_suggestions`        | Finds suggestions by keyword, status, or label.                                                    | Read-only                |
| `get_suggestion_diff`       | Shows the changes that a suggestion proposes.                                                      | Read-only                |
| `list_documentation_files`  | Lists the files in a doc collection.                                                               | Read-only                |
| `search_documentation`      | Finds text in the documentation files.                                                             | Read-only                |
| `read_documentation_file`   | Reads one documentation file.                                                                      | Read-only                |
| `get_account_status`        | Shows the setup status and connected integrations of the organization.                             | Read-only                |
| `submit_documentation_task` | Starts a documentation task. The task can open a docs pull request.                                | Changes data             |
| `send_task_message`         | Adds an instruction to a task that is in progress.                                                 | Changes data             |
| `answer_task_question`      | Sends the answer to a question that a task asked.                                                  | Changes data             |
| `request_changes`           | Asks Promptless to revise a suggestion.                                                            | Changes data             |
| `connect_integration`       | Creates a link that a person opens to connect an integration, such as GitHub, to the organization. | Changes data             |
| `update_suggestion`         | Sets the title, labels, or assignees of a suggestion, or opens its docs pull request.              | Changes existing content |
| `close_suggestion`          | Closes a suggestion and its docs pull request.                                                     | Changes existing content |
| `write_documentation_file`  | Creates or replaces one file on the branch of an open suggestion.                                  | Changes existing content |
| `edit_documentation_file`   | Replaces specific text in one file on the branch of an open suggestion.                            | Changes existing content |

The two file tools write only to the branch of an open suggestion, as one commit for each call. They do not write to the default branch of the documentation repository. The tools cannot edit a closed suggestion.

For the arguments and results of each tool, see [Available tools](/docs/for-docs/connect/triggers/mcp#available-tools).

## Data access

A connection has the access of the user who approved it, in the organization that the user selected. The approval page shows this access. There are no narrower permissions to select. A connection can:

- Read all documentation tasks, doc collections, and suggestions in the organization. This includes work that started from Slack, GitHub, the dashboard, or the API.
- Start documentation tasks, which can open docs pull requests.
- Revise, update, and close suggestions.
- Search, read, and edit documentation files on the branch of an open suggestion.

A connection applies to one organization only. To use a different organization, disconnect, connect again, and select the other organization on the approval page.

Promptless checks the organization membership of the user on each call. If the user is no longer an active member, the connection stops working. For more about access and membership, see [Authorize in the browser](/docs/for-docs/connect/triggers/mcp#authorize-in-the-browser). For data handling, see the [Promptless privacy policy](/docs/for-docs/security/privacy-policy).

## Test the connection

Use these prompts to make sure that the connection works. Start a new conversation with Promptless turned on. In ChatGPT, select or @-mention Promptless in each message.

| Prompt                                                                                                                 | Tool                                                     | Expected result                                                                                                                                                                                                                                         |
| ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `List my Promptless doc collections.`                                                                                  | `list_doc_collections`                                   | A list of the doc collections of the organization, by name. If the organization has not finished setup, the result tells you to [finish setting up Promptless](https://app.gopromptless.ai/configuration).                                              |
| `Show my recent Promptless tasks.`                                                                                     | `list_recent_tasks`                                      | A list of recent tasks, newest first. The list includes tasks from Slack, GitHub, and the dashboard. A new organization might have no tasks.                                                                                                            |
| `Search my Promptless docs for "install".`                                                                             | `search_documentation`                                   | Lines that contain "install", with their file paths.                                                                                                                                                                                                    |
| `Ask Promptless to fix any typos on the quickstart page in my docs collection, and follow the task until it finishes.` | `submit_documentation_task`, then `wait_for_task_update` | The app asks you to approve `submit_documentation_task`. Then the app follows the task for some minutes and shows messages from Promptless. The final result is a suggestion with a docs pull request link, or a statement that no change is necessary. |

The last prompt is optional. It starts real work in the organization. To remove the result, enter `Close that Promptless suggestion.`

If the first two prompts give results, the connection works. If the third prompt says that the tool does not exist, the connector uses `https://api.gopromptless.ai/mcp`. Remove the connector. Then add it again with `https://api.gopromptless.ai/mcp/with-direct-edits`.

## Reconnect or disconnect

A connection lasts 90 days from approval. During this time, the app refreshes its access automatically. After 90 days, the app asks you to connect again.

To connect again:

- In Claude.ai, go to **Customize** > **Connectors**, select **Promptless**, and select **Connect**.
- In ChatGPT, go to **Settings** > **Apps** or **Plugins**, select **Promptless**, and connect your account.

To disconnect:

- In Claude.ai, go to **Customize** > **Connectors**. Open the menu next to **Promptless**, and select **Remove**. On a Team or Enterprise plan, an Owner can remove the connector for all members in **Organization settings** > **Connectors**.
- In ChatGPT, go to **Settings** > **Apps** or **Plugins**, and select **Promptless**. Disconnect it from its menu. A workspace admin can turn off the app for all members in the admin settings of the workspace.

The Promptless dashboard does not have a control to disconnect a chat app. Each member disconnects their own connection in the chat app.

## Troubleshooting

- **The approval page says that the request is no longer valid**: Approval requests expire after 30 minutes. Start the connection again from Claude.ai or ChatGPT.
- **The approval page says that the request has already been answered**: You already approved or canceled the request. If the app still waits for approval, start the connection again.
- **You canceled on the approval page**: The app shows that the connection was declined. To try again, select **Connect** in Claude.ai, or connect the app again in ChatGPT.
- **The organization is not in the picker**: You are not an active member of the organization. Ask an admin of the Promptless organization to invite you.
- **Promptless tools do not run in a Claude.ai conversation**: Turn on Promptless from **+** > **Connectors** in the conversation. Then make sure that the tool is not set to **Blocked** in **Customize** > **Connectors**.
- **Promptless tools do not run in a ChatGPT conversation**: Make sure that developer mode is on. Then select or @-mention Promptless in the message. On a plan limited to read actions, tools that change data do not run.
- **You connected the wrong organization**: Disconnect Promptless. Connect again, and select the correct organization on the approval page.

For errors that Promptless tools return after you connect, see [Troubleshooting](/docs/for-docs/connect/triggers/mcp#troubleshooting) on the MCP triggers page. For other problems, send an email to [help@gopromptless.ai](mailto\:help@gopromptless.ai).
