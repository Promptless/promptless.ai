## Overview

Connect Promptless to Claude or ChatGPT to work on your docs from a conversation. Ask for documentation changes, follow each task to a docs pull request, review Promptless suggestions, and edit the docs on an open suggestion. Use this connection when your team plans and discusses docs work in a chat app. Any member of a Promptless organization can connect their own account.

To set up the connection, follow the guide for your app:

- [Use Promptless from Claude](/docs/for-docs/work-the-queue/claude) to add the connector from the [Claude directory](https://claude.ai/directory/promptless), in Claude on the web, Claude Desktop, or the Claude mobile apps.
- [Use Promptless from ChatGPT](/docs/for-docs/work-the-queue/chatgpt) to add Promptless as a custom MCP plugin.

To use Promptless from an editor such as Claude Code or Cursor, see [MCP triggers](/docs/for-docs/connect/triggers/mcp). To work from Slack or Microsoft Teams, see [Review from Slack and Teams](/docs/for-docs/work-the-queue/reviewing-from-slack-and-teams).

## What you can do from a conversation

Ask in plain language. The chat app selects the Promptless tool that matches your request.

| Ask                                                                          | Promptless                                                                                                    |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `Ask Promptless to document the new --preview flag in the CLI reference.`    | Starts a documentation task. The app follows the task and shows its result, such as a docs pull request link. |
| `Show my recent Promptless tasks.`                                           | Lists recent tasks in your organization, including tasks that started from Slack, GitHub, or the dashboard.   |
| `Find open Promptless suggestions about webhook retries.`                    | Finds suggestions by keyword, status, or label.                                                               |
| `Revise that suggestion to also cover single sign-on.`                       | Asks Promptless to revise the suggestion and its docs pull request.                                           |
| `In my docs, change the default retry count from 3 to 5 on that suggestion.` | Searches, reads, and edits documentation files on the branch of an open suggestion.                           |

For every tool and what it can change, see [Tools](/docs/for-docs/reference/claude-and-chatgpt-connector#tools) in the connector reference.

## What a connection can access

A connection has the Promptless access of the person who approved it, in the one organization that they selected. It can read all tasks, doc collections, and suggestions in that organization. It can also start documentation tasks, change and close suggestions, and edit documentation files on the branch of an open suggestion. Edits never go to the default branch. For the full list, the sign-in, and token lifetimes, see the [Claude and ChatGPT connector reference](/docs/for-docs/reference/claude-and-chatgpt-connector).

On a Claude Team or Enterprise plan, an Owner adds Promptless for the organization before members connect. On a ChatGPT Business, Enterprise, or Edu workspace, an admin publishes the Promptless plugin first. Each member then connects their own Promptless account, so each connection has only that member's access.
