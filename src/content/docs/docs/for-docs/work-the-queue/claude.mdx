## Overview

Add the [Promptless connector from the Claude directory](https://claude.ai/directory/edb58d4d-3a6e-4950-a748-02d45a9e863c) to work on your docs from a Claude conversation. Ask Claude to start a documentation task, follow it to a docs pull request, review suggestions, or edit the docs on an open suggestion. The connector works in Claude on the web, Claude Desktop, and the Claude mobile apps. Each member of a Promptless organization connects their own account. On a Claude Team or Enterprise plan, an Owner adds the connector for the organization first. When you finish, Promptless is connected and you have run a test prompt.

For ChatGPT, see [Use Promptless from ChatGPT](/docs/for-docs/work-the-queue/chatgpt). For Claude Code, see [MCP triggers](/docs/for-docs/connect/triggers/mcp). To check the server, sign-in, and tools before you approve the connector, see the [Claude and ChatGPT connector reference](/docs/for-docs/reference/claude-and-chatgpt-connector).

## Before you connect

- A Promptless organization that has [finished setting up Promptless](https://app.gopromptless.ai/configuration). Any active member of the organization can connect.
- A Claude account. On a Team or Enterprise plan, an Owner adds the connector for the organization before members connect.
- Read [what a connection can access](/docs/for-docs/reference/claude-and-chatgpt-connector#data-access). The connection acts with your Promptless access in the organization that you select. It can start documentation tasks, and change suggestions and the files on their branches.

## Add Promptless on an individual plan

Use these steps on a Free, Pro, Max, or Ultra plan.

<Steps>
  1. Open the [Promptless listing in the Claude directory](https://claude.ai/directory/edb58d4d-3a6e-4950-a748-02d45a9e863c).

  2. Select **Connect**. A Promptless tab opens.

  3. Approve the connection. See [Approve the connection](#approve-the-connection).
</Steps>

## Add Promptless for your organization

On a Team or Enterprise plan, an Owner adds Promptless one time for the organization. On Enterprise, a member whose custom role includes managing the organization's libraries can also add it. Adding the connector makes it available to members. Each member still connects their own account.

<Steps>
  1. In Claude, go to **Organization settings** > **Connectors**.

  2. Select **Browse connectors**.

  3. Select **Promptless**, and then select **Add to your team**.
</Steps>

On a Team plan, a member who cannot add connectors sees **Request** on the Promptless listing. Selecting it sends the request to the Owners of the organization. To block specific Promptless tools for all members, an Owner uses **Organization settings** > **Connectors**.

## Connect your account in an organization

On a Team or Enterprise plan, connect your own Promptless account after an Owner adds Promptless. The connection has your Promptless access only.

<Steps>
  1. In Claude, go to **Customize** > **Connectors**.

  2. Find **Promptless**, and then select **Connect**. A Promptless tab opens.

  3. Approve the connection. See [Approve the connection](#approve-the-connection).
</Steps>

## Add Promptless as a custom connector

Use these steps on an individual plan when you cannot open the directory listing from your account. The custom connector uses the same server as the directory listing.

<Steps>
  1. In Claude, go to **Customize** > **Connectors**.

  2. Select **+**, and then select **Add custom connector**.

  3. In the name field, enter `Promptless`.

  4. In the URL field, enter `https://api.gopromptless.ai/mcp/with-direct-edits`.

  5. Under **OAuth client**, select **Register automatically**. Promptless supports dynamic client registration, so Claude registers itself with Promptless.

  6. Select **Add**.

  7. On the **Promptless** connector, select **Connect**. A Promptless tab opens.

  8. Approve the connection. See [Approve the connection](#approve-the-connection).
</Steps>

On a Team or Enterprise plan, an Owner adds the custom connector in **Organization settings** > **Connectors**. The Owner selects **Add**, points to **Custom**, selects **Web**, and enters the same URL. Then each member follows [Connect your account in an organization](#connect-your-account-in-an-organization).

Use the URL `https://api.gopromptless.ai/mcp/with-direct-edits`. It adds the tools that search, read, and edit your documentation, which a chat app needs because it has no local copy of your repository.

## Approve the connection

When you select **Connect**, a Promptless tab opens. On this page, you approve the connection. Promptless uses OAuth, so Claude never gets your Promptless password.

<Steps>
  1. If the page asks you to sign in, sign in with your Promptless account.

  2. Find the **Returns to** row. For Claude, the address is `claude.ai` or `claude.com`.

  3. If the address is different, select **Cancel**. The app sets its own name, and Promptless does not verify it, so check the address, not the name.

  4. In the organization picker, select the Promptless organization to connect. The picker selects your active organization by default. The page also shows your role in the organization.

  5. Select **Authorize as \{your email}**.
</Steps>

The tab returns you to Claude, and Promptless shows as connected. You can close the tab.

If you are not a member of a Promptless organization, the approval page asks for an organization name. The button reads **Create organization and authorize as \{your email}**. When you select it, Promptless creates the organization. Before you start documentation tasks, [finish setting up Promptless](https://app.gopromptless.ai/configuration).

## Turn on Promptless in a conversation

<Steps>
  1. In a conversation, select **+** at the lower left of the message box.

  2. Select **Connectors**.

  3. Turn on **Promptless**.
</Steps>

Claude asks you to approve the first call to each Promptless tool. To change this for one tool, go to **Customize** > **Connectors**, select **Promptless**, and set the tool to **Ask each time**, **Always allow**, or **Blocked**. Recommended settings:

- Set read-only tools, such as `list_doc_collections` and `get_task_status`, to **Always allow**.
- Keep tools that start or change work, such as `submit_documentation_task` and `edit_documentation_file`, on **Ask each time**.

The [MCP tools reference](/docs/for-docs/reference/mcp-tools) shows which tools are read-only. For more about connector settings, see the Anthropic [custom connectors guide](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).

## Test the connection

Start a new conversation with Promptless turned on. Then enter these prompts:

| Prompt                                     | Tool                   | Expected result                                                                                                               |
| ------------------------------------------ | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `List my Promptless doc collections.`      | `list_doc_collections` | The doc collections of the organization, by name. To see setup steps that remain, enter `What is my Promptless setup status?` |
| `Show my recent Promptless tasks.`         | `list_recent_tasks`    | Recent tasks, newest first, including tasks from Slack, GitHub, and the dashboard. A new organization might have no tasks.    |
| `Search my Promptless docs for "install".` | `search_documentation` | Lines that contain "install", with their file paths.                                                                          |

If the first two prompts give results, the connection works.

To see the full flow, run a real task. This step is optional and starts real work in your organization:

```text
Ask Promptless to fix any typos on the quickstart page in my docs collection, and follow the task until it finishes.
```

Claude asks you to approve `submit_documentation_task`. Then Claude follows the task with `wait_for_task_update` for some minutes and shows messages from Promptless. The final result is a suggestion with a docs pull request link, or a statement that no change is necessary. To remove the result, enter `Close that Promptless suggestion.`

## Reconnect or disconnect

A connection lasts 90 days from approval. During this time, Claude refreshes its access automatically. After 90 days, Claude asks you to connect again.

- To connect again, go to **Customize** > **Connectors**, select **Promptless**, and select **Connect**.
- To disconnect, go to **Customize** > **Connectors**, open the menu next to **Promptless**, and select **Remove**. On a Team or Enterprise plan, an Owner can remove the connector for all members in **Organization settings** > **Connectors**.

Each member disconnects their own connection in Claude.

## Troubleshooting

- **The approval page says that the request is no longer valid**: The request expired after 30 minutes. Or you opened a request that you already approved or canceled. Select **Connect** in Claude again.
- **The approval page says that the request has already been answered**: You selected **Authorize** or **Cancel** a second time, for example in a second tab. If Claude still waits for approval, select **Connect** again.
- **You canceled on the approval page**: Claude shows that the connection was declined. To try again, select **Connect**.
- **The organization is not in the picker**: You are not an active member of the organization. Ask an admin of the Promptless organization to invite you.
- **A prompt says that a documentation tool does not exist**: The custom connector uses `https://api.gopromptless.ai/mcp`, which has no tools to search, read, or edit documentation. Remove the connector. Then add it again with `https://api.gopromptless.ai/mcp/with-direct-edits`, or add Promptless from the [Claude directory](https://claude.ai/directory/edb58d4d-3a6e-4950-a748-02d45a9e863c).
- **Promptless tools do not run in a conversation**: Turn on Promptless from **+** > **Connectors** in the conversation. Then make sure that the tool is not set to **Blocked** in **Customize** > **Connectors**.
- **You connected the wrong organization**: Disconnect Promptless. Connect again, and select the correct organization on the approval page.

For errors that Promptless tools return after you connect, see [Tool errors](/docs/for-docs/reference/mcp-tools#tool-errors) in the MCP tools reference. To report a problem from the conversation, ask Claude to message Promptless support, which uses the [`message_promptless_support`](/docs/for-docs/reference/mcp-tools#message_promptless_support) tool. For other problems, send an email to [help@gopromptless.ai](mailto\:help@gopromptless.ai).
