## Overview

Promptless keeps a directory of everyone who works on your docs and code. It holds your teammates, the AI agents on your team, and service accounts such as a CI account. Each record lists the accounts one person uses, such as Slack, GitHub, GitLab, and Jira. An AI agent gets the same kind of record, so Promptless knows the agent's account in each tool too. Promptless builds the directory itself, including when a person or agent has a different username or email in each tool. You review and organize it on the People page.

Because of the directory, a [routing preference](/docs/for-docs/work-the-queue/assignment-and-routing#customize-routing-in-your-knowledge-base) can cross tools. For example, you can write "Assign the docs ticket in Jira to the engineer whose GitLab merge request triggered the suggestion." Promptless finds that engineer's Jira account in their record. Your Knowledge Base doesn't need to explain who is who.

## Open the directory

Open **Settings** and select **People**. Search by name, email, or account.

- **Needs attention** lists assignees with no Slack account, inferred accounts to confirm, and possible duplicates.
- **Merge history** lists the records Promptless merged automatically in the past week.

## Sort records into groups

Each record is in one group. Move a record to classify it as a teammate, an AI agent, or a service account.

| Group                | Use it for                                                             |
| -------------------- | ---------------------------------------------------------------------- |
| **People**           | Your teammates.                                                        |
| **Agents**           | AI agents on your team, such as a coding agent that opens PRs.         |
| **Service accounts** | Shared and automated accounts, such as a CI account.                   |
| **Archived**         | Records you want out of view, such as a teammate who left the company. |

Only organization admins can move or archive records.

- To move records, select them and choose a group under **Move to…**. You can also change the group in a record's details.
- To archive records, select them and select **Archive**. An archived record keeps its accounts, assignment history, and group. You can't pick it as an assignee in the dashboard, but Promptless can still assign it. To return it to its group, select **Restore**.

## Correct a record's accounts

Each account on a record is inferred or verified. Promptless infers an account from evidence such as a matching name. An account is verified when an admin confirms or adds it, or when the person signs in to it. The weekly digest @-mentions an assignee only when their Slack account is verified.

Organization admins can change any record. Select a record, then:

- To accept an inferred account, select **Confirm link**.
- To remove a wrong account, select **Unlink account**.
- To add an account, select **Add an account**, choose its type, enter the account, and select **Link account**. For GitHub or GitLab, enter the username as it appears on that platform.

To add a person who isn't in the directory, select **Add person** and enter their name.

## Link your own accounts

Any member can verify their own Slack and GitHub accounts. Under **My accounts**, select **Link my Slack** or **Link my GitHub** and sign in. If the account was inferred on another person's record, it moves to yours. **Link my GitHub** appears only when your organization's GitHub connection is on github.com.

Members can also edit their own display name, notes, and alternate names. Only an admin can add other accounts.

## Merge duplicate records

An admin can merge two records for the same person. Start in one of these ways:

- In the directory, select both records and select **Merge selected**.
- In a person's details, select **Merge with…** and choose the other record.
- In a person's details, select **Compare** next to a possible duplicate.

Promptless shows both records side by side. Choose the display name, group, and notes to keep, then select **Merge records**. The merged record keeps every account, name, and assignment from both.

If a possible duplicate is a different person, select **Why this match?**, then **These are different records**. To undo a merge, open the merged record, expand **Merge history**, and select **Undo merge**.

## Delete a record

To delete a record, an admin opens its details menu and selects **Delete record…**. Review the accounts and open assignments listed, then select **Delete record**. Deletion is permanent. It removes the record, the records merged into it, and their suggestion assignments, including those on closed suggestions. The suggestions and their other assignees stay. If Promptless sees the person again, it can add them back.
