Promptless keeps your documentation current by connecting three pieces. **Triggers** signal when something changed, and **context sources** help Promptless understand the change. **Doc collections** define where your documentation lives and where updates are published. This page explains how those pieces fit together and how teams use them.

## Use cases

Keeping documentation current is hard work. Context gets lost in handoffs, updates fall behind releases, and support teams keep answering the same questions because the docs trail the product. Promptless drafts content in the voice of your existing docs and keeps screenshots in sync as your UI changes. It also shows the citations and reasoning behind every suggestion. Your team stays in charge of review and approval.

Teams use Promptless in different ways:

- **Vellum** (YC W23) runs Slack Connect channels with key customers and uses Promptless to turn support conversations into documentation updates. Over 50% of Vellum's docs PRs originate from Promptless. Each month, 60% of its product and engineering team uses Promptless to draft updates for features they own.
- **Amplitude**'s technical writers couldn't keep up with documentation demands, so the team uses Promptless to draft documentation for every feature release. Engineers review the first draft before it goes to customers.
- **Basis**, an AI agents platform for accounting ([ofbasis.com](https://ofbasis.com/)), uses Promptless for its entire knowledge base. Promptless processes the team's meeting recordings and updates customer pages, internal guides for its fast-growing team, and customer-facing documentation.
- **Fortune 500 companies** use Promptless to make their technical writers more productive. Their context is spread across Linear, Confluence, and Slack, and Promptless assembles the relevant information to draft doc updates for every PR.
- **Vitess**, a CNCF graduated project, uses Promptless for its open-source docs. Since installing Promptless, 94% of its documentation updates have been drafted with Promptless.

<Aside type="note" title="See Promptless in action">
  Vitess is a CNCF graduated project powering YouTube, Slack, and Square. Browse their [docs commit history](https://github.com/vitessio/website/commits/prod/content) to see Promptless drafting documentation updates in real time.
</Aside>

## Core capabilities

These capabilities keep suggestions accurate and easy to review:

- **Voice Match:** Learns the tone, sentence structure, formatting, and terminology of your existing docs, so suggestions read as if your team wrote them. See [How Promptless learns your docs](/docs/for-docs/connect/doc-locations/how-promptless-learns-your-docs).
- **Promptless Capture:** Keeps product screenshots in sync with your UI. When code changes affect a screenshot, Promptless detects which images need updating and regenerates them from your current interface.
- **Screenshot Editor:** Crop, annotate, highlight UI elements, or add shapes and text to screenshots in the dashboard. Saved edits appear in your documentation suggestions right away.
- **Passive channel listening:** Reads the Slack and Microsoft Teams channels you choose, such as Slack Connect customer channels. Promptless drafts a documentation suggestion when a conversation reveals something worth documenting. See [Get the most out of passive channel listening](/docs/for-docs/get-the-most-out/passive-channel-listening).
- **Promptless Citations:** Shows where each documentation change came from. Every update references the specific GitHub files, Slack threads, or support conversations that informed it.
