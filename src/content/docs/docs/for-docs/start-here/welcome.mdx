Promptless is an AI agent built to support technical writers. It detects when docs need to change, gathers context from code and team tools, drafts updates, and opens reviewable suggestions or pull requests.

Use Promptless to keep product docs, internal docs, agent instructions, screenshots, changelogs, and support-driven documentation current as your team ships.

In this short walkthrough, Promptless turns a product change into a documentation pull request. It finds the relevant docs and uses code and project context to draft an update with citations. Then it hands the change to a technical writer for review.

## How Promptless works

Promptless works inside the tools your team already uses. A typical documentation update follows this flow:

![Diagram of triggers and optional context sources feeding Promptless, which proposes updates to your doc collections](/mermaid/how-it-works.svg)

<Steps>
  <ol>
    <li>
      <strong>A trigger starts the workflow.</strong> A pull request, commit, Slack message, Teams message, or API event tells Promptless to investigate whether docs need to change.
    </li>

    <li>
      <strong>Promptless gathers context.</strong> Promptless reads the relevant code, existing docs, tickets, conversations, and configured context sources.
    </li>

    <li>
      <strong>Promptless drafts a suggestion.</strong> Promptless decides which pages are affected, writes the proposed update, and explains the sources behind the change.
    </li>

    <li>
      <strong>Your team reviews the update.</strong> Review the suggestion in Promptless, comment in GitHub, or ask for follow-up edits in Slack or Microsoft Teams.
    </li>

    <li>
      <strong>Promptless publishes through your docs workflow.</strong> When the update is ready, Promptless opens or updates a documentation pull request for your normal review and merge process.
    </li>
  </ol>
</Steps>
