## Overview

This quickstart gets Promptless drafting documentation updates for your team. You create an account, then work through a five-step setup wizard. The wizard connects your chat tool, your docs repository, the code providers whose changes start documentation work, and the tools that hold product context. When you finish, Promptless indexes your docs and starts watching for changes.

Connecting your docs repository is the only step you must complete. You can connect everything else later.

## Before you start

- A Promptless account. Sign up for a free account at [accounts.gopromptless.ai](https://accounts.gopromptless.ai).
- Admin access to the tools you plan to connect, depending on your organization's settings:

  | Integration         | Access you need                                                           |
  | ------------------- | ------------------------------------------------------------------------- |
  | Slack               | Workspace admin permissions to install the Promptless app                 |
  | GitHub              | Organization admin, or enough repository access to install the GitHub App |
  | Jira and Confluence | Atlassian admin permissions to authorize the OAuth connection             |
  | Linear              | Workspace admin permissions to connect the integration                    |

If you don't have the access an integration needs, invite a teammate who does. In the wizard, select **Invite team members** under **Need an admin?**. The invited person receives an email that brings them to the same setup page, and they continue from the current step.

## Complete the setup wizard

When you first sign in, the setup wizard opens. Your progress saves automatically, so you can leave and pick up where you left off.

<Steps>
  1. **Connect chat.** Connect Slack or Microsoft Teams. Promptless uses chat for notifications and for documentation requests that start in a conversation. If you use neither, book a setup call from this step.

     If your Slack workspace requires admin approval, the wizard shows a pending Slack card while you wait. After an admin approves, select **Continue in Slack** on the card to finish connecting. See [Connect Slack](/docs/for-docs/connect/triggers/slack-messages#connect-slack).

  2. **Connect docs.** Install the Promptless GitHub App or connect GitLab, then pick the repositories where your documentation lives. Each repository you pick becomes a doc collection, and you can add more doc collections at any time. You must complete this step to finish setup.

  3. **Connect triggers.** Optional. Connect the code providers whose changes should start documentation updates: GitHub or GitLab. If you skip this step, connect the provider before you add or change its triggers. See [Connect a provider before you add its triggers](/docs/for-docs/connect/triggers#connect-a-provider-before-you-add-its-triggers).

  4. **Connect context.** Optional. Connect Atlassian (Jira and Confluence), Linear, or Notion to give Promptless more context for its suggestions.

  5. **Review set-up.** Check the connection summary, then select **Finish setup**. Optional: book a setup review call so the Promptless team can help tune your configuration.
</Steps>

## Review what Promptless set up

When you finish the wizard, Promptless indexes your docs repository to learn its structure and content. Indexing takes 5–30 minutes, depending on the size of your docs.

Promptless also writes a `promptless.yaml` configuration from the integrations you connected:

| Integration you connected                                | What Promptless adds                                                                                           |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| GitHub or GitLab                                         | A pull request or merge request trigger with `repos: all`, so Promptless listens across all your repositories. |
| Jira, Confluence, Linear, Notion, Google Drive, or Slite | An unscoped context source, so Promptless can use all the data the integration reaches.                        |

Promptless doesn't add commit triggers automatically. From then on, Promptless listens for trigger events from these sources, gathers context, and drafts documentation suggestions for your review.

To narrow or extend this configuration:

<Steps>
  1. Open the [Configuration page](https://app.gopromptless.ai/configuration).
  2. Edit your triggers and context sources, for example to limit a trigger to specific repositories or to add a [commit trigger](/docs/for-docs/connect/triggers/github-commits).
  3. Save the configuration.
</Steps>
