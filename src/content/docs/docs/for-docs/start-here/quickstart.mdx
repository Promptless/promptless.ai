## Overview

This quickstart gets Promptless drafting documentation updates for your team. You create an account, then work through a five-step setup wizard. The wizard connects your chat tool, your docs repository, the code providers whose changes start documentation work, and the tools that hold product context. When you finish, Promptless indexes your docs and starts watching for changes.

Connecting your docs repository is the only step you must complete. You can connect everything else later.

## Before you start

- A Promptless account. Sign up for a free account at [accounts.gopromptless.ai](https://accounts.gopromptless.ai).
- Admin access to the tools you plan to connect, depending on your organization's settings:

  | Integration         | Access you need                                                           |
  | ------------------- | ------------------------------------------------------------------------- |
  | Slack               | Workspace admin permissions to install the Promptless app                 |
  | GitHub              | Organization admin, or enough repository access to install the GitHub App |
  | Jira and Confluence | Atlassian admin permissions to authorize the OAuth connection             |
  | Linear              | Workspace admin permissions to connect the integration                    |

If you don't have the access an integration needs, invite a teammate who does. In the wizard, select **Invite team members** under **Need an admin?**. The invited person receives an email that brings them to the same setup page, and they continue from the current step.

## Choose what to set up

When you first sign in, choose what you want to set up:

- **Docs**: Keep your documentation up to date. You continue to the guided setup wizard.
- **Agent Instructions**: Improve the instructions your AI agents follow. You book a guided setup call with the Promptless team, who help connect your instructions and agree on pricing with you.
- **Both**: Start with Docs setup in the wizard. The Promptless team follows up about Agent Instructions.

You need to be an organization admin to make this choice. To change it before you finish setup, select **Change product choice** on the Agent Instructions setup page.

## Complete the setup wizard

If you chose Docs or Both, the setup wizard opens next. Your progress saves automatically, so you can leave and pick up where you left off.

<Steps>
  1. **Connect chat.** Connect Slack or Microsoft Teams. Promptless uses chat for notifications and for documentation requests that start in a conversation. If you use neither, book a setup call from this step.

     If your Slack workspace requires admin approval, the wizard shows a pending Slack card while you wait. After an admin approves, select **Continue in Slack** on the card to finish connecting. See [Connect Slack](/docs/for-docs/connect/triggers/slack-messages#connect-slack).

  2. **Connect docs.** Install the Promptless GitHub App or connect GitLab, then pick the repositories where your documentation lives. Each repository you pick becomes a doc collection, and you can add more doc collections at any time. You must complete this step to finish setup.

  3. **Connect triggers.** Optional. Connect the code providers whose changes should start documentation updates: GitHub or GitLab. If you skip this step, connect the provider before you add or change its triggers. See [Connect a provider before you add its triggers](/docs/for-docs/connect/triggers#connect-a-provider-before-you-add-its-triggers).

  4. **Connect context.** Optional. Connect Atlassian (Jira and Confluence), Linear, or Notion to give Promptless more context for its suggestions.

  5. **Review set-up.** Check the connection summary, review your recommended plan and check out, then select **Finish setup**. See [Choose a plan and check out](#choose-a-plan-and-check-out). Optional: book a setup review call so the Promptless team can help tune your configuration.
</Steps>

## Choose a plan and check out

On the **Review set-up** step, Promptless measures the documentation you connected and recommends a Docs plan. It counts roughly every 400 words as one page, so the page count can differ from the number of files in your repository. The step shows the page count and the recommended plan.

- **Startup**: Select **Continue to secure checkout** and add a card in Stripe. The plan includes 14 days free, then $500/month. Cancel before the free period ends to avoid a charge.
- **Growth or Enterprise**: Select **Book a plan and setup call**. The Promptless team confirms your quote and helps you finish setup on the call.

Connected integrations can also determine the plan. Some integrations require Growth or above, even for a small documentation set. See [Pricing](https://promptless.ai/pricing) for what each plan includes.

**Finish setup** becomes available after Promptless confirms your checkout, which usually takes a few seconds. If you selected **Both**, this checkout covers Docs only. The Promptless team arranges Agent Instructions pricing with you separately.

## Review what Promptless set up

When you finish the wizard, Promptless indexes your docs repository to learn its structure and content. Indexing takes 5–30 minutes, depending on the size of your docs.

Promptless also writes a `promptless.yaml` configuration from the integrations you connected:

| Integration you connected                                | What Promptless adds                                                                                           |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| GitHub or GitLab                                         | A pull request or merge request trigger with `repos: all`, so Promptless listens across all your repositories. |
| Jira, Confluence, Linear, Notion, Google Drive, or Slite | An unscoped context source, so Promptless can use all the data the integration reaches.                        |

Promptless doesn't add commit triggers automatically. From then on, Promptless listens for trigger events from these sources, gathers context, and drafts documentation suggestions for your review.

To narrow or extend this configuration:

<Steps>
  1. Open the [Configuration page](https://app.gopromptless.ai/configuration).

  2. Edit your triggers and context sources, for example to limit a trigger to specific repositories or to add a [commit trigger](/docs/for-docs/connect/triggers/github-commits).

  3. Save the configuration.
</Steps>

## Redeem the Promptless YC deal

Y Combinator companies can redeem the Promptless deal for Docs and Agent Instructions. The deal includes:

- 90 days free, shared by both products
- White-glove onboarding and access to the Promptless founders in Slack
- 30% off your first 12 paid months, then standard pricing. On the Startup plan, that's $350/month for 12 months, then $500/month.

The deal is for new customers only. Organizations with existing paid terms keep them.

After you redeem the deal, Promptless emails you a welcome message with a signup link. It also invites you through Slack Connect to a shared channel with the Promptless team. Cofounders at the same company share one benefit and one channel.

To claim the benefit:

<Steps>
  1. Go to [app.gopromptless.ai/yc](https://app.gopromptless.ai/yc).

  2. Sign up or log in with your Bookface email or the work email you gave YC. To use a different address, open the **Get started** link in your welcome email instead. The link works once and expires after 30 days.

  3. If you belong to more than one organization, choose the one that should receive the benefit. The benefit attaches to one organization and can't be moved. You need admin access to the organization and a verified email address.

  4. Wait while Promptless confirms your benefit. It then opens the product choice, where you choose Docs, Agent Instructions, or Both.
</Steps>

Promptless might not match your email to a redemption. In that case, open the **Get started** link in your welcome email, or log in with your Bookface or work email. To set up Promptless without the deal, select **Continue without the benefit**.

If you choose Docs or Both, the **Review set-up** step applies your 90-day free period and discount to the recommended plan.
