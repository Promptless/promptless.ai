## Overview

Connect Google Drive as a context source so Promptless reuses the specs, numbers, and rationale your team keeps in Google Docs, Sheets, and Slides. While Promptless drafts a suggestion, it can:

- Search files by name and full text across My Drive and shared drives.
- Read a file's content: Google Docs as Markdown, Sheets as CSV, and Slides as plain text.
- Resolve Google Drive and Google Docs URLs that a trigger references. When a linked file isn't accessible to the connected account but is publicly shared, Promptless reads it as a public web page.

Promptless reads only the files the connected Google account can read, and you can narrow that further. See [Connect Google Drive](#connect-google-drive) and [Limit Promptless to specific shared drives or folders](#limit-promptless-to-specific-shared-drives-or-folders).

Google Drive access is read-only. Promptless connects with read-only Drive scopes and never creates, updates, or deletes files. It queries Drive in real time when a documentation task needs it, and doesn't store your Drive content. It caches results briefly during a documentation session, then discards them.

### Example

A developer merges a GitHub PR that lowers the default API rate limit from 1,000 to 600 requests per minute. A code comment in the PR links to the "Rate Limiting v2" design doc in Google Docs. Promptless resolves the linked doc and reads the rollout thresholds and the reasoning behind the new limit. Its update to the rate-limit reference page reuses those exact numbers and that rationale.

- An admin role in your Promptless organization, to connect Google Drive and edit the [Configuration page](https://app.gopromptless.ai/configuration).

## Connect Google Drive

The Google account that authorizes the connection decides what Promptless can read. For least-privilege access, connect through a dedicated Google account that acts as a service account for Promptless. Promptless then reads only what you share with that account.

<Steps>
  1. Optional. Create a dedicated Google account for Promptless.
  2. Optional. Share with the dedicated account only the shared drives and folders you want Promptless to read.
  3. On the [Integrations page](https://app.gopromptless.ai/integrations), select **Connect Google Drive**.
  4. In Google, authorize read-only access with the account you want Promptless to use.
  5. On the Google Drive card, check that the header names the account you intended, with its email address under its name. If the header shows no account, select **Check access** on the card, or reconnect the integration.
  6. Check that the card lists only the shared drives and folders you expect Promptless to read.
</Steps>

## Limit Promptless to specific shared drives or folders

Promptless can read everything the connected account can access. To point Promptless at specific shared drives or folders, scope the Google Drive context source. For example, scope it to your product team's shared drive or a folder of current-quarter specs:

<Steps>
  1. On the **Context sources** tab of the [Configuration page](https://app.gopromptless.ai/configuration), expand the Google Drive source. If it isn't listed, select **Add a context source**, and then select **Google Drive**.
  2. In **Which Google Drive shared drives should Promptless read?**, add each shared drive.
  3. Optional. In **Specific folders (optional)**, add individual folders.
  4. Select **Save changes**. For a new source, select **Add context source**.
</Steps>

In YAML, the scope is the `drive_ids` and `folder_ids` lists on an entry with `source_type: google_drive`. An entry's key uses hyphens, such as `google-drive`:

```yaml
context_sources:
  google-drive:
    source_type: google_drive
    drive_ids:
      - 0AExampleDriveIdUk9PVA
    folder_ids:
      - 1BExampleFolderIdXyZ
```

An entry with no drive or folder IDs, or no entry, gives Promptless everything the connected account can read. For every context source field, see the [Configuration Reference](/docs/for-docs/reference/configuration-reference#context-sources).
