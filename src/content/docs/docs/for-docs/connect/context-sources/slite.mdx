## Overview

Connect Slite as a context source so Promptless reuses the feature names, limits, and rationale your team settled in its Slite notes and PRDs. While Promptless drafts a suggestion, it can:

- Search your Slite workspace for related notes.
- Read a note as Markdown.
- Resolve Slite note URLs that a trigger references.

Slite connects with an API key, which grants read access to every note the account that created the key can see. Slite has no scope settings in Promptless, so Promptless reads that whole set of notes while Slite is connected. To limit what Promptless can read, create the key from a dedicated service account that can see only the notes Promptless needs.

Slite access is read-only. Promptless queries Slite in real time when a documentation task needs it, and doesn't store your Slite content. It caches results briefly during a documentation session, then discards them. It never creates, updates, or deletes notes.

### Example

A developer merges a GitHub PR that adds a configurable retry limit to your webhook delivery system. The feature was scoped in a PRD in your Slite workspace. The PRD names the feature ("Delivery Retry Policy") and sets the default and maximum retry counts, with the reasoning behind the cap.

When Promptless picks up the merged PR, it resolves any Slite URLs in the PR description and searches your workspace for related notes. Its suggestion uses the PRD's feature name, retry limits, and rationale, so the docs match the spec your product and engineering teams wrote.

## Before you start

- An admin role in your Promptless organization, to connect Slite.
- A Slite account that can create an API key. Recommended: a dedicated service account, so you can revoke its key independently.

## Connect Slite

1. In Slite, under **Settings > API**, create a new API key.
2. On the [Integrations page](https://app.gopromptless.ai/integrations), select **Connect Slite**.
3. In **API Key**, paste the key.
4. Select **Connect**.

The Slite card then shows the account that created the key and the first characters of the key.
