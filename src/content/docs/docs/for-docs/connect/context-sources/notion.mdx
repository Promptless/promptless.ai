## Overview

Connect Notion as a context source so Promptless uses the names and rules your team settled in its Notion specs, PRDs, and databases. Through the connection, Promptless reads only the pages and databases you share with it. Within them, Promptless can:

- Search pages and databases by keyword.
- Read a page as Markdown.
- Query a database's rows, such as entries in a product roadmap or feature-spec database.
- Resolve Notion URLs that a trigger references. When a linked page isn't shared with the connection but is public, Promptless reads it as a public web page.

Notion access is read-only. Promptless queries Notion in real time when a documentation task needs it, and doesn't store your Notion content. It never creates, updates, or deletes pages or databases.

### Example

A developer merges a GitHub PR that adds role-based permissions to your workspace settings. The feature was specced in an entry in your "Product Specs" database in Notion. The entry defines the official role names ("Owner," "Editor," and "Viewer"), the permissions each role grants, and who can change another member's role.

When Promptless picks up the merged PR, it resolves the Notion page URL in the PR description. It then queries the Product Specs database for the matching entry. Its suggestion uses the spec's role names, permission matrix, and constraints, so the docs match what your product team defined.

## Before you start

- An admin role in your Promptless organization, to connect Notion and edit the [Configuration page](https://app.gopromptless.ai/configuration).

## Connect Notion

Skip this section if Notion is already connected on the [Integrations page](https://app.gopromptless.ai/integrations).

<Steps>
  1. On the [Integrations page](https://app.gopromptless.ai/integrations), select **Connect Notion**.
  2. In Notion, authorize Promptless to access your workspace.
  3. Select the pages and data sources Promptless can read.
  4. On the Integrations page, confirm that the Notion card lists your workspace.
</Steps>

To change which pages Promptless can read later, select **Add or remove pages on Notion** in the workspace picker. The link opens Notion, where you update your sharing selections.

## Limit Promptless to specific databases or pages

Promptless can read every page and database shared with the Notion connection. To keep it to specific databases or pages, scope the Notion context source:

<Steps>
  1. On the **Context sources** tab of the [Configuration page](https://app.gopromptless.ai/configuration), expand the Notion source. If it isn't listed, select **Add a context source**, and then select **Notion**.
  2. In **Which Notion databases should Promptless read?**, add each database.
  3. Optional. In **Specific Notion pages (optional)**, add individual pages.
  4. Select **Save changes**. For a new source, select **Add context source**.
</Steps>

In YAML, the scope is the `database_ids` and `page_ids` lists on a `notion` entry:

```yaml
context_sources:
  notion:
    source_type: notion
    database_ids:
      - abc123def456
    page_ids:
      - xyz789ghi012
```

An entry with no database or page IDs, or no entry, gives Promptless everything shared with the connection. For every context source field, see the [Configuration Reference](/docs/for-docs/reference/configuration-reference#context-sources).
