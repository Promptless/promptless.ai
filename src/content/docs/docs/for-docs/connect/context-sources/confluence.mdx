## Overview

Connect Confluence as a context source so Promptless writes new documentation with the conventions, terminology, and decisions your team already recorded there. While Promptless drafts a suggestion, it searches your Confluence spaces and reads the pages that match, such as:

- Documentation standards for style, terminology, and page structure
- Technical specifications, design decisions, and architecture notes
- Internal processes and guidelines

Confluence access is read-only. Promptless queries Confluence in real time when a documentation task needs it, and doesn't store your Confluence content. It never creates, updates, or deletes pages.

### Example

A developer merges a GitHub PR that adds a `/v2/exports` endpoint to your public API. Your team keeps its API conventions on an "API Guidelines" page in Confluence. That page mandates cursor-based pagination, the `limit` and `starting_after` parameter names, and a standard error-envelope format.

When Promptless picks up the merged PR, it searches your Confluence spaces and reads the API Guidelines page. Its suggestion documents the endpoint's pagination and errors the way every other endpoint in your API reference does. It uses the same parameter names, envelope shape, and structure.

## Connect Confluence

Promptless connects to Confluence through Atlassian. Skip this section if Atlassian is already connected on the [Integrations page](https://app.gopromptless.ai/integrations).

<AtlassianConnect />

If Confluence searches later fail with a `401 Unauthorized` scope error, the connection is missing the Confluence search scopes. Reconnect Atlassian to grant them. See [Permissions required](/docs/for-docs/reference/integrations/atlassian#permissions-required).

## Limit Promptless to specific spaces

Promptless can search every space the connected Atlassian account can see. To keep it to the spaces that hold relevant material, scope the Confluence context source:

<Steps>
  1. On the **Context sources** tab of the [Configuration page](https://app.gopromptless.ai/configuration), expand the Confluence source. If it isn't listed, select **Add a context source**, and then select **Confluence**.

  2. In **Which Confluence spaces should Promptless read?**, add the key of each space.

  3. Select **Save changes**. For a new source, select **Add context source**.
</Steps>

In YAML, the scope is the `space_keys` list on a `confluence` entry:

```yaml
context_sources:
  confluence:
    source_type: confluence
    space_keys:
      - ENGINEERING
      - PRODUCT
```

An entry with no space keys, or no entry, gives Promptless every space the account can see. For every context source field, see the [Configuration Reference](/docs/for-docs/reference/configuration-reference#context-sources).
