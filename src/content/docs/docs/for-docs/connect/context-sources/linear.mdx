## Overview

Connect Linear as a context source so Promptless documents the intent behind a code change, which usually lives on the Linear issue for that work. Promptless reads Linear in two ways:

- When a GitHub PR mentions a Linear issue, Promptless reads that issue.
- Promptless searches Linear for related issues and projects to understand a feature's requirements.

Linear access is read-only. Promptless queries Linear in real time when a documentation task needs it, and doesn't store your Linear data. It never creates, updates, or deletes issues.

### Example

A developer merges a GitHub PR that links to `ENG-238`, the Linear issue for a new scheduled-reports feature. The issue records what the diff doesn't show. Reports run daily or weekly and post to a Slack channel. Only workspaces on the Business plan can use them.

When Promptless picks up the merged PR, it reads `ENG-238` and searches Linear for related issues in the same project. Its suggestion covers the scheduling options, the Slack delivery, and the plan requirement, so the docs explain what users can do and who has access.

## Limit Promptless to specific teams

Promptless can read every team in the connected Linear workspace. To keep it to the teams that hold relevant work, scope the Linear context source:

<Steps>
  1. On the **Context sources** tab of the [Configuration page](https://app.gopromptless.ai/configuration), expand the Linear source. If it isn't listed, select **Add a context source**, and then select **Linear**.

  2. In **Which Linear teams should Promptless read?**, add the key of each team.

  3. Select **Save changes**. For a new source, select **Add context source**.
</Steps>

In YAML, the scope is the `team_keys` list on a `linear` entry:

```yaml
context_sources:
  linear:
    source_type: linear
    team_keys:
      - engineering
      - product
```

An entry with no team keys, or no entry, gives Promptless the whole workspace. For every context source field, see the [Configuration Reference](/docs/for-docs/reference/configuration-reference#context-sources).
