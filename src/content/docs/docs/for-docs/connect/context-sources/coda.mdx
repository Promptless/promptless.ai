## Overview

Connect Coda as a context source so Promptless reuses the feature names, limits, and rationale your team wrote in its Coda docs. While Promptless drafts a suggestion, it can:

- Find a Coda doc by its name. Search matches doc names, not the body text of pages.
- Read the pages of a matched doc, with their product specs, internal notes, and reference material.

<Aside type="tip">
  Because search matches on the name, give each Coda doc a title that names the feature or subject it covers. If a suggestion misses a Coda doc you expected, check that the doc's title matches the feature name.
</Aside>

Promptless reads Coda pages as plain text, so it captures the words but not link targets, inline formatting, or tables.

Coda access is read-only. Promptless queries Coda in real time when a documentation task needs it, and doesn't store your Coda content. It caches results briefly to improve performance and refreshes them when your Coda content changes. It never creates, updates, or deletes Coda content.

### Example

A developer merges a GitHub PR that adds a configurable batch size to your data export pipeline. The feature was documented in a Coda doc named "Bulk Export Design." That doc holds the official feature name ("Bulk Export Batching"), the default and maximum batch sizes, and the reasoning behind the cap.

When Promptless picks up the merged PR, it searches your Coda docs by name and finds "Bulk Export Design." Its suggestion reuses the doc's feature name, the default batch size of 500, the 2,000-row maximum, and the rationale your team recorded. The docs then match the spec your product and engineering teams wrote.

## Before you start

- A Coda account that can access the docs you want Promptless to read. Recommended: a dedicated service account, a Coda account you control and use only for integrations, so Promptless gets least-privilege access. Add the service account as a collaborator on those docs, or on the workspace.

## Connect Coda

Coda connects with a personal API token. The token inherits the Coda access of the account that created it.

<Steps>
  1. In Coda, under **Account Settings > API Settings**, generate a personal API token. You can restrict the token to specific docs. See [Coda's API documentation](https://coda.io/developers/apis/v1).

  2. On the [Integrations page](https://app.gopromptless.ai/integrations), select **Connect** on the Coda card.

  3. Paste the token, and then select **Connect**. Promptless validates the token when you connect.
</Steps>

The Coda card then shows the connection status. If the connection later breaks, for example because the token was revoked in Coda, see [Connection health](/docs/for-docs/connect/connection-health).

## Limit Promptless to specific docs

Promptless reads every Coda doc the connected token can access. To point Promptless at specific docs, add their IDs to the `doc_ids` list on the entry with `source_type: coda` in your `promptless.yaml`:

```yaml
context_sources:
  coda:
    source_type: coda
    doc_ids:
      - AbCdEfGhIj
```

An entry with no doc IDs, or no entry, gives Promptless every doc the token can access. For every context source field, see the [Configuration Reference](/docs/for-docs/reference/configuration-reference#context-sources).
