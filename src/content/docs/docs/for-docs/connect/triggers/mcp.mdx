## Overview

Ask for documentation updates from the AI editor you already work in. When you finish a code change in Claude Code or Cursor, ask Promptless to document it. Your editor follows the task in the same conversation and reports the outcome and the docs pull request link. You review and approve the change.

[MCP](https://modelcontextprotocol.io) (Model Context Protocol) is the open protocol that AI editors use to connect to tools. The Promptless MCP server needs no API key and no `promptless.yaml` entry. Connect your editor, approve the connection once in the browser, and run a test prompt to confirm the connection.

To start tasks from CI or a script, use the [API trigger](/docs/for-docs/connect/triggers/api). To connect a chat app, see [Use Promptless from Claude](/docs/for-docs/work-the-queue/claude) or [Use Promptless from ChatGPT](/docs/for-docs/work-the-queue/chatgpt).

## Before you start

- An MCP client that supports HTTP transport and OAuth, such as Claude Code, Cursor, VS Code, or Codex CLI.
- Your organization's [Promptless setup](https://app.gopromptless.ai/configuration) finished.
- An active membership in the organization. Any member can connect, whatever their [organization role](/docs/for-docs/security/access-and-permissions).

## Connect the server

Every editor connects to the same server URL, `https://api.gopromptless.ai/mcp`. Follow the steps for your editor, then [authorize in the browser](#authorize-in-the-browser). The dashboard also shows the URL and the Claude Code command under **Settings** > **Editor connection (MCP)**.

### Claude Code

<Steps>
  1. In a terminal, add the `promptless` server:

     ```bash
     claude mcp add --transport http promptless https://api.gopromptless.ai/mcp
     ```

  2. In Claude Code, run `/mcp` and select **promptless**. A browser tab opens to the consent page.
</Steps>

### Cursor

<Steps>
  1. Add the `promptless` server to `mcp.json`. The `url` key tells Cursor to use HTTP transport.

     ```json
     {
       "mcpServers": {
         "promptless": {
           "url": "https://api.gopromptless.ai/mcp"
         }
       }
     }
     ```

     Or select [Add to Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=promptless\&config=eyJ0eXBlIjoiaHR0cCIsInVybCI6Imh0dHBzOi8vYXBpLmdvcHJvbXB0bGVzcy5haS9tY3AifQ%3D%3D) to add the same server in one step.

  2. In Cursor's MCP settings, select **Needs login** next to **promptless**. A browser tab opens to the consent page.
</Steps>

### VS Code

<Steps>
  1. In a terminal, add the `promptless` server:

     ```bash
     code --add-mcp "{\"name\":\"promptless\",\"type\":\"http\",\"url\":\"https://api.gopromptless.ai/mcp\"}"
     ```

  2. In the Command Palette, run **MCP: List Servers** and start **promptless**. A browser tab opens to the consent page.
</Steps>

### Codex CLI

<Steps>
  1. In a terminal, add the `promptless` server. Codex infers HTTP transport from the `--url` flag.

     ```bash
     codex mcp add promptless --url https://api.gopromptless.ai/mcp
     ```

  2. Start authorization:

     ```bash
     codex mcp login promptless
     ```

     A browser tab opens to the consent page.
</Steps>

### Other MCP clients

Add an HTTP server named `promptless` with the URL `https://api.gopromptless.ai/mcp`, then start the client's OAuth login. The exact steps vary by client.

## Authorize in the browser

Every editor uses the same consent page. Approve the connection there once.

<Steps>
  1. On the consent page, choose the Promptless organization to connect. The picker selects your active organization by default.

  2. Check the **Returns to** row. It shows where Promptless sends access when you approve. Promptless doesn't verify the client name, so go by this row. A local editor such as Claude Code or Cursor returns to a local address with a port, like `127.0.0.1:54321`. An app that opens through its own link scheme shows a callback like `myapp://claude.ai/cb`, and any app on your device that handles `myapp://` links receives the access. Cancel if you didn't start this connection from that editor or app.

  3. Select **Authorize as \{your email}**. Your editor stores the token, and the tab returns you to the editor.
</Steps>

The connection acts with your access in the organization you chose. It can read any task and change any suggestion in that organization. A connection covers one organization. To connect another organization, authorize again and choose that organization.

## Test the connection

Right after you approve, confirm that the editor reaches the right organization. Enter this prompt in your editor:

```text
Which documentation repositories is Promptless connected to?
```

The editor calls `list_doc_collections`, a read-only tool, and lists the doc collections of the organization you chose by name, such as `acme/docs`. If the editor asks to approve the call, approve it. The connection works when you see your organization's documentation repositories.

If the list is empty or shows repositories you don't recognize, you chose the wrong organization on the consent page. To check which organization is connected, enter `Which Promptless organization am I connected to?` To switch, remove the `promptless` server from your editor. Then add it again with the steps for your editor, and choose the correct organization.

## Ask your editor

Ask in plain language, and your editor picks the tools. For example:

- "Document the new authentication flow in the API docs collection."
- "Triage my open Promptless suggestions, label the P0s, and close anything we've decided against."

Your editor can auto-approve the read-only tools. Tools that start or change work ask before they run. For what each tool does and which tools are read-only, see the [MCP tools reference](/docs/for-docs/reference/mcp-tools).

## Answer a clarifying question

A task can finish by asking you one clarifying question. If your editor supports MCP forms (elicitation), it shows a **Your answer** field. Otherwise, reply in the same conversation. Promptless continues the work in a new task that carries your request and your answer, and your editor follows that task too.

## Workflow skills

Promptless also offers skills, step-by-step guidance for workflows that chain several tools, such as backlog triage. Skills reach your editor over the draft MCP Skills extension (SEP-2640), which many clients don't support yet. A client without it calls the same tools directly.

## See your MCP tasks in the dashboard

On the [Triggers page](https://app.gopromptless.ai/triggers), a task started over MCP shows an **MCP Task** pill with a byline reading `<client name> · submitted by @<username>`. Tasks submitted with an `sk-pl-` API key show an **API Task** pill.

To find MCP-originated suggestions on the [Suggestions list](https://app.gopromptless.ai/suggestions), set the **Trigger source** filter to "API". That filter includes both MCP and API-key submissions.

## Manage and revoke your connection

A connection lasts 90 days from approval, and your editor refreshes its access automatically until then. After 90 days, authorize in the browser again.

To revoke a connection, remove the `promptless` server from your editor. The dashboard's **Editor connection (MCP)** section shows setup instructions only. Promptless also revokes the connection if you lose active membership in the organization. Each member manages their own connection, and an admin can't revoke another member's connection.

## Troubleshooting

- **The consent tab doesn't open, or consent was denied, canceled, or expired**: Repeat the last step for your editor under [Connect the server](#connect-the-server).
- **No promptless entry under `/mcp` in Claude Code**: Confirm that the `claude mcp add` command ran, then restart Claude Code.
- **Cursor's Needs login button doesn't respond**: Remove the `promptless` server and add it again.
- **The organization is not in the picker**: You aren't an active member of that organization. Ask an admin of the Promptless organization to invite you.
- **A tool you expect is missing**: Your editor loads the tool list when it connects. Reconnect the `promptless` server or start a new conversation.

For an error a tool returns, such as `task_finished` or `stale_head`, see [Tool errors](/docs/for-docs/reference/mcp-tools#tool-errors).
