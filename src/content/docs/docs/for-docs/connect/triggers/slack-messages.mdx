## Overview

Turn Slack conversations into documentation suggestions. Support threads and internal discussions often raise questions your documentation should answer, and Promptless starts the update from the thread where the question came up. It reads the entire thread, including text, images, and file attachments, and creates documentation suggestions based on the conversation.

Start Promptless in one of these ways:

| Method                    | What you do                                                                                                | Configuration needed                                                                                 |
| ------------------------- | ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Message action            | Run the Promptless **Update Docs** message shortcut on any message, without interrupting the conversation. | None                                                                                                 |
| Mention in a channel      | Tag @Promptless in a thread with instructions or questions. Promptless reads the full thread.              | None                                                                                                 |
| Direct message            | Send a request to @Promptless in a DM, for documentation requests you want to keep private.                | None                                                                                                 |
| Passive channel listening | Nothing per message. Promptless responds to conversations in channels you select.                          | A `slack_listen` trigger. See [Set up passive channel listening](#set-up-passive-channel-listening). |

Promptless reads only the Slack content you point it to:

| How Promptless is triggered                                 | What it reads                                      |
| ----------------------------------------------------------- | -------------------------------------------------- |
| @mention, direct message, or **Update Docs** message action | The thread or conversation where you triggered it. |
| Passive channel listening                                   | Messages in the channels you selected.             |

With no passive listening configured, Promptless reads Slack only when someone triggers it.

<Aside type="tip">
  You can also ask Promptless in Slack or Microsoft Teams to set up passive listening for you. For example, "@Promptless passively listen to my #support and #docs-feedback channels." See [Ask Promptless to update your configuration](/docs/for-docs/get-the-most-out/ask-promptless-to-update-config).
</Aside>

## Request documentation from a Slack thread

<Steps>
  1. In the thread, run the **Update Docs** message shortcut on a message, or tag @Promptless with your instructions. To keep the request private, send it to @Promptless in a direct message.

  2. Optional. To refine the suggestion, reply in the same thread with feedback or more context.
</Steps>

### Include images and files

Promptless reads the images and files in a thread you trigger it from, and decides whether each one adds useful context for the documentation:

| Attachment          | What Promptless does when it's relevant                                                                      |
| ------------------- | ------------------------------------------------------------------------------------------------------------ |
| Image               | Uploads it to a secure S3 bucket, formats it for your documentation platform, and adds it to the suggestion. |
| File, including PDF | Extracts the relevant content, including images inside PDFs, and uses it in the suggestion.                  |

When you review the suggestion in the Promptless app, approve or reject each added image at the bottom of the review interface.

## Reply in a thread Promptless is in

After Promptless posts in a thread or is @mentioned there, each later reply is a follow-on trigger. No new @mention is needed. Reply with feedback or more context, continue a conversation Promptless started, or send the images, files, or clarifications it asked for.

Promptless decides whether each reply is actionable, so not every reply starts a documentation update. To have Promptless ignore one message, start it with `aside` or `/aside`:

```text
aside This is an internal discussion point, not for docs.
```

### Change the thread reply trigger mode

The organization-wide thread reply trigger mode sets which replies Promptless processes:

| Mode                            | Promptless processes                                                                                 |
| ------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Listen to all replies (default) | Every reply in threads where it's participating, except replies that start with `aside` or `/aside`. |
| Require @promptless             | Only replies that @mention Promptless.                                                               |

To change the mode, open **Settings**, select **Organization**, and choose a mode. The setting applies to all Slack threads in your organization.

## Set up passive channel listening

With passive listening, Promptless monitors the channels you select and creates documentation suggestions as messages are posted. It's opt-in and applies only to the channels you list.

<Steps>
  1. Optional. For a private channel, or a channel shared with another workspace through Slack Connect, add Promptless to the channel in Slack. Promptless joins public channels on its own when you configure them.

  2. On the [Configuration page](https://app.gopromptless.ai/configuration), switch to **YAML** mode.

  3. In the `triggers` section, add a `slack_listen` trigger that lists the channels, without the `#` prefix:

     ```yaml
     triggers:
       support-channels:
         trigger_type: slack_listen
         match:
           - channels:
               - customer-support
               - product-questions
     ```

  4. Save the configuration.
</Steps>

When a Slack channel is renamed, Promptless updates your configuration automatically. See the [Configuration Reference](/docs/for-docs/reference/configuration-reference#triggers) for every option.

By default, Promptless uses its own judgment to decide what to document from a monitored channel. To tailor the output, add instructions to the `PROMPTLESS.md` file in your [Agent KB](https://app.gopromptless.ai/settings/knowledge).
