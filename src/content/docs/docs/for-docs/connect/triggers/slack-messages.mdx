  You can set up this trigger by hand as this page describes, or ask Promptless in Slack or Microsoft Teams to do it for you. For example, "@Promptless passively listen to my #support and #docs-feedback channels." See [Ask Promptless to update your configuration](/docs/for-docs/get-the-most-out/ask-promptless-to-update-config).
</Aside>

Turn Slack conversations into documentation suggestions. Support threads and internal discussions often raise questions your documentation should answer. Promptless starts the update from the thread where the question came up.

## How it works

When you trigger Promptless in Slack, it reads the entire thread, including text, images, and file attachments, and creates documentation suggestions based on the conversation. To refine a suggestion, keep replying in the same thread.

These triggers require the Slack integration. To connect it, see the [Slack integration](/docs/for-docs/reference/integrations/slack) setup guide.

## Trigger methods

| Method                    | What you do                                                                                                | Configuration needed                                                                            |
| ------------------------- | ---------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Message action            | Run the Promptless **Update Docs** message shortcut on any message, without interrupting the conversation. | None                                                                                            |
| Mention in a channel      | Tag @Promptless in a thread with instructions or questions. Promptless reads the full thread.              | None                                                                                            |
| Direct message            | Send a request to @Promptless in a DM, for documentation requests you want to keep private.                | None                                                                                            |
| Passive channel listening | Nothing per message. Promptless responds to conversations in channels you select.                          | A `slack_listen` trigger. See [Passive channel listening](#passive-channel-listening-optional). |

## Images and file attachments

Promptless reads the images and files in a thread you trigger it from, and decides whether each one adds useful context for the documentation:

| Attachment          | What Promptless does when it's relevant                                                                      |
| ------------------- | ------------------------------------------------------------------------------------------------------------ |
| Image               | Uploads it to a secure S3 bucket, formats it for your documentation platform, and adds it to the suggestion. |
| File, including PDF | Extracts the relevant content, including images inside PDFs, and uses it in the suggestion.                  |

When you review the suggestion in the Promptless app, approve or reject each added image at the bottom of the review interface.

## Thread reply auto-listening

After Promptless posts in a thread or is @mentioned there, each later reply is a follow-on trigger. No new @mention is needed. Reply with feedback or more context, continue a conversation Promptless started, or send the images, files, or clarifications it asked for.

Promptless decides whether each reply is actionable, so not every reply starts a documentation update. Choose how it handles replies with the organization-wide thread reply trigger mode:

| Mode                            | Promptless processes                                                                                 |
| ------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Listen to all replies (default) | Every reply in threads where it's participating, except replies that start with `aside` or `/aside`. |
| Require @promptless             | Only replies that @mention Promptless.                                                               |

To have Promptless ignore one message, start it with `aside` or `/aside`:

```text
aside This is an internal discussion point, not for docs.
```

### Thread reply trigger mode

To change the mode, open **Settings** and select **Organization**. The setting applies to all Slack threads in your organization.

## Passive channel listening (optional)

With passive listening, Promptless monitors the channels you select and creates documentation suggestions as messages are posted. It's opt-in and applies only to the channels you list. Whether Promptless can join a channel on its own depends on the channel type:

| Channel type                                                | What you do                                                  |
| ----------------------------------------------------------- | ------------------------------------------------------------ |
| Public channel                                              | Nothing. Promptless joins the channel when you configure it. |
| Private channel                                             | Add Promptless to the channel in Slack.                      |
| Channel shared with another workspace through Slack Connect | Add Promptless to the channel in Slack.                      |

<Aside type="note">
  Adding, renaming, or modifying a Slack trigger requires the Slack integration to be connected first. See [Connect a provider before you add its triggers](/docs/for-docs/connect/triggers#connect-a-provider-before-you-add-its-triggers).
</Aside>

To turn it on, add a `slack_listen` trigger in the `triggers` section of your [Configuration page](https://app.gopromptless.ai/configuration):

```yaml
triggers:
  support-channels:
    trigger_type: slack_listen
    match:
      - channels:
          - customer-support
          - product-questions
```

Write channel names without the `#` prefix. When a Slack channel is renamed, Promptless updates your configuration automatically. See the [Configuration Reference](/docs/for-docs/reference/configuration-reference#triggers) for every option.

<Aside type="tip" title="Customize what Promptless documents">
  By default, Promptless uses its own judgment to decide what to document from a monitored channel. To tailor the output, add instructions to the `PROMPTLESS.md` file in your [Agent KB](https://app.gopromptless.ai/settings/knowledge).
</Aside>

## Privacy and channel access

Promptless reads only the Slack content you point it to:

| How Promptless is triggered                                 | What it reads                                      |
| ----------------------------------------------------------- | -------------------------------------------------- |
| @mention, direct message, or **Update Docs** message action | The thread or conversation where you triggered it. |
| Passive channel listening                                   | Messages in the channels you selected.             |

By default, with no passive listening configured, Promptless reads Slack only when someone triggers it.
