Add Promptless to the Claude.ai or ChatGPT web app as a custom connector, so you can work with Promptless from a chat conversation. Once connected, ask in plain language to start a documentation task and follow it to its docs pull request. You can also check on recent tasks, search and read your docs, and review or revise a suggestion. This page covers setup in each app, the sign-in you approve, and a short test to confirm the connection works.

Promptless connects to these apps over [MCP](https://modelcontextprotocol.io) (Model Context Protocol), the open protocol chat apps and editors use to reach external tools. To connect an editor such as Claude Code or Cursor, see [MCP triggers](/docs/for-docs/connect/triggers/mcp), which is also the full reference for every tool.

## Use the chat app server URL

Chat apps connect at this URL:

```txt
https://api.gopromptless.ai/mcp/with-direct-edits
```

A chat app has no local copy of your docs repository. This URL gives it the task and suggestion tools that editors use at `https://api.gopromptless.ai/mcp`. It adds tools to search, read, and edit your documentation directly. Both URLs use the same sign-in and the same organization-wide access.

<Aside type="note" title="Before you start">
  - A Promptless organization that has [finished setting up Promptless](https://app.gopromptless.ai/configuration). Any active member can connect. No API key is needed.
  - For Claude.ai: any plan. The Free plan allows one custom connector. On a Team or Enterprise plan, an Owner adds the connector for the organization first.
  - For ChatGPT: a paid plan with developer mode turned on. On a Business, Enterprise, or Edu workspace, an admin or owner manages developer mode and custom apps.
</Aside>

## Add Promptless to Claude.ai

The steps depend on your plan. Free, Pro, and Max are individual plans. On Team and Enterprise plans, an Owner adds the connector for the organization.

### Individual plans

<Steps>
  1. In Claude.ai, go to **Customize** > **Connectors**.

  2. Select **+**, then select **Add custom connector**.

  3. In the name field, enter `Promptless`.

  4. In the URL field, enter `https://api.gopromptless.ai/mcp/with-direct-edits`. Leave **Advanced settings** empty. Claude registers itself with Promptless automatically, so no OAuth client ID or secret is needed.

  5. Select **Add**.

  6. On the **Promptless** connector, select **Connect**, then approve the connection in the Promptless tab that opens. See [Approve the connection](#approve-the-connection).
</Steps>

Claude is rolling out a two-step version of this dialog. It asks for the name and URL first, then shows authentication options on a second screen. If you see that version, keep the defaults that sign in with OAuth.

### Organization plans

An Owner adds the connector once for the organization. Each member then connects their own Promptless account.

<Steps>
  1. Owner: In Claude.ai, go to **Organization settings** > **Connectors**.

  2. Owner: Select **Add**, point to **Custom**, then select **Web**.

  3. Owner: Enter the URL `https://api.gopromptless.ai/mcp/with-direct-edits`, then select **Add**.

  4. Member: Go to **Customize** > **Connectors** and find the **Promptless** connector, labeled **Custom**.

  5. Member: Select **Connect**, then approve the connection in the Promptless tab that opens. See [Approve the connection](#approve-the-connection).
</Steps>

Each member approves their own connection, so each connection acts with that member's Promptless access. An Owner can also turn off specific tools for the whole organization in **Organization settings** > **Connectors**.

### Turn on Promptless in a conversation

<Steps>
  1. In a chat, select **+** at the lower left of the message box.

  2. Select **Connectors**, then turn on **Promptless**.
</Steps>

The first time Claude calls a Promptless tool, it asks you to approve the call. To change the default for a tool, go to **Customize** > **Connectors**, select **Promptless**, and set each tool to **Ask each time**, **Always allow**, or **Blocked**. Set read-only tools, such as `list_doc_collections` and `get_task_status`, to **Always allow** so routine checks don't prompt you each time. Keep tools that start or change work, such as `submit_documentation_task` and `edit_documentation_file`, on **Ask each time**.

For details on Claude's connector settings, see Anthropic's [custom connectors guide](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).

## Add Promptless to ChatGPT

ChatGPT runs custom MCP servers as apps in developer mode. OpenAI labels developer mode and full MCP support as beta. Depending on your account, ChatGPT shows app settings under **Apps** or under **Plugins**.

Your plan decides which Promptless tools ChatGPT runs:

- Business, Enterprise, and Edu workspaces get full MCP support, including actions that change data, such as submitting a task. Only admins and owners can turn on developer mode and create or publish apps for the workspace. On Enterprise and Edu, an admin can grant developer mode to specific members through role-based access.
- On Plus and Pro, you turn on developer mode yourself. OpenAI documents Pro as limited to read and fetch actions for custom apps, so tools that start or change work, such as `submit_documentation_task`, might not run.
- The Free plan doesn't support custom apps.

<Steps>
  1. In ChatGPT, open **Settings** and turn on **Developer mode**. The toggle is under **Security and login**, or under **Apps** > **Advanced settings** on accounts that still show the earlier layout.

  2. Go to [chatgpt.com/plugins](https://chatgpt.com/plugins), or to **Settings** > **Apps**, and select **Create** or **+**.

  3. In the name field, enter `Promptless`.

  4. In the description field, enter a short description, such as `Start and track Promptless documentation tasks, and search, read, and edit our docs.` ChatGPT uses this text to decide when to call the app.

  5. In the MCP server URL field, enter `https://api.gopromptless.ai/mcp/with-direct-edits`.

  6. For authentication, select **OAuth**. ChatGPT registers itself with Promptless automatically, so no client ID or secret is needed.

  7. Select **Create**, then approve the connection in the Promptless tab that opens. See [Approve the connection](#approve-the-connection).
</Steps>

ChatGPT reads the Promptless tool list and adds the app with a **Dev** label. On a Business, Enterprise, or Edu workspace, an admin can publish the app from the workspace's app drafts. Other members can then connect to it.

### Use Promptless in a conversation

In a new chat, select Promptless from the tools menu under the message box, or @-mention it by name. The selection applies to the message you send, so select or mention Promptless again for a follow-up that needs it.

Before a tool that changes data runs, ChatGPT shows a confirmation card. Review the action, then allow or deny it. For per-app permission settings, see OpenAI's [developer mode guide](https://help.openai.com/en/articles/12584461-developer-mode-and-full-mcp-apps-in-chatgpt-beta).

## Approve the connection

After you select **Connect** in Claude.ai or **Create** in ChatGPT, a Promptless tab opens so you can approve the connection. Promptless uses OAuth, so the chat app never sees your Promptless password.

<Steps>
  1. If you aren't signed in to Promptless, sign in with your Promptless account. The approval page opens after you sign in.

  2. Check where the connection goes. The page names the app that's asking to connect and the web address it sends the connection to. For Claude, that address is `claude.ai` or `claude.com`. For ChatGPT, it's `chatgpt.com`. The app chooses its own name, so check the address, not the name, and cancel if it doesn't match the app you're connecting.

  3. In the organization picker, choose the Promptless organization to connect. It defaults to your active organization. The page also shows your role in that organization.

  4. Select **Authorize as \{your email}**.
</Steps>

The tab reports that it's returning you to the app, and you can close it. Back in Claude.ai or ChatGPT, Promptless shows as connected, and its tools are ready to use.

If you don't belong to a Promptless organization yet, the page asks for a name and creates an organization when you authorize. Finish [setting up Promptless](https://app.gopromptless.ai/configuration) before you start documentation tasks.

### What the connection can access

There are no narrower permissions to choose. A connection acts with your access across the organization you picked. It can:

- read every documentation task, doc collection, and suggestion in the organization, including work started from Slack, GitHub, the dashboard, or the API;
- start documentation tasks, which can open docs pull requests;
- revise, update, and close suggestions;
- search, read, and edit documentation files on an open suggestion's branch.

The connection is tied to one organization. To work in a different organization, disconnect and connect again, then pick that organization on the approval page. For the full access and membership rules, see [Authorize in the browser](/docs/for-docs/connect/triggers/mcp#authorize-in-the-browser).

## What you can do once connected

Ask in plain language. The chat app picks the Promptless tool that matches your request. With the chat app URL, you can:

- Start a documentation task and follow it to its outcome and docs pull request link (`submit_documentation_task`, `wait_for_task_update`).
- Check a task's status and read its conversation (`get_task_status`).
- List your organization's recent tasks, newest first (`list_recent_tasks`).
- Add an instruction to a task that's still running (`send_task_message`).
- Answer a clarifying question a task asked (`answer_task_question`).
- List your doc collections (`list_doc_collections`).
- Search suggestions by keyword, status, or label (`search_suggestions`).
- View the diff a suggestion proposes (`get_suggestion_diff`).
- Ask Promptless to revise a suggestion (`request_changes`).
- Set a suggestion's title, labels, or assignees, and open its docs pull request (`update_suggestion`).
- Close a suggestion you won't ship (`close_suggestion`).
- List, search, and read your documentation files (`list_documentation_files`, `search_documentation`, `read_documentation_file`).
- Edit a page yourself on an open suggestion's branch (`edit_documentation_file`, `write_documentation_file`).
- Check your organization's setup status and connected integrations (`get_account_status`).

For each tool's arguments and results, see [Available tools](/docs/for-docs/connect/triggers/mcp#available-tools) on the MCP triggers page.

## Test the connection

Run these prompts in a new conversation with Promptless turned on. In ChatGPT, select or @-mention Promptless in each message.

1. Enter `List my Promptless doc collections.` The app calls `list_doc_collections` and lists your organization's doc collections by name. If it reports that the organization hasn't finished setting up Promptless, finish setup on the [Configuration page](https://app.gopromptless.ai/configuration).

2. Enter `Show my recent Promptless tasks.` The app calls `list_recent_tasks` and lists recent tasks newest first, including ones started from Slack, GitHub, or the dashboard. A new organization might have none yet.

3. Enter `Search my Promptless docs for "install".` The app calls `search_documentation` and returns matching lines with their file paths. If this works, the connection uses the chat app URL.

4. Optional: Start a small real task. For example, enter `Ask Promptless to fix any typos on the quickstart page in my docs collection, and follow the task until it finishes.` Approve the `submit_documentation_task` call when asked. The app follows the task for several minutes and relays messages from Promptless. It then reports the outcome: a suggestion with its docs pull request link, or no change needed. This runs real work in your organization. To discard the resulting suggestion, enter `Close that Promptless suggestion.`

If the first two prompts return results, the connection works. If the third says the tool doesn't exist, the connector uses `https://api.gopromptless.ai/mcp`. Remove it and add it again with the chat app URL.

## Reconnect or disconnect

A connection lasts 90 days. Within that time, the app refreshes its access automatically. After 90 days, the app asks you to connect again. If you lose active membership in the organization, Promptless revokes the connection. To approve a connection again:

- In Claude.ai, go to **Customize** > **Connectors**, select **Promptless**, and select **Connect**.
- In ChatGPT, go to **Settings** > **Apps** or **Plugins**, select **Promptless**, and connect your account again.

To disconnect:

- In Claude.ai, go to **Customize** > **Connectors**, open the menu next to **Promptless**, and select **Remove**. On a Team or Enterprise plan, an Owner removes the connector for everyone in **Organization settings** > **Connectors**.
- In ChatGPT, go to **Settings** > **Apps** or **Plugins**, select **Promptless**, and disconnect it from its menu. A workspace admin can turn the app off for everyone in the workspace's admin settings.

Promptless has no revoke button in the dashboard. Each member manages their own connection from the chat app.

## Troubleshooting

- **The approval page says the request is no longer valid**: approval requests expire after 30 minutes. Start the connection again from Claude.ai or ChatGPT.
- **The approval page says the request has already been answered**: the request was already approved or canceled. If the app is still waiting, start the connection again.
- **You canceled on the approval page**: the app reports that the connection was declined. Select **Connect** in Claude.ai, or reconnect the app in ChatGPT, to try again.
- **The organization you want isn't in the picker**: you aren't an active member of it. Ask an admin of that Promptless organization to invite you.
- **Promptless tools don't run in a Claude.ai chat**: turn on Promptless from **+** > **Connectors** in that conversation. Then check that the tool isn't set to **Blocked** in **Customize** > **Connectors**.
- **Promptless tools don't run in a ChatGPT chat**: confirm that developer mode is on, then select or @-mention Promptless in the message. On a plan limited to read actions, tools that start or change work don't run.
- **You connected the wrong organization**: disconnect Promptless, connect again, and pick the right organization on the approval page.

For errors that Promptless tools return after you connect, see [Troubleshooting](/docs/for-docs/connect/triggers/mcp#troubleshooting) on the MCP triggers page.
