## Overview

Promptless agents can call models with your organization's own keys, through the inference providers you set up on the [**Models**](https://app.gopromptless.ai/settings/models) settings page. Use the AI your company already has: add a provider API key or your own endpoint. If you [self-host Promptless](/docs/for-docs/security/self-hosting), set your internal inference here too.

Inference options vary by plan. To talk through the setup that fits your organization, [contact the Promptless team](/docs/for-docs/reference/getting-help).

Promptless works with any endpoint that serves an OpenAI-compatible or Anthropic-compatible API. Anthropic, OpenAI, and OpenRouter are built in, so each needs only an API key. Your organization holds one key for each built-in provider and any number of custom endpoints.

## Before you start

- An organization admin role. Other members see the page read-only.
- An API key for each provider.

## Add a provider key

<Steps>
  1. Open **Settings**, then [**Models**](https://app.gopromptless.ai/settings/models).

  2. On the provider's card, select **Add OpenRouter key**, **Add Anthropic key**, or **Add OpenAI key**.

  3. Enter the **API key**, then select **Add key**.

  4. Select **Run test call**. The card shows **Verified**, or **Test call failed** with the provider's message.
</Steps>

The test call sends one short prompt to the lowest-priced model the key reaches. Promptless encrypts the key on save. After that, the dashboard shows only a short fingerprint.

## Add a custom endpoint

The endpoint must use `https` and resolve only to public IP addresses. Promptless doesn't follow redirects.

<Steps>
  1. On the **Models** settings page, select **Add custom endpoint**.

  2. Enter a **Provider ID** of lowercase letters, digits, and hyphens, such as `dashscope`. It can't match a built-in provider's ID.

  3. Enter a **Display name**, the **Base URL**, and the **API key**.

  4. Under **API**, select **OpenAI chat completions** or **Anthropic messages**.

  5. Add a row for each model with its **Model ID**, context window, and maximum output tokens. Promptless enforces a spending limit on each agent session, so you must also enter what the endpoint charges. Enter its input and output prices in USD per million tokens. Use `0` for tokens the endpoint doesn't charge for.

  6. Select **Add endpoint**, then **Run test call** on the endpoint's card.
</Steps>

To change the model list later, select **Edit models** on the endpoint's card.

## Find a model's ref

The **Models you can pick** table lists each model your enabled keys reach, with its price per million tokens and its model ref. Use the ref when you choose a model for an agent. A ref has the form `<provider-id>/<model-id>`, such as `openrouter/qwen/qwen3-coder` or `anthropic/claude-haiku-4-5`.

A model shows **Ready** once its provider passes a test call. Until then it shows **Verify provider first**, and agents can't use it.

## Replace, disable, or remove a key

| Action  | Control on the provider's card | Effect                                                        |
| ------- | ------------------------------ | ------------------------------------------------------------- |
| Replace | **Replace key**                | The provider is unverified until you run the test call again. |
| Disable | **Disable**, then **Enable**   | Agents can't use the provider's models while it's disabled.   |
| Remove  | The delete icon, then confirm  | Agents can't use the provider's models.                       |

Editing a custom endpoint's model list also resets it to unverified.
