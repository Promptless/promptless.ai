Agent-ready docs are documentation an AI agent can read, search, and cite on its own, without a person pasting pages into a prompt. A Starport site ships llms.txt files, a docs Model Context Protocol (MCP) server, and page actions. It adds agent-friendly docs (afdocs) scoring and an optional site assistant. Any AI agent can use these to answer questions about your product from your content. For the full capability list, see [What's included in Starport](/docs/for-docs/starport/whats-included).

## Use cases

| What you need                                                                        | What to use                                        |
| ------------------------------------------------------------------------------------ | -------------------------------------------------- |
| Give an AI agent your whole docs corpus as plain text.                               | [`llms-full.txt`](#the-llmstxt-files)              |
| Let a coding assistant, such as Claude Code or Cursor, search your docs as it works. | [The docs MCP server](#read-only-docs-mcp-server)  |
| Let a reader hand one page to ChatGPT or Claude.                                     | [Page actions](#page-actions)                      |
| Catch a change that makes your published docs harder for agents to read.             | [Afdocs scoring](#afdocs-scoring)                  |
| Answer reader questions from your docs, inside the site.                             | [The site assistant](#the-optional-site-assistant) |

## The llms.txt files

Starport generates three files at build, following the [llms.txt standard](https://llmstxt.org/), so an agent can load your docs as plain text:

- `llms.txt` is the entry point. It names your site and links to the two documentation sets below.
- `llms-full.txt` carries the full text of your docs in one file.
- `llms-small.txt` carries an abridged version, with non-essential content removed.

An agent reads them at their published paths:

```text
https://docs.example.com/llms.txt
https://docs.example.com/llms-full.txt
https://docs.example.com/llms-small.txt
```

Point an agent at `llms-full.txt` when it needs the whole corpus, and at `llms-small.txt` when its context window is tight.

## Read-only docs MCP server

Starport serves a read-only [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) server at `/mcp`. AI clients such as Claude Code, Cursor, and VS Code connect to it to search and read your docs, through two tools:

- `search` finds passages by query and returns them with their source URLs.
- `get_page` returns one page's full content as Markdown.

Both tools are read-only, so an agent reads your docs and never writes to them.

```text
https://docs.example.com/mcp
```

The endpoint requires no authentication. To restrict access, use your hosting provider's access control, for example Cloudflare Access or Vercel Deployment Protection.

<Aside type="note">
  The docs MCP server is on by default. To turn it off, set `MCP_ENABLED` to `false`. See [Configure deploy settings](/docs/for-docs/starport/configuring-starport#configure-deploy-settings) for the settings it needs.
</Aside>

## Page actions

Every page carries controls that hand its content to an agent in one step. **Copy Markdown** copies the page as Markdown for pasting into any tool. Under **Open**, **Open in ChatGPT** and **Open in Claude** open that assistant with a prompt to read the page, ready for your questions.

## Afdocs scoring

Starport checks how ready your docs are for agents with afdocs, the checker for the [Agent-Friendly Docs Spec](https://agentdocsspec.com/spec/web/). The check runs daily against your published site and can also be run manually. It fails when the score drops below a minimum, 100 by default, so a regression shows up on the next run. The check runs once the `AFDOCS_URL` repository variable holds your published site's URL.

To score any docs site without a Starport repository, use [Agent Score](/agent-score), a hosted run of afdocs.

## The optional site assistant

Add an Anthropic API key and Starport turns on an assistant in site search. A reader selects **Ask Assistant** and asks a question. The assistant answers from your published pages, with links to the pages it drew from. For the key and the model setting, see [Configure your Starport site](/docs/for-docs/starport/configuring-starport#turn-on-the-site-assistant).
