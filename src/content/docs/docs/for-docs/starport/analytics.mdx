A Starport site measures reader activity through the analytics tools you already run. The template gives you an event seam to wire those tools in, and Promptless configures search-query analytics for you on request. For the capabilities still on the way, see [What's included in Starport](/docs/for-docs/starport/whats-included).

## The analytics event seam

The site emits a browser custom event named `starport:analytics` for search and site-assistant interactions. Those interactions include a search query, a result click, and an assistant question. You attach a listener that forwards each event to the analytics tool of your choice. Each event's `detail` carries the interaction, for example the action name and the page path. The seam keeps your analytics provider a setting you own, so you swap providers by changing the listener.

```js
// Illustrative: your provider's browser SDK is loaded as `myAnalytics`.
window.addEventListener('starport:analytics', (event) => {
  // event.detail carries the payload for the tracked action.
  myAnalytics.track(event.detail);
});
```

## Connect a third-party analytics provider

Wiring a third-party analytics provider is the concrete path available today. Load your provider's browser SDK on the site, then forward the `starport:analytics` event to it with a listener like the one above. From then on, your provider records the traffic and you read it in that provider's own dashboards. A hosted analytics dashboard, including human-versus-AI traffic, is forthcoming; see [What's included in Starport](/docs/for-docs/starport/whats-included). For how documentation impact rolls up across Promptless, see [Reporting and ROI](/docs/for-docs/measure/reporting-and-roi).

## Search-query analytics through managed setup

Starport tracks what readers search for and sends those queries into a product-analytics tool. Promptless configures this for you as a managed setup: you tell the team the tool you use, and Promptless wires the queries through. For what Promptless processes and retains, see [Data handling and classification](/docs/for-docs/security/data-handling-and-classification).

<Aside type="note">
  To turn on search-query analytics, ask your Promptless contact and name the product-analytics tool you use.
</Aside>
