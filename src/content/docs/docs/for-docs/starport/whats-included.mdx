A Starport site ships the capabilities below, split into what you get today and what's on the way. Two capabilities have their own pages: [agent-ready surfaces](/docs/for-docs/starport/agent-ready) and [analytics](/docs/for-docs/starport/analytics). To set any of these up after onboarding, see [Configure your Starport site](/docs/for-docs/starport/configuring-starport).

## Available today

Every Starport site ships the capabilities below.

| Capability | What you get |
| --- | --- |
| Astro and Starlight core | The site builds on the open-source Astro Starlight framework. |
| Internationalization | English ships with a Spanish sample locale, through native Starlight i18n. |
| Multi-section sidebar navigation | Group your pages into topic sections in the sidebar. |
| OpenAPI API reference | Generate a reference from an OpenAPI schema. |
| llms.txt and llms-full.txt | Starport generates both files at build for AI agents. |
| Broken-link validation | The build checks your internal links and fails on a broken one. |
| Redirects | Author redirects that the build emits as 301s. |
| Sitemap | The build generates a sitemap for search engines. |
| Site search with an optional AI assistant | Set an Anthropic API key to turn the assistant on. |
| Read-only docs Model Context Protocol (MCP) server | Agents read your docs through a read-only MCP server. |
| PDF export | Export a single page, and export named page sets on a schedule. |
| Content linting | Frontmatter, prose, and Markdown linting run over your content. |
| Doc Detective testing | Validates that documented procedures still work against the running product and flags failures. The template runs it on a schedule and files an issue when one fails. |
| Vercel-first deploy | Deploy to Vercel, with documented GitHub Pages and Cloudflare Pages paths. |

<Aside type="note">
  The site assistant is the part of AI-powered search you get today. It answers reader questions from your indexed content when you supply an Anthropic API key.
</Aside>

## Forthcoming

The capabilities below are forthcoming. Plan around what ships today, and treat each row here as not yet available.

| Capability | Status |
| --- | --- |
| Role-based access control (RBAC) and authenticated docs | Forthcoming. Gate the published site at the hosting layer with your hosting provider's access control, for example Cloudflare Access or Vercel Deployment Protection. May need custom work. |
| Versioned documentation | Forthcoming. |
| Changelogs | Forthcoming. |
| Interactive API playground | Forthcoming. |
| Page and code feedback | Forthcoming. |
| Hosted analytics dashboard | Forthcoming, including human-versus-AI traffic. |
| Semantic (AI) search | Forthcoming. The optional site assistant is the part of AI-powered search you get today. |

## Security and compliance

For an enterprise security review of Promptless itself, see [Compliance and certifications](/docs/for-docs/security/compliance-and-certifications), [Data handling and classification](/docs/for-docs/security/data-handling-and-classification), and [Subprocessors](/docs/for-docs/security/subprocessors).
