Starport is a managed docs-as-code framework, built on the open-source Astro Starlight. Promptless stands up your documentation site, sets up its build and deploy pipeline, and keeps its content current as your product changes. Your site runs on a hosting provider you choose, such as Vercel, on an account you own. You keep control of your infrastructure instead of depending on a single vendor. Starport suits teams who want docs-as-code run as a service, with hosting they control.

<Aside type="tip" title="Migration is included, and optional">
  You don't need Starport to use Promptless. Promptless keeps your docs current on your existing setup. When you do want to move, migration to Starport is included at no cost in every annual Promptless plan.
</Aside>

<Aside type="note">
  The documentation you are reading runs on Starport. Promptless migrated promptless.ai onto the Starport template and keeps it current.
</Aside>

## What Starport gives you

<CardGrid>
  <Card title="Build pipeline set up for you, hosting you own" icon="rocket">
    Promptless sets up your build and deploy pipeline, which then runs in CI, so your team spends its time on content, not operations. Your site runs on a provider you choose, such as Vercel, on an account you own.
  </Card>

  <Card title="Agent-ready by default" icon="seti:default">
    Every Starport site ships llms.txt, a read-only docs Model Context Protocol (MCP) server, and page actions. These make your docs consumable by AI agents.
  </Card>

  <Card title="Self-service configuration" icon="setting">
    Set site metadata, branding, search, redirects, and deploy options yourself after onboarding, in plain configuration files.
  </Card>

  <Card title="Kept current by Promptless" icon="approve-check">
    Promptless detects when your product changes and opens documentation pull requests against the Git repository you own.
  </Card>
</CardGrid>
