## Overview

This page gives short answers to common questions about what Promptless connects to, what it reads, and how it handles your data. Each answer links to the page that covers the topic in full. For account creation and team management, see [Account management](/docs/for-docs/reference/account-management).

## Integrations and access

| Question                                       | Answer                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| What platforms does Promptless integrate with? | For triggers: GitHub, GitLab, Jira, Slack, Microsoft Teams, and LaunchDarkly. For context: GitHub, GitLab, Jira, Confluence, Linear, Notion, Google Drive, and Slite. For publishing: Git-hosted docs, such as Fern, Mintlify, Docusaurus, ReadMe, GitBook, and MkDocs sites. See [Integrations](/docs/for-docs/reference/integrations) for the full list.                                                                                          |
| Does Promptless monitor my Slack channels?     | Not by default. Promptless reads Slack only when someone tags @Promptless, sends it a DM, or uses the **Update Docs** message action. If you turn on [passive channel listening](/docs/for-docs/get-the-most-out/passive-channel-listening), Promptless also reads the channels you select in your configuration, and only those. You can add or remove channels at any time. See [Slack integration](/docs/for-docs/reference/integrations/slack). |
| Does Promptless analyze my entire codebase?    | No. When a pull request triggers it, Promptless starts from the pull request and its diff. It reads other code in the repositories you've granted only when the diff alone doesn't explain the change. Promptless never runs your code.                                                                                                                                                                                                             |

## Data handling

| Question                                 | Answer                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| How does Promptless handle my data?      | Promptless stores copies of your documentation for processing. It processes data from third-party integrations without storing it, and it doesn't process end-user data. All data is encrypted in transit with TLS 1.2 or higher, and at rest with AES-256. See [Data handling and classification](/docs/for-docs/security/data-handling-and-classification). |
| Does Promptless train models on my data? | No. Promptless doesn't use customer data to pre-train or fine-tune language models. See [How Promptless uses AI](/docs/for-docs/security/how-promptless-uses-ai).                                                                                                                                                                                             |
