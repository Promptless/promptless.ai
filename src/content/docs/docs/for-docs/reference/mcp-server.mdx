The Promptless [MCP](https://modelcontextprotocol.io) (Model Context Protocol) server connects AI editors, such as Claude Code and Cursor, and chat apps, such as Claude and ChatGPT, to your Promptless organization. A connection signs in with OAuth and acts with your Promptless access, so the client can start documentation tasks and work on suggestions for you. Use this page to check the server URLs, the sign-in, the token lifetimes, and what a connection can access before you approve the server for yourself, your organization, or a marketplace listing.

To connect a client, see [MCP triggers](/docs/for-docs/connect/triggers/mcp) for editors, or [Use Promptless from Claude](/docs/for-docs/work-the-queue/claude) and [Use Promptless from ChatGPT](/docs/for-docs/work-the-queue/chatgpt). If you review the Claude or ChatGPT connector, see [Connector review details](#connector-review-details).

## Server URLs

| URL                                                 | Use it for                                                                                                                | Tools                                                                                               |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `https://api.gopromptless.ai/mcp`                   | Editors such as Claude Code, Cursor, VS Code, and Codex CLI, which work in a local copy of your documentation repository | Tools that start and follow documentation tasks, work on suggestions, and check your account        |
| `https://api.gopromptless.ai/mcp/with-direct-edits` | Chat apps such as Claude and ChatGPT, which have no local copy of your repository                                         | The same tools, plus tools that search, read, and edit documentation files and show suggestion diffs |

Each URL is a separate connection. A token issued for one URL doesn't work on the other. The URL also decides which approval page opens, as [Sign-in and approval](#sign-in-and-approval) describes. For each tool on each URL, see the [MCP tools reference](/docs/for-docs/reference/mcp-tools).

## Authentication

These values are the same for both URLs and for every client.

| Item                  | Value                                                                                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Authentication        | OAuth 2.1 authorization code flow with PKCE (`S256`)                                                                |
| Client registration   | Dynamic client registration only. The client registers itself, with no client ID or client secret to configure.     |
| Account               | A Promptless account. The server uses OAuth sign-in, with no API key.                                               |
| Access token lifetime | 8 hours. The client refreshes the token automatically.                                                              |
| Connection lifetime   | 90 days from approval. Refreshing the token doesn't extend it. After 90 days, you approve the connection again.     |
| Approval request      | Expires 30 minutes after the client starts it. For a chat app, this includes the time that you spend on docs setup. |
| Data scope            | One Promptless organization, which you select on the approval page                                                  |

## Sign-in and approval

When you connect, the client opens a Promptless approval page in your browser. You sign in to Promptless, choose one organization, and approve. If you aren't a member of an organization yet, you can create one there. The client never gets your Promptless password.

The server URL, not the client, decides which approval page opens:

| Step            | Editors (`/mcp`)                                                                                                     | Chat apps (`/mcp/with-direct-edits`)                                                                                                                   |
| --------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Page            | **Connect \{client} to Promptless**                                                                                  | **What do you want help with?**, then **Choose your organization**, or **Create your organization** if you have none                                   |
| **Returns to**  | A local address with a port, such as `127.0.0.1:54321`, or the callback of an app that opens through its own link scheme | `claude.ai` or `claude.com` for Claude, and `chatgpt.com` for ChatGPT                                                                                  |
| Approve         | **Authorize as \{your email}**, or **Create organization and authorize as \{your email}**                            | The same buttons                                                                                                                                       |
| After approval  | The tab returns you to the editor.                                                                                   | If the organization has no GitHub or GitLab connection, the docs setup page opens before the tab returns you to the app. Then you ask the app to set up your docs, which starts a Promptless setup task. |

On both pages, the organization picker selects your active organization by default and shows your role in it. The client sets its own name, and Promptless doesn't verify the name, so check the **Returns to** row before you approve.

## Data access

A connection has the Promptless access of the person who approved it, in the organization that they selected. Every connection to the same URL gets the same access.

| A connection can                                                                                                                                                         | `/mcp` | `/mcp/with-direct-edits` |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ | ------------------------ |
| Read all documentation tasks, doc collections, and suggestions in the organization, including work that started from Slack, GitHub, the dashboard, or the API             | Yes    | Yes                      |
| Start documentation tasks, which can open docs pull requests                                                                                                             | Yes    | Yes                      |
| Revise, update, and close suggestions, and open or close their docs pull requests                                                                                        | Yes    | Yes                      |
| Search, read, and edit documentation files. Edits go only to the branch of an open suggestion, as one commit for each edit, and never to the default branch               | No     | Yes                      |

Promptless checks the person's organization membership on each call. If the person is no longer an active member, the connection stops working. Each member disconnects their own connection in their editor or chat app, and an admin can't disconnect another member's connection. For data handling, see the [Promptless privacy policy](/docs/for-docs/security/privacy-policy).

## Tools

Each Promptless tool carries MCP annotations that tell the client whether it's read-only. Read-only tools, such as `list_doc_collections` and `search_documentation`, only read data. Tools that start or change work, such as `submit_documentation_task`, `close_suggestion`, and `edit_documentation_file`, are marked destructive, and the client asks before they run. For each tool's annotations, arguments, and results, see the [MCP tools reference](/docs/for-docs/reference/mcp-tools).
