Look up what each Promptless role can do, how members join your organization, and what the Billing page shows.

## Create an account

You can sign up for an account at [accounts.gopromptless.ai](https://accounts.gopromptless.ai), or contact the team at [hello@gopromptless.ai](mailto\:hello@gopromptless.ai).

## Manage team members

Each member of your organization has one of three roles:

| Role           | What the role can do                                                                                                        | Typical use                                                   |
| -------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| `Admin`        | Manage organization settings, team members, integrations, and projects. Edit suggestions and the Agent Knowledge Base.      | People who set up and run Promptless for the organization     |
| `Editor`       | Edit documentation suggestions and create tasks. Editors can't manage organization settings, integrations, or team members. | People who work directly on docs without needing admin access |
| `Collaborator` | View documentation suggestions and leave comments for feedback. Collaborators can't edit suggestions.                       | Stakeholders who review content without making direct changes |

### Add team members

Invite teammates and choose each one's role from your organization's management page:

<Steps>
  1. In the upper-left corner of the dashboard, select your organization name.

  2. Next to your organization, select **Manage**.

     <img src="https://promptless-customer-doc-assets.s3.us-east-2.amazonaws.com/docs-images/org_3DaVKUzHgjyjaODgCPaDmjXezqp/organization-manage-button-96515c5c.png" alt="Organization menu with the Manage button next to the current organization" />

  3. Select **Members**, then select **Invite**.

  4. Enter one or more email addresses, select a role, and select **Send invitations**.
</Steps>

### Admin-only configuration

Every member can view the organization-wide configuration. Only admins can change it:

| Configuration                             | Who can change it                                                              |
| ----------------------------------------- | ------------------------------------------------------------------------------ |
| Doc collections (create, edit, or delete) | Admins, in the dashboard or through the API with an API key issued to an admin |
| Configuration page (`promptless.yaml`)    | Admins                                                                         |
| Agent Knowledge Base                      | Admins                                                                         |
| Default role for new members              | Admins                                                                         |

## Domain verification and auto-enrollment

Add your company's email domain to your organization so people with addresses at that domain can join without an individual invitation. The domain's enrollment mode controls how they join:

| Enrollment mode             | How people from the domain join                                                     |
| --------------------------- | ----------------------------------------------------------------------------------- |
| **No automatic enrollment** | An admin invites each person.                                                       |
| **Automatic invitations**   | People receive an invitation when they sign up and can join at any time.            |
| **Automatic suggestions**   | People receive a suggestion to request to join, and an admin approves each request. |

Changing the enrollment mode applies to new users only.

### Set up automatic team member joining

<Steps>
  1. In the upper-left corner of the dashboard, select your organization name.

  2. Next to your organization, select **Manage**.

  3. Under **Verified domains**, select **Add domain**.

     <img src="https://promptless-customer-doc-assets.s3.us-east-2.amazonaws.com/docs-images/org_3DaVKUzHgjyjaODgCPaDmjXezqp/add-domain-interface-2985f950.png" alt="Organization General page with the Verified domains section and its Add domain button" />

  4. Enter your domain, for example `yourcompany.com`.

  5. Verify the domain with the code sent to an email address at that domain.

  6. Select an enrollment mode, then select **Save**.

     <img src="https://promptless-customer-doc-assets.s3.us-east-2.amazonaws.com/docs-images/org_3DaVKUzHgjyjaODgCPaDmjXezqp/enrollment-mode-selection-d29b4789.png" alt="Enrollment options for a verified domain, with Automatic invitations selected" />
</Steps>

### Set the default role for new members

The **Default role for new members** setting sets the role that members who join through a verified domain receive: `Admin`, `Editor`, or `Collaborator`. Existing members keep their roles. To change the setting, an admin opens **Settings**, selects **Organization**, picks a role, and selects **Save**.

## Security and access controls

Promptless supports these sign-in and security features for organizations:

| Feature                         | What it provides                                                     |
| ------------------------------- | -------------------------------------------------------------------- |
| Single sign-on (SSO)            | Sign-in through Google, GitHub, and enterprise identity providers    |
| Two-factor authentication (2FA) | Time-based one-time password (TOTP) codes as a second sign-in factor |
| SAML 2.0                        | Just-in-time provisioning for enterprise customers                   |
| OpenID Connect (OIDC)           | Sign-in through OIDC-compliant identity providers                    |

Enterprise customers also have access to custom data retention policies and advanced audit logging. For SSO setup, see [Single sign-on (SSO) setup](/docs/for-docs/security/single-sign-on).

## Billing

Billing is a page in the dashboard Settings, visible only to **`Admin`** users in organizations on a paid plan. Organizations that aren't on a paid plan (including free and trial organizations) and non-admins don't see it. Anyone who navigates to it directly sees a restricted-access message.

The Billing page has three sections:

| Section             | What it's for                                                       |
| ------------------- | ------------------------------------------------------------------- |
| Current plan        | View your plan, price, subscription status, and next billing event. |
| Payment method      | Replace the card on file.                                           |
| Cancel subscription | Find where to send a cancellation request.                          |

### View your current plan

The **Current plan** section of the Billing page summarizes your organization's active subscription. Its information is read-only:

| Field               | What it shows                                                                                                                            | Example            |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| Plan name           | The subscription's product name                                                                                                          | Promptless Startup |
| Price and cadence   | A fixed amount and billing frequency. Usage-based, tiered, and non-USD subscriptions show **Custom pricing** with the billing frequency. | $500/month         |
| Subscription status | One of **Active**, **Trial**, **Payment overdue**, **Unpaid**, **Paused**, or **Setup incomplete**                                       | Active             |
| Next billing event  | The next date in the subscription, labeled **Renews**, **Trial ends**, **Ends** (a pending cancellation), or **Current period ends**     | Renews Aug 7, 2026 |

When there's no current subscription, the section says no active subscription was found. That happens before a subscription starts or after one ends. If the message looks wrong, email [help@gopromptless.ai](mailto\:help@gopromptless.ai).

### Update your payment method

To replace the card on file, select **Update payment method** on the Billing page. Stripe's secure hosted billing portal opens to the card-update flow and returns you to the Billing page when you finish.

<Aside type="note">
  Card details are handled entirely by Stripe's hosted portal. Promptless never sees or stores your card data.
</Aside>

### Change or cancel a subscription

To upgrade a plan, change seats, or cancel, email the support team at [help@gopromptless.ai](mailto\:help@gopromptless.ai). Send other billing questions to the same address.
