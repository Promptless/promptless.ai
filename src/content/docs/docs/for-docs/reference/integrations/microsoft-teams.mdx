## Overview

Install the Promptless app in your Microsoft Teams tenant so your team can start documentation work from Teams conversations. With Teams connected, you can:

- Tag @Promptless in channels, threads, group chats, or a personal chat.
- Run the **Update docs with Promptless** message action on any message.
- Turn on [passive channel listening](/docs/for-docs/get-the-most-out/passive-channel-listening) for the channels you select.
- [Ask Promptless to update your configuration](/docs/for-docs/get-the-most-out/ask-promptless-to-update-config), such as your triggers and doc collections.

By default, Promptless reads Teams content only when someone mentions it or uses the message action. With passive listening on, it also reads the channels you select, and only those. Promptless doesn't archive or store your Teams messages. It uses large language models (LLMs) from OpenAI and Anthropic, which can generate inaccurate results.

In this guide, you install the Teams app, link your tenant to Promptless, and choose which SharePoint sites Promptless can read shared files from.

## Before you start

- An admin role in your Promptless organization.
- Access to the Microsoft Teams admin center, with permission to manage app setup policies and install third-party apps.
- A Microsoft admin to approve the admin-consent sign-in that links your tenant.
- To let Promptless read files shared in channels, a SharePoint Administrator or Global Administrator with PowerShell.

### Key permissions

Promptless requests these permissions through Teams resource-specific consent (RSC). A team owner consents to them when the app is installed in a team:

| Permission                   | What Promptless uses it for                                                        |
| ---------------------------- | ---------------------------------------------------------------------------------- |
| `ChannelMessage.Read.Group`  | Reads channel messages without an @mention, for passive listening.                 |
| `TeamMember.Read.Group`      | Resolves the identities of team members.                                           |
| `ChannelSettings.Read.Group` | Lists the team's channels and their membership types, such as standard or private. |

The app also has standard bot permissions, which let it send messages and notifications and read user information for mentions.

## Connect Microsoft Teams

<MicrosoftTeamsConnect />

When someone adds Promptless to their personal chat, Promptless sends a welcome message. It explains how to ask an admin to connect the tenant, how to mention `@Promptless`, and how to use the **Update docs with Promptless** message action. If someone uses Promptless before your tenant is linked, Promptless points them to the [Integrations](https://app.gopromptless.ai/integrations) page, where an admin can finish the connection.

## Add Promptless to channels

Promptless receives messages only from channels in teams where the app is installed. To use Promptless in a channel:

1. Install the Promptless Teams app in the team that contains the channel.
2. Optional. To have Promptless read the channel without an @mention, add the channel to your [passive listening configuration](/docs/for-docs/get-the-most-out/passive-channel-listening).

## Choose which shared files Promptless can read

Promptless reads files from Teams as context for the documentation it drafts. What it can read depends on where the file was shared:

| Where the file was shared | What Promptless reads                                                                                   |
| ------------------------- | ------------------------------------------------------------------------------------------------------- |
| A personal (1:1) chat     | Attached files and images, and inline images you paste into a message.                                  |
| A channel                 | Inline images, and attached files stored on a SharePoint site that a Microsoft admin granted access to. |
| A group chat              | Nothing that's attached or pasted, including inline images.                                             |

A file on a SharePoint site without a grant shows as unavailable instead of being read. Access is granted per SharePoint site, not per channel. A team's standard channels share one site, and each private or shared channel has its own site.

To grant access to a site, a SharePoint Administrator or Global Administrator completes these steps after the Teams connection is approved:

1. On the [Integrations](https://app.gopromptless.ai/integrations) page, on the Microsoft Teams card, select **Choose SharePoint sites**. After the first grant, the button reads **Manage SharePoint site access**.
2. Select each site whose files Promptless should read.
3. Copy the permission command the dialog generates, and run it in PowerShell.
4. Select **Verify access**.

The card lists each granted site. A private or shared channel's site appears only to its members. To grant one, reconnect Microsoft Teams as an admin who belongs to that channel. If your organization linked Teams before Promptless could read channel files, an admin reconnects and picks sites before channel files become available.
