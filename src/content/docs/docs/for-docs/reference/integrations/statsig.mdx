## Overview

Connect Statsig when your team releases features behind Statsig feature gates, experiments, or dynamic configs, so Promptless knows whether a change has reached your users before it documents it. A merged pull request can add a feature that stays off for most users until someone changes its gate. When a change depends on a feature that Statsig controls, Promptless reads the current rules for that gate, experiment, or dynamic config from your Statsig project. It finds out whether the feature is on for every user, for some users, or only outside production, and uses that, with your instructions, to decide whether to document the feature yet.

Promptless starts from the ID that the code passes to the Statsig SDK, such as the gate name in a `checkGate` call. For example, a developer merges a pull request that shows a new bulk export button only when the `bulk_export` gate passes. The gate's production rule passes 20% of users. Promptless reads the gate and reports bulk export as a partial rollout.

Connecting Statsig starts no work. Your [triggers](/docs/for-docs/connect/triggers) still decide when Promptless drafts. Access is read-only: Promptless reads feature gates, experiments, dynamic configs, and segments, and never changes them. Promptless connects one Statsig project for your organization.

## Before you start

- An admin role in your Promptless organization.
- A Statsig account that can create Console API keys for the project.

## Connect Statsig

<StatsigConnect />

Statsig doesn't report a key's permissions, so Promptless can't reject a key that has write access. Promptless still runs only read commands. Use a read-only key so the key itself can't change your project. Promptless keeps the key out of the agent's environment and workspace, and supplies it to each Statsig read itself.

## Set how Promptless handles a partial rollout

When a feature reaches only some users, the right docs change depends on your team. Some teams document a feature only once it reaches every user in production. Others document a beta for the users who have it.

- Write your rule as a convention in the Agent Knowledge Base. See [Write a convention in the Knowledge Base](/docs/for-docs/tune/teaching-conventions#write-a-convention-in-the-knowledge-base).

## Disconnect Statsig

- On the [Integrations](https://app.gopromptless.ai/integrations) page, on the Statsig card, select **Disconnect Statsig**.

Promptless stops reading your Statsig project. To revoke the key too, delete it in Statsig's [API keys settings](https://console.statsig.com/api_keys).

## Fix connection problems

| What you see                                                                                  | What it means                                                                               | What to do                                                                                                                  |
| --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| "Invalid Statsig Console API key" when you connect                                            | Statsig rejected the key.                                                                   | Copy the key again, or create a new read-only Console API key, and connect with it.                                         |
| "Statsig accepted this Console API key but refused it access to its project" when you connect | The key can't read the project.                                                             | Create a read-only Console API key in the project you want Promptless to read, and connect with it.                         |
| **Needs reconnect** on the Statsig card                                                       | The daily check found that Statsig rejects the key, or that the key can't read its project. | Select **Disconnect Statsig**, create a new read-only Console API key, then select **Connect Statsig** and connect with it. |

For the other health labels, see [Connection health](/docs/for-docs/reference/integrations#connection-health).
