## Overview

Connect Linear so Promptless can read your Linear issues and projects as context when it drafts documentation. For example, when a pull request mentions a feature, Promptless can find the related Linear issue and reuse the reasoning recorded there. Promptless connects through [Linear's OAuth 2.0 flow](https://developers.linear.app/docs/oauth/authentication) and refreshes its access token automatically.

In this guide, you connect a Linear workspace, then reconnect it if Linear stops accepting Promptless's access.

## Before you start

- An admin role in your Promptless organization.
- A Linear account in the workspace you want to connect. Promptless reads only the teams that account can access.

## Connect Linear

<LinearConnect />

The Linear card lists the teams Promptless can reach. To review or revoke Promptless's access from Linear, select **Review access in Linear** on the card.

## Reconnect Linear

When Linear stops accepting Promptless's access, the Linear card on the [Integrations](https://app.gopromptless.ai/integrations) page shows a **Reconnect Linear** callout. Promptless can't read Linear issues until you reconnect. Linear stops accepting access when Promptless can't refresh its token, or when someone removes the Promptless authorization in Linear.

1. On the Linear card, select **Reconnect Linear**.
2. In Linear, approve access for Promptless.

When the card lists your teams again, Promptless can read your Linear issues.
