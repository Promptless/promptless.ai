**Used for: Triggers**

Connecting LaunchDarkly creates a webhook that receives flag-change events from your projects. This connection is the prerequisite for flag-triggered documentation work. A configured [LaunchDarkly flag trigger](/docs/for-docs/connect/triggers/launchdarkly) is what starts documentation work when a matching feature flag changes.

## Authentication model

Promptless uses API token authentication for LaunchDarkly integrations. The service token and the webhook Promptless creates when you connect provide:

- Secure webhook delivery with HMAC-SHA256 signature verification
- A unique signing secret for each integration
- Ability to revoke access at any time

To disconnect, click the LaunchDarkly card on the integrations page and select Disconnect. This removes the webhook from your LaunchDarkly account.

If a configured flag trigger stops starting documentation work after a disconnect, a revoked token, or a failed webhook signature check, see [Connection health](/docs/for-docs/connect/connection-health).
