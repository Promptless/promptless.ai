## Overview

Connect LaunchDarkly so Promptless can start documentation work when a feature flag changes. Connecting creates a webhook in your LaunchDarkly account that sends Promptless flag-change events from all your projects. The connection alone starts no work. A [LaunchDarkly flag trigger](/docs/for-docs/connect/triggers/launchdarkly) decides which flag changes start documentation work.

Promptless reads projects and flag state, and it manages only its own webhook. It never edits a flag. The LaunchDarkly integration is in beta.

In this guide, you create a LaunchDarkly service token, connect it in Promptless, and disconnect when you no longer need flag-triggered work.

## Before you start

- An admin role in your Promptless organization.
- A LaunchDarkly account that can create access tokens.

## Connect LaunchDarkly

<LaunchDarklyConnect />

Promptless authenticates to LaunchDarkly with the service token. It verifies each webhook delivery with an HMAC-SHA256 signature, using a signing secret unique to your connection.

## Disconnect LaunchDarkly

- On the [Integrations](https://app.gopromptless.ai/integrations) page, on the LaunchDarkly card, select **Disconnect LaunchDarkly**.

Promptless removes its webhook from your LaunchDarkly account, and flag changes stop reaching Promptless. To revoke the service token too, delete it in LaunchDarkly's [Authorization settings](https://app.launchdarkly.com/settings/authorization).
