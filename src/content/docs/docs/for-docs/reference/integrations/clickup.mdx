## Overview

Connect ClickUp so Promptless can start documentation work when a task moves into a status you choose, and read ClickUp tasks while it researches. Connecting creates a webhook in your ClickUp workspace that sends Promptless task status changes. The connection alone starts no work. A [ClickUp status trigger](/docs/for-docs/connect/triggers/clickup) decides which statuses start documentation work.

Promptless reads ClickUp tasks with the access of the ClickUp account that authorizes the connection. Besides tasks that match a trigger, Promptless reads any task it finds referenced in a pull request, message, or request, using the task ID. Promptless doesn't change tasks or post to ClickUp.

In this guide, you connect ClickUp, check the connection, and disconnect when you no longer need ClickUp-triggered work.

## Before you start

- A ClickUp account in the workspace whose tasks you want Promptless to watch.

## Check the connection

- On the [Integrations](https://app.gopromptless.ai/integrations) page, on the ClickUp card, select **Check access**.

Promptless lists the workspaces the connection can reach. When it can reach none, the card shows **Needs reconnect**. Reconnect ClickUp from its card.

## Disconnect ClickUp

- On the [Integrations](https://app.gopromptless.ai/integrations) page, on the ClickUp card, select **Disconnect ClickUp**.

ClickUp status changes stop starting documentation work, and your ClickUp status triggers show as inactive until you reconnect. The webhook Promptless created stays in your ClickUp workspace, and Promptless ignores its deliveries.
