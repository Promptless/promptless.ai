## Overview

Connect Vercel to see in the Promptless dashboard whether your [Starport](/docs/for-docs/starport) documentation site built and published. Promptless reads your site's recent production deployments, plus the project and domain metadata that identify the site. Access is read-only. Promptless never deploys and never changes your Vercel projects, domains, or environment variables.

The integration is optional and applies only to Promptless-managed Starport sites. It also backs the Promptless listing on the Vercel Marketplace, so you can start the installation from Vercel instead.

## Before you start

- An admin role in your Promptless organization.
- A Promptless-managed Starport site that deploys to Vercel.

## Fix connection problems

The [connection health](/docs/for-docs/connect/connection-health) label on the Vercel card reports whether the connection itself is authenticated and reachable. Deployment status appears separately in the dashboard.

| What the Vercel card shows                    | What it means                                                         | What to do                                                                                               |
| --------------------------------------------- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **Problem**                                   | Promptless couldn't reach or verify Vercel during its latest check.   | No action needed. Promptless checks again and returns the card to **Connected** when the check succeeds. |
| **Needs reconnect**                           | The authorization expired or was revoked.                             | Select **Disconnect Vercel**, then **Connect Vercel**, and approve access again.                         |
| A note that connecting Vercel isn't turned on | Vercel connections aren't enabled for your Promptless deployment yet. | Contact [help@gopromptless.ai](mailto\:help@gopromptless.ai) to have them enabled.                       |
