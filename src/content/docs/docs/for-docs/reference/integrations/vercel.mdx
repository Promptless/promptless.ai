**Used for: Monitoring**

Connect Vercel to see in the Promptless dashboard whether your [Starport](/docs/for-docs/starport) documentation site built and published. Promptless reads your site's recent production deployments, plus the project and domain metadata that identify the site. Access is read-only: Promptless never deploys and never changes your Vercel projects, domains, or environment variables.

The integration is optional and applies only to Promptless-managed Starport sites. It also powers the Promptless listing on the Vercel Marketplace, so you can install it from Vercel.

## Installation

An organization admin connects Vercel once, through OAuth, for the whole organization.

1. On the [integrations page](https://app.gopromptless.ai/integrations), click "Connect Vercel".
2. On Vercel, approve read-only access for Promptless.
3. Confirm that Vercel shows as connected on the integrations page.

<Aside type="note" title="Monitoring is separate from your Starport deploy">
  Your Starport site deploys to Vercel from CI, using the credentials in [Starport configuration](/docs/for-docs/starport/configuring-starport#configure-deploy-settings). This connection only reads the result.
</Aside>

## Connection health

The [connection health](/docs/for-docs/connect/connection-health) label on the Vercel card reports whether the connection itself is authenticated and reachable. Deployment status appears separately in the dashboard.

- **Needs reconnect**: Click **Disconnect Vercel**, then **Connect Vercel**, and approve access again.
- **Temporary outage**: No action needed. Promptless rechecks and returns the card to **Connected** once the check succeeds.
