## Overview

Connect the Promptless Slack app so your team can start documentation work from Slack conversations and get notified when suggestions are ready. One connection covers these jobs:

| Capability    | What Promptless does                                                                                             | Set it up                                                                                                      |
| ------------- | ---------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Triggers      | Starts documentation work when someone tags @Promptless, uses the **Update Docs** message action, or sends a DM. | [Slack messages](/docs/for-docs/connect/triggers/slack-messages)                                               |
| Context       | Reads the thread where you trigger it, and Slack threads that a request links to.                                | [Slack messages](/docs/for-docs/connect/triggers/slack-messages)                                               |
| Notifications | Posts to your notification channel when suggestions are created, updated, or published.                          | [Customize notifications](/docs/for-docs/tune/notifications)                                                   |
| Configuration | Updates your triggers, doc collections, and other configuration when you ask in Slack.                           | [Ask Promptless to update your configuration](/docs/for-docs/get-the-most-out/ask-promptless-to-update-config) |

By default, Promptless reads Slack only when someone triggers it. If you turn on [passive channel listening](/docs/for-docs/get-the-most-out/passive-channel-listening), Promptless also reads the channels you select, and only those. Promptless doesn't archive or store your Slack messages. It uses large language models (LLMs), which can generate inaccurate results.

In this guide, you install the Slack app, add Promptless to channels, and grant permissions that Promptless adds later.

## Before you start

- An admin role in your Promptless organization.
- Permission to install apps in your Slack workspace, or a Slack workspace admin who can approve the request.

### Key permissions

Slack's approval screen lists every permission the Promptless Slack app requests. These are the ones that control what you can do in Slack:

| Permission                     | What Promptless uses it for                                                                                                              |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `channels:read`, `groups:read` | Lists public channels, and private channels Promptless was invited to, so you can pick them as a notification channel or trigger source. |
| `channels:join`                | Joins a public channel when you configure it for passive listening, so you don't have to invite Promptless.                              |
| `chat:write`                   | Replies in threads and posts suggestion notifications.                                                                                   |
| `files:read`                   | Reads screenshots and logs attached to a request to @Promptless.                                                                         |
| `links:read`, `links:write`    | Shows a preview card when someone shares a Promptless suggestion link.                                                                   |
| `users:read`                   | Shows people's names instead of user IDs when Promptless replies to mentions.                                                            |
| `users:read.email`             | Matches the person who submitted a task through an MCP editor to their Slack account, so Promptless can DM them the result.              |

## Add Promptless to a channel

Promptless responds to an @mention only in a channel it's a member of. It joins a public channel on its own before it posts there, such as for a suggestion notification. It also joins a public channel when you configure the channel for passive listening. Promptless can't join a private channel, or a channel shared with another workspace through Slack Connect, on its own.

Add Promptless to a channel yourself when you want to:

- Tag @Promptless in a channel it isn't a member of yet.
- Use a private or Slack Connect channel as your notification channel, to trigger Promptless from its messages, or for passive listening.

To add Promptless, tag `@Promptless` in the channel, and accept Slack's prompt to invite the app. You can also run `/invite @promptless`. A private channel then appears in the dashboard's channel pickers, with no refresh needed.

## Update Slack permissions

As Promptless adds Slack features, the app sometimes requests new permissions. A workspace that connected before a permission was added lacks it until you grant it. The Slack card on the [Integrations](https://app.gopromptless.ai/integrations) page then shows a **Grant additional Slack permissions** callout. The callout names each missing permission and what it's for.

<Steps>
  1. In the **Grant additional Slack permissions** callout, select **Update connection**.

  2. In Slack, approve the added permissions.
</Steps>

Promptless swaps the stored token in place, so your workspace stays connected and your channel memberships and configuration don't change. The callout only adds capability to a connection that already works. When the authorization itself lapses or is rejected, the card shows **Needs reconnect** instead. See [Connection health](/docs/for-docs/connect/connection-health).

## Troubleshooting

| Problem                                                                                        | Cause                                                                                                                                                        | Fix                                                                                                                                                                     |
| ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A private channel doesn't appear when you choose a notification channel or trigger source.     | Promptless isn't in the channel, or the workspace is missing `groups:read`.                                                                                  | [Add Promptless to the channel](#add-promptless-to-a-channel). If the Slack card names `groups:read` as missing, [update Slack permissions](#update-slack-permissions). |
| A shared suggestion link posts as plain text, with no preview card.                            | The workspace is missing `links:write`.                                                                                                                      | [Update Slack permissions](#update-slack-permissions).                                                                                                                  |
| Someone who submitted a task through an MCP editor gets no DM when their suggestion is ready.  | The workspace is missing `users:read.email`, so Promptless notifies the notification channel instead.                                                        | [Update Slack permissions](#update-slack-permissions).                                                                                                                  |
| The MCP submitter still gets no DM after you grant `users:read.email`.                         | Their Slack account email differs from their Promptless account email, the address shown as "Authorize as \{email}" when they authorized the MCP connection. | Use the same email address for both accounts. Updating Slack permissions doesn't fix this case.                                                                         |
| Promptless isn't reading a channel you configured for passive listening, and no error appears. | The channel is private or shared through Slack Connect, or the workspace is missing `channels:join`.                                                         | For a private or shared channel, [add Promptless to it](#add-promptless-to-a-channel). For a public channel, [update Slack permissions](#update-slack-permissions).     |

If a problem persists, contact [help@gopromptless.ai](mailto\:help@gopromptless.ai).
