## Connect multiple GitHub organizations

You can connect multiple GitHub organizations to your Promptless account.

After you connect your first organization, click the "Connect another GitHub Org" button on the integrations page to add more. Each new organization follows the same steps as [Connect GitHub](#connect-github).

Each connected organization appears as its own card on the integrations page, showing:

- Organization name
- List of accessible repositories
- Individual refresh and disconnect controls

When creating or editing projects, repositories from all connected organizations are available in the dropdown menus, displayed as `organization/repository`.

## Manage repository access

When selecting a docs repository during setup, Promptless shows the connected GitHub organization above the repository picker. Click **Manage repository access** at the bottom of the picker to open GitHub's installation settings and adjust which repositories Promptless can access.

Each connected card on the integrations page also carries a **Configure in GitHub** button. It opens the Promptless GitHub App's installation page in a new tab. This button appears on both the main GitHub card and the GitHub (read-only) card. Repository access is always governed in GitHub's App settings, including any organization admin-approval requirement.

After installation, manage further repository access directly through your GitHub organization settings:

1. In your GitHub organization settings, go to "Third-party Access" → "GitHub Apps", then find "Promptless" and click "Configure".
2. In the "Repository access" section, switch between "All repositories" and "Only select repositories". Use the "Select repositories" dropdown to add a repository, or click the "×" next to a repository's name to remove it.

<img src="https://promptless-customer-doc-assets.s3.amazonaws.com/docs-images/org_2lvkgU9erOFxYhtEVVC0ymPrPdF/bc05f421-e940-4f84-b442-6f9181a0eab3-github-app-repository-management.png" alt="GitHub App Repository Management" />

3. Click "Save" to apply your changes.

After you update repository access, the new repositories become available when creating or editing projects in Promptless. Changes may take a few minutes to appear in the dashboard. If newly added repositories don't show up right away, click the "refresh repos" icon on the integrations page.

## Authentication model

Promptless uses the official [GitHub App specification](https://docs.github.com/en/apps/creating-github-apps/about-creating-github-apps) and authenticates with JWTs generated by the App installation. Promptless has read and write access to the repositories you select, and either party can revoke access at any time.

## Organization IP allow lists

If your GitHub organization enforces an IP allow list, Promptless must reach your organization from its own network. Otherwise GitHub blocks its requests, silently stopping it from reading pull requests and publishing updates.

A GitHub organization owner picks one of the following options, both under **Settings → Authentication security**. If you don't administer the organization, hand these to whoever does.

- **Let installed GitHub Apps bypass the list (recommended)**: Select **Enable IP allow list configuration for installed GitHub Apps**. GitHub automatically adds the Promptless GitHub App's addresses, and this keeps working even when they change.
- **Add Promptless's egress IP address**: Add `3.143.177.103` to your allow list. This is the NAT gateway address that Promptless's requests originate from. This address can change, so prefer the bypass option above for a setting you don't have to maintain.

This applies to standard GitHub.com organizations. If you use GitHub Enterprise, see [Allow Promptless IP addresses](/docs/for-docs/reference/integrations/github-enterprise#step-6-allow-promptless-ip-addresses) for the full list of addresses to allow.

## What you can do with GitHub

Once connected, you can use GitHub for:

- **[Triggers](/docs/for-docs/connect/triggers)**: Monitor pull requests and commits for documentation updates
- **[Context Sources](/docs/for-docs/connect/context-sources)**: Search code repositories and issues for technical context
- **[Doc Collections](/docs/for-docs/connect/doc-locations/github-repos)**: Publish documentation updates to GitHub-based platforms

## Frequently asked questions

<details>
  <summary>Promptless shows 'no repositories accessible' during setup. What do I do?</summary>

  The Promptless GitHub App is installed but has no repository access yet. Click **Manage repository access** to open GitHub's installation settings, where you can grant access to specific repositories or select "All repositories." After updating access, click **Refresh** in Promptless to reload the list.
</details>

<details>
  <summary>How do I add more repositories after installing the GitHub integration?</summary>

  Add repositories anytime from your GitHub organization settings. In GitHub, go to `Settings -> Third-party Access -> GitHub Apps`, find the Promptless GitHub App, and click "Configure." Add or remove repositories in the "Repository access" section, then click "Save." The newly added repositories are then available when creating or editing your Promptless projects.
</details>

<details>
  <summary>Can I remove GitHub repository access from Promptless?</summary>

  You can remove access to specific repositories, or uninstall the integration entirely, from the same "Configure" page in your GitHub organization settings. Click the `×` next to a repository name to remove it from the Promptless GitHub App. To remove the app entirely, click the `Uninstall` button at the bottom of the page.
</details>

<details>
  <summary>How long does it take for repository changes to appear in Promptless?</summary>

  Repository updates in the GitHub App may take a few minutes to appear in your Promptless dashboard. If newly added repositories don't show up right away when creating or editing projects, click the "refresh repos" icon on the integrations page.
</details>

<details>
  <summary>Can I connect multiple GitHub organizations to one Promptless account?</summary>

  Yes. After connecting your first GitHub organization, add more by clicking "Connect another GitHub Org" on the integrations page. Each organization appears as its own card, and repositories from all connected organizations are available when setting up projects.
</details>

<details>
  <summary>What happens if my GitHub organization requires owner approval for apps?</summary>

  If your organization requires owner approval before third-party apps can be installed, GitHub shows you a request flow instead of installing. Submit the request, and Promptless tracks it automatically. Approval installs the App but doesn't connect it to Promptless. After an owner approves, a Promptless organization admin starts a fresh connection from the integrations page and authorizes it as a GitHub organization owner. The connection link stays valid for one hour.
</details>
