## Overview

Connect a GitHub organization to Promptless through the Promptless GitHub App. One connection covers triggers, context, and publishing for the repositories you grant the app:

| Capability | What Promptless does                                                                          | Set it up                                                         |
| ---------- | --------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Triggers   | Starts documentation work from pull requests, commits, and issues in monitored repositories.  | [Triggers](/docs/for-docs/connect/triggers)                       |
| Context    | Searches code and issues in granted repositories for technical context.                       | [Context sources](/docs/for-docs/connect/context-sources)         |
| Publishing | Opens pull requests with documentation updates in repositories you set up as doc collections. | [GitHub repos](/docs/for-docs/connect/doc-locations/github-repos) |

The app follows the [GitHub App specification](https://docs.github.com/en/apps/creating-github-apps/about-creating-github-apps) and authenticates with JWTs generated by the app installation. It has read and write access to the repositories you select, and either you or Promptless can revoke that access at any time. If you can't grant write access, use the [GitHub (read-only) app](/docs/for-docs/reference/integrations/github-read-only). On GitHub Enterprise Server, use the [GitHub Enterprise integration](/docs/for-docs/reference/integrations/github-enterprise).

In this guide, you install the app on an organization and choose which repositories it can reach. If your organization has an IP allow list, you also let Promptless through it.

## Before you start

- An admin role in your Promptless organization.
- An owner of the GitHub organization to authorize the app. If you aren't an owner, you can request approval during setup.
- If your organization enforces an IP allow list, an owner who can change its **Authentication security** settings.

## Connect GitHub

<GitHubConnect />

### Connect multiple GitHub organizations

To add another organization, select **Connect another GitHub Org** on the [Integrations](https://app.gopromptless.ai/integrations) page, and repeat the steps in [Connect GitHub](#connect-github). Each organization gets its own card, with its repositories and its own **Check access** and **Disconnect GitHub** controls. When you create or edit a doc collection or trigger, repositories from every connected organization are available, listed as `organization/repository`.

## Manage repository access

Change which repositories Promptless can reach whenever you add a source or docs repository, or want to remove one. GitHub controls this access in the app's installation settings.

<img src="https://promptless-customer-doc-assets.s3.amazonaws.com/docs-images/org_2lvkgU9erOFxYhtEVVC0ymPrPdF/bc05f421-e940-4f84-b442-6f9181a0eab3-github-app-repository-management.png" alt="Repository access section of the Promptless GitHub App settings, with the All repositories and Only select repositories options" />

1. On the [Integrations](https://app.gopromptless.ai/integrations) page, on the organization's GitHub card, select **Configure in GitHub**. The app's installation settings open in GitHub in a new tab.
2. Under **Repository access**, select **All repositories** or **Only select repositories**.
3. Optional. To add a repository, select it from the **Select repositories** list. To remove one, select **×** next to its name.
4. Select **Save**.
5. Back on the GitHub card in Promptless, select **Check access**.

The card lists the repositories the installation can reach, and they become available when you create or edit doc collections and triggers. GitHub can take a few minutes to report the change. If a repository is still missing, select **Check access** again.

You can also reach the same settings in GitHub, under your organization's **Settings** > **Third-party Access** > **GitHub Apps**: find **Promptless** and select **Configure**. To remove the app entirely, select **Uninstall** at the bottom of that page.

## Organization IP allow lists

If your GitHub organization enforces an IP allow list, GitHub blocks requests from Promptless that don't come from an allowed address. Promptless then can't read pull requests or publish updates, and GitHub reports no error to you. A GitHub organization owner picks one of these options, both under **Settings** > **Authentication security**:

| Option                                                  | What to do                                                                       | Maintenance                                                                     |
| ------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Let installed GitHub Apps bypass the list (recommended) | Select **Enable IP allow list configuration for installed GitHub Apps**.         | None. GitHub adds the Promptless GitHub App's addresses and keeps them current. |
| Add the Promptless egress IP address                    | Add `3.143.177.103`, the NAT gateway address that Promptless requests come from. | This address can change, so you might need to update the entry later.           |

These options apply to organizations on GitHub.com. For GitHub Enterprise, see [Allow Promptless IP addresses](/docs/for-docs/reference/integrations/github-enterprise#step-6-allow-promptless-ip-addresses) for the full list of addresses.

## Fix common GitHub connection problems

| Problem                                                                                              | Cause                                                                        | Fix                                                                                                                                        |
| ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| The GitHub card says no repositories are accessible to the installation.                             | The app is installed but has no repository access yet.                       | Grant access as described in [Manage repository access](#manage-repository-access).                                                        |
| A repository you just granted doesn't appear in Promptless.                                          | GitHub can take a few minutes to report new access.                          | Select **Check access** on the GitHub card.                                                                                                |
| The doc collection picker shows "No connected repository matches that."                              | The repository isn't in a connected organization, or the app can't reach it. | Select **Manage repository access** below the picker to open the Integrations page, then connect the organization or grant the repository. |
| The card shows **Waiting on an organization owner**.                                                 | Your organization requires an owner to approve third-party apps.             | Ask an owner to approve the app. See [Connect GitHub](#connect-github).                                                                    |
| Promptless stopped reading pull requests or publishing, and your organization uses an IP allow list. | GitHub blocks requests from addresses that aren't on the list.               | Allow Promptless as described in [Organization IP allow lists](#organization-ip-allow-lists).                                              |
