Check the Promptless connector for Claude and ChatGPT before you approve it for yourself, your organization, or a marketplace listing. This page lists the server, the sign-in, what a connection can access, and each tool with its MCP annotations. The connector is the Promptless [MCP](https://modelcontextprotocol.io) (Model Context Protocol) server.

To set up the connector, see [Use Promptless from Claude](/docs/for-docs/work-the-queue/claude) or [Use Promptless from ChatGPT](/docs/for-docs/work-the-queue/chatgpt). The Promptless listing in the Claude directory is at [claude.ai/directory/promptless](https://claude.ai/directory/promptless).

## Server details

| Item                  | Value                                                                                                                                    |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Server URL            | `https://api.gopromptless.ai/mcp/with-direct-edits`                                                                                      |
| Authentication        | OAuth 2.1 authorization code flow with PKCE (`S256`)                                                                                     |
| Client registration   | Dynamic client registration. The app registers itself, with no client ID or client secret to configure.                                  |
| Account               | A Promptless account. The connector uses OAuth sign-in, with no API key.                                                                 |
| Access token lifetime | 8 hours. The app refreshes the token automatically.                                                                                      |
| Connection lifetime   | 90 days from approval. After 90 days, the user approves the connection again.                                                            |
| Approval request      | Expires 30 minutes after the app starts it                                                                                               |
| Data scope            | One Promptless organization, which the user selects on the approval page                                                                 |
| Setup guides          | [Use Promptless from Claude](/docs/for-docs/work-the-queue/claude), [Use Promptless from ChatGPT](/docs/for-docs/work-the-queue/chatgpt) |
| Privacy policy        | [Promptless privacy policy](/docs/for-docs/security/privacy-policy)                                                                      |
| Support               | [help@gopromptless.ai](mailto\:help@gopromptless.ai)                                                                                     |

Promptless has a second server URL, `https://api.gopromptless.ai/mcp`, for editors such as Claude Code and Cursor. It omits the six tools that search, read, and edit documentation files. Chat apps use the direct-edit URL because they have no local copy of the documentation repository. Each URL is a separate connection.

## Sign-in and approval

When a user connects, the app opens the Promptless approval page. The user signs in to Promptless, selects one organization, and approves. The page shows:

- The **Returns to** address, which receives the connection. For Claude, it is `claude.ai` or `claude.com`. For ChatGPT, it is `chatgpt.com`. The app sets its own name, and Promptless does not verify the name, so users check the address.
- An organization picker, which selects the user's active organization by default, and the user's role in that organization.
- The access that the connection gets, as listed in [Data access](#data-access).

A user who is not a member of a Promptless organization can create one from the approval page. The app never gets the user's Promptless password.

## Data access

A connection has the Promptless access of the person who approved it, in the organization that they selected. Every connection gets this access, at one access level. A connection can:

- Read all documentation tasks, doc collections, and suggestions in the organization. This includes work that started from Slack, GitHub, the dashboard, or the API.
- Start documentation tasks, which can open docs pull requests.
- Revise, update, and close suggestions, and open or close their docs pull requests.
- Search, read, and edit documentation files. Edits go only to the branch of an open suggestion, as one commit for each edit. They never go to the default branch.

A connection applies to one organization. Promptless checks the person's organization membership on each call. If the person is no longer an active member, the connection stops working. Each member disconnects their own connection in the chat app. For data handling, see the [Promptless privacy policy](/docs/for-docs/security/privacy-policy).

## Tools

The direct-edit URL has 20 tools. Each tool has MCP annotations that tell the app if the tool is read-only or changes data. The **Type** column shows these annotations:

- **Read-only**: `readOnlyHint` is true. The tool does not change data.
- **Changes data**: `readOnlyHint` is false and `destructiveHint` is false. The tool adds work or input, and does not change or remove existing content.
- **Changes existing content**: `readOnlyHint` is false and `destructiveHint` is true. The tool changes or closes an existing suggestion or file.

Each tool name links to its arguments, results, and errors on the MCP triggers page.

| Tool                                                                                           | Action                                                                                             | Type                     |
| ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------ |
| [`list_doc_collections`](/docs/for-docs/connect/triggers/mcp#list_doc_collections)             | Lists the doc collections of the organization.                                                     | Read-only                |
| [`list_recent_tasks`](/docs/for-docs/connect/triggers/mcp#list_recent_tasks)                   | Lists the recent tasks of the organization, newest first.                                          | Read-only                |
| [`get_task_status`](/docs/for-docs/connect/triggers/mcp#get_task_status)                       | Gets the status and conversation of one task.                                                      | Read-only                |
| [`wait_for_task_update`](/docs/for-docs/connect/triggers/mcp#wait_for_task_update)             | Waits up to 30 seconds for new messages or a status change on one task.                            | Read-only                |
| [`search_suggestions`](/docs/for-docs/connect/triggers/mcp#search_suggestions)                 | Finds suggestions by keyword, status, or label.                                                    | Read-only                |
| [`get_suggestion_diff`](/docs/for-docs/connect/triggers/mcp#get_suggestion_diff)               | Shows the changes that a suggestion proposes.                                                      | Read-only                |
| [`list_documentation_files`](/docs/for-docs/connect/triggers/mcp#list_documentation_files)     | Lists the files in a doc collection.                                                               | Read-only                |
| [`search_documentation`](/docs/for-docs/connect/triggers/mcp#search_documentation)             | Finds text in the documentation files.                                                             | Read-only                |
| [`read_documentation_file`](/docs/for-docs/connect/triggers/mcp#read_documentation_file)       | Reads one documentation file.                                                                      | Read-only                |
| [`get_account_status`](/docs/for-docs/connect/triggers/mcp#get_account_status)                 | Shows the setup status and connected integrations of the organization.                             | Read-only                |
| [`submit_documentation_task`](/docs/for-docs/connect/triggers/mcp#submit_documentation_task)   | Starts a documentation task. The task can open a docs pull request.                                | Changes data             |
| [`send_task_message`](/docs/for-docs/connect/triggers/mcp#send_task_message)                   | Adds an instruction to a task that is in progress.                                                 | Changes data             |
| [`answer_task_question`](/docs/for-docs/connect/triggers/mcp#answer_task_question)             | Sends the answer to a question that a task asked.                                                  | Changes data             |
| [`request_changes`](/docs/for-docs/connect/triggers/mcp#request_changes)                       | Asks Promptless to revise a suggestion.                                                            | Changes data             |
| [`connect_integration`](/docs/for-docs/connect/triggers/mcp#connect_integration)               | Creates a link that a person opens to connect an integration, such as GitHub, to the organization. | Changes data             |
| [`message_promptless_support`](/docs/for-docs/connect/triggers/mcp#message_promptless_support) | Sends a one-way report to the Promptless team. Replies do not come back through the tool.          | Changes data             |
| [`update_suggestion`](/docs/for-docs/connect/triggers/mcp#update_suggestion)                   | Sets the title, labels, or assignees of a suggestion, or opens its docs pull request.              | Changes existing content |
| [`close_suggestion`](/docs/for-docs/connect/triggers/mcp#close_suggestion)                     | Closes a suggestion and its docs pull request.                                                     | Changes existing content |
| [`write_documentation_file`](/docs/for-docs/connect/triggers/mcp#write_documentation_file)     | Creates or replaces one file on the branch of an open suggestion.                                  | Changes existing content |
| [`edit_documentation_file`](/docs/for-docs/connect/triggers/mcp#edit_documentation_file)       | Replaces specific text in one file on the branch of an open suggestion.                            | Changes existing content |

The two file tools cannot edit a closed suggestion.
