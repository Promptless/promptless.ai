## Overview

Environment variables store credentials, API keys, and configuration values that Promptless uses when it works with your systems. The most common use is login credentials for [Promptless Capture](/docs/for-docs/get-the-most-out/screenshots), so Promptless can sign in to your application and capture product screenshots. Custom tasks, such as [turning docs analytics into doc-gap suggestions](/docs/for-docs/get-the-most-out/teach-promptless-a-custom-task/analytics-docs-gaps), read API credentials the same way.

Promptless sees each variable's name, so use a name that says what the value is for, such as `TEST_ACCOUNT_USER`, `QA_USERNAME`, or `STAGING_LOGIN_EMAIL`. Mark passwords, API keys, and other sensitive values as secrets.

## Before you start

- An admin role in your Promptless organization. Only organization admins can view and manage environment variables.
- For screenshot credentials, a dedicated test or service account. See [Keep secrets secure](#keep-secrets-secure).

## Add an environment variable

<Steps>
  1. In the Promptless dashboard, open **Settings** and select [**Agent Env Vars**](https://app.gopromptless.ai/settings/env-vars).

  2. In the **Add Variable** form, enter a **Key Name**. Key names use uppercase letters, numbers, and underscores, up to 100 characters. The form converts the letters you type to uppercase.

  3. Enter the **Value**.

  4. If the value is a password, API key, or other sensitive value, turn on the **Secret** toggle. The **Value** field then masks what you type.

  5. Select **Add Variable**. The variable appears in the table above the form.
</Steps>

## Keep secrets secure

After you save a secret, the dashboard hides its value, and no one can view it again. Promptless also redacts secret values from the records it logs, stores, and transmits. See [How Promptless protects secrets and sensitive data](/docs/for-docs/security/secrets-and-sensitive-data#credential-redaction).

<Aside type="caution">
  Store credentials for dedicated test or service accounts, not personal accounts. Screenshots then contain no personal data, and results stay consistent.
</Aside>

## Example: Screenshot capture credentials

For [Promptless Capture](/docs/for-docs/get-the-most-out/screenshots), add these variables so Promptless can log in to your application:

| Variable            | Example value                       | Secret |
| ------------------- | ----------------------------------- | ------ |
| `TEST_ACCOUNT_URL`  | `https://app.yourcompany.com/login` | No     |
| `TEST_ACCOUNT_USER` | `qa-screenshots@yourcompany.com`    | No     |
| `TEST_ACCOUNT_PASS` | `(your password)`                   | Yes    |

<Aside type="tip">
  Give the test account access to every feature you want documented, including features that need specific permissions or plan tiers.
</Aside>

## Update or delete a variable

You can change a variable's value, but not its key name. To rename a variable, delete it and add it again under the new name.

To change a variable's value:

1. In the variable's row, select **Update**.
2. Enter the new value. The field starts empty, so enter the whole value.
3. Select **Save**.

To delete a variable:

1. In the variable's row, select **Delete**.
2. Select **Confirm**.

Promptless removes the variable, and the agent can no longer use it.
