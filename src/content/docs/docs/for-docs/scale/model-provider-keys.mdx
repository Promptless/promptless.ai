## Overview

Runs that use a model your organization picks, such as docs eval runs, call that model with your organization's own API key. Promptless doesn't pay for these calls. The provider bills your account.

On the [**Models**](https://app.gopromptless.ai/settings/models) settings page, you add a key for each provider you use, test it, and see which models your runs can use. You can add keys for:

- **OpenRouter**, where one key reaches open models such as Qwen, DeepSeek, and Llama
- **Anthropic**
- **OpenAI**
- **Custom endpoints** that serve the OpenAI chat completions API or the Anthropic messages API

Your organization holds one key for each of OpenRouter, Anthropic, and OpenAI, and any number of custom endpoints.

## Before you start

- An admin role in your Promptless organization. Only organization admins can add, test, change, or remove keys. Other members see the page read-only.
- An API key from each provider you plan to use. Create one at [openrouter.ai/keys](https://openrouter.ai/keys), in the Claude Console, or in the OpenAI platform. Keys are 8 to 500 characters.

## Add a provider key

<Steps>
  1. In the Promptless dashboard, open **Settings** and select [**Models**](https://app.gopromptless.ai/settings/models).

  2. On the provider's card, select **Add OpenRouter key**, **Add Anthropic key**, or **Add OpenAI key**.

  3. Enter the **API key**, then select **Add key**.

  4. On the provider's card, select **Run test call**. The card shows **Verified** when the call succeeds.
</Steps>

The test call sends one short prompt, capped at $0.05, to the cheapest model the key reaches. If the provider refuses the call, the card shows **Test call failed** with the provider's message. Fix the cause, such as an expired key or missing credit, and run the test again.

Promptless encrypts each key when you save it. The dashboard identifies each key by a short fingerprint, and no one can view the key again.

## Add a custom endpoint

Add a custom endpoint for a provider that serves an OpenAI-compatible or Anthropic-compatible API. Examples include Alibaba DashScope or a model gateway your company runs. The endpoint must use `https` and a public host name.

<Steps>
  1. On the **Models** settings page, select **Add custom endpoint**.

  2. Enter a **Provider ID** of lowercase letters, digits, and hyphens, such as `dashscope`. Runs name the endpoint's models as `<provider-id>/<model-id>`. The ID can't match a built-in provider's ID.

  3. Enter a **Display name**, the **Base URL**, and the **API key**.

  4. Under **API**, select **OpenAI chat completions** or **Anthropic messages**.

  5. Add a row for each model the endpoint serves. Enter its **Model ID**, context window, maximum output tokens, and input and output prices in USD per million tokens. Both prices are required, and Promptless uses them to enforce a run's cost cap. Enter `0` only when the endpoint doesn't charge for those tokens.

  6. Select **Add endpoint**.

  7. On the endpoint's card, select **Run test call**.
</Steps>

To change the endpoint's model list later, select **Edit models** on its card.

## Pick a model for a run

The **Models you can pick** table lists every model your enabled keys reach, with its model ref and its price per million tokens. A model ref is the provider ID and the model ID, such as `openrouter/qwen/qwen3-coder` or `anthropic/claude-haiku-4-5`. Name a model by its ref when you start a run.

A model shows **Ready** once its provider's key passes a test call. Until then it shows **Verify provider first**, and runs can't use it.

## Replace, disable, or remove a key

A new key and an edited model list both start unverified. After either change, select **Run test call** again.

- To replace a key, select **Replace key** on the provider's card, enter the new key, and select **Replace key**.
- To pause a provider, select **Disable** on its card. Runs can't use its models until you select **Enable**.
- To delete a key, select the delete icon on the provider's card, then confirm. Runs can no longer use its models.
