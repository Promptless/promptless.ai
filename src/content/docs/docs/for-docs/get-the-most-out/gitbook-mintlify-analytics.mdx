## Overview

If you publish your documentation on GitBook or Mintlify, the site's reader analytics show where readers look for answers and don't find them. Connect GitBook Analytics or Mintlify Analytics so Promptless reads those analytics and checks each signal against your documentation source. It then tells you which gaps to fix first.

Promptless reads the site's searches, the questions readers ask its AI assistant (Ask AI on GitBook), page ratings and comments, and page views. The strongest signals are assistant questions that went unanswered or got a poor rating, and searches where readers rarely opened a result. The connection is read-only.

The reports include text that readers typed, such as their questions, search terms, and comments. Promptless treats that text as evidence about your docs and quotes only the words that identify a gap.

## Before you start

- An admin role in your Promptless organization, to connect the analytics.
- A [doc collection](/docs/for-docs/connect/doc-locations/how-promptless-learns-your-docs) that holds the source of the docs your site publishes. Promptless searches it to confirm each gap.
- For GitBook, a GitBook plan that includes site insights, and a GitBook user who can open the site and its insights. The connection reads with that user's access.
- For Mintlify, a Pro or Enterprise plan, which the Mintlify API requires.

## Ask Promptless for a gap analysis

Ask Promptless for a gap analysis in Slack, in Microsoft Teams, or from **New Task**. For example: "@Promptless find documentation gaps in our GitBook analytics for the last 90 days."

Name a date range to narrow the analysis, or name one signal, such as unanswered assistant questions, to get only that report. Without a date range, Promptless uses the last 90 days.

For each candidate gap, Promptless searches your doc collection for the term or question, its synonyms, and the product names it contains. It drops typos, questions about other products, and subjects the docs already answer under another name. It then classifies each remaining gap:

| Class       | Meaning                                                                                                                                       |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Missing     | No page covers the subject.                                                                                                                   |
| Findability | A page covers the subject, but readers search or ask for it and don't find it. Its title, headings, and metadata don't use the readers' term. |
| Quality     | Readers reach the page, then rate it low, comment that it's wrong or unclear, or get a poor assistant answer from it.                         |

Promptless returns the gaps ranked by reader impact: the number of questions, searches, or ratings behind each gap, weighted by the page's views. A gap with signals in several reports ranks higher than a gap with one. Each gap names its report, the question, term, or page, its count, and the date range. It also names the page that covers the subject, or says that no page does, and recommends a change. When a report reads only part of the site's data, the gap says how much it read. To fix a gap, ask Promptless to open a suggestion for it.

To run the analysis on a schedule, pair a schedule trigger with a workflow. See [Example: Turn docs analytics into doc-gap suggestions](/docs/for-docs/get-the-most-out/teach-promptless-a-custom-task/analytics-docs-gaps).

## Example

Your API docs are on Mintlify. In the last 30 days, readers asked the assistant "how do I rotate an API key?" 14 times, and the assistant marked most of those questions unanswered. Searches for "rotate key" also rarely led to a result click.

You ask Promptless in Slack for a gap analysis of the last 30 days. Promptless searches your doc collection and finds that the "API keys" page covers creating and deleting keys but not rotating them. It reports one Missing gap with both signals, so the gap ranks near the top. The gap cites the assistant questions and the search term with their counts. It names the "API keys" page and recommends a "Rotate an API key" section on it. You reply in the thread and ask Promptless to open a suggestion for that section.

## Troubleshooting

### GitBook doesn't connect

When you select **Connect**, Promptless reads the site and one small insights report with the token. The connection saves only when both reads succeed:

- **Invalid GitBook API token**: GitBook rejected the token. Create a new API token and reconnect.
- **GitBook site not found for this API token**: the token's user can't see a site with these IDs. Copy both IDs again from the site's URL in GitBook. If they're right, use a token from a user with access to the site.
- **This GitBook API token's user cannot read this site's insights**: the token's user can see the site but not its insights. Create the token with a user who can open the site's insights in GitBook.
- **This GitBook organization's plan does not include site insights**: GitBook answers analytics requests only on plans with site insights. The message names the plan GitBook requires. Upgrade the GitBook plan, then connect again.

### Mintlify doesn't connect

When you select **Connect**, Promptless reads analytics with the key. The connection saves only when that read succeeds:

- **This is a Mintlify assistant API key, which cannot read analytics**: assistant keys, which start with `mint_dsc_`, reach only Mintlify's assistant, search, and page content APIs. Create an admin API key and connect with it.
- **Invalid Mintlify API key**: Mintlify rejected the key. Copy the key again, or create a new admin API key.
- **Mintlify project not found for this API key**: the project ID doesn't belong to the key's Mintlify organization. Copy the project ID again from the API keys page in Mintlify.
- **Mintlify refused this API key**: the key lacks read access, or its IP allowlist blocks Promptless. Mintlify sets both when you create a key and doesn't let you change them. Create a new admin API key with read access and no IP allowlist, then connect with it.
- **Mintlify's hourly analytics rate limit (100 requests per organization) is used up**: Mintlify allows 100 analytics requests an hour for your whole Mintlify organization. Your own tools share that budget. Try again after the hour resets.

### The card shows Needs reconnect

Promptless checks the connection regularly. The **GitBook Analytics** card shows **Needs reconnect** when GitBook rejects the token or the token's user loses access to the site or its insights. It also shows it when the GitBook plan drops site insights. The **Mintlify Analytics** card shows it when Mintlify rejects or refuses the key, or the key can't read the project. Fix the access in GitBook or Mintlify, then select **Check access**. If the token or key was deleted, or a Mintlify key needs different access, disconnect the integration and connect it with a new one.
