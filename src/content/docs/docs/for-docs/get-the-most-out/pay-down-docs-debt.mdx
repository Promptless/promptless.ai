## Overview

Use Deep Analysis when a documentation project spans many pages, needs background research, or calls for a plan before any edits land. Promptless plans the work, splits it into parts, and runs its full writing workflow on each part. You get a coordinated set of suggestions in place of a single edit.

Deep Analysis fits projects like these:

- Refactor or rewrite a whole section to match a new pattern or stronger examples.
- Audit the collection for consistency, accuracy, or style compliance.
- Write documentation from scratch for a new feature or product.
- Add error codes, examples, or other structured data across an OpenAPI reference.

Deep Analysis is one of three modes on the New Task page. Choose the mode that fits the size of the request:

| Mode          | Best for                                | Expected response | Typical output               |
| ------------- | --------------------------------------- | ----------------- | ---------------------------- |
| Fast          | Typos and small wording fixes           | Under 5 minutes   | Usually 1 suggestion         |
| Default       | Most documentation changes              | 10–20 minutes     | Usually 1–2 suggestions      |
| Deep analysis | Audits, migrations, and multi-page work | Can take hours    | Often 10 or more suggestions |

For routine updates, use a regular trigger, such as Slack or a GitHub PR trigger, or a New Task in **Default** mode.

<Aside type="tip">
  Auditing, remediating, or restructuring an existing docs set? See [Audit and keep your docs healthy](/docs/for-docs/audit/keep-docs-healthy) for how Deep Analysis fits alongside Vale, Doc Detective, and redirects.
</Aside>

## Submit a request

<img src="https://promptless-customer-doc-assets.s3.us-east-2.amazonaws.com/docs-images/org_3DaVKUzHgjyjaODgCPaDmjXezqp/new-task-composer-deep-analysis-fullpage-4ca80367.png" alt="The New Task page with the Doc Collection chip set to Let Promptless decide, the Mode chip set to Deep analysis, the Notify control set to Slack, an empty instructions field with the attach and submit buttons, the Auto-create PRs chip, and the Use a template rail of template cards" />

1. In the sidebar, select **New task**. To open the New Task page with **Deep analysis** already selected, use the [Deep Analysis link](https://app.gopromptless.ai/new-task?mode=deep).
2. Optional. To scope the run yourself, choose a collection from the **Doc Collection** chip. The default, **Let Promptless decide**, picks the collections the task affects. Only collections that have finished initial analysis appear in the list.
3. In the **Mode** chip, select **Deep analysis**.
4. Optional. Under **Use a template**, select a [Deep Analysis template](#choose-a-template). Do this before you write: a template replaces anything already in the instructions field.
5. In the instructions field, describe the project. Include the product area, the source code or APIs Promptless should inspect, examples to model, and the changes to focus on.
6. Optional. To add screenshots, PDFs, or specs, select **Attach files** (the paperclip) or paste an image into the field. You can attach up to 5 files, 10 MB each.
7. Optional. Change where Promptless reports on the task. The **Notify** control opens on the Slack channel your `promptless.yaml` policies route notifications to, or your escalation channel when that's the only one set. Choose another channel, or select **No notification**.
8. Optional. Turn on **Auto-create PRs** to open a pull request for each of this task's suggestions without reviewing it first.
9. Select the submit arrow, or press Cmd+Enter on macOS or Ctrl+Enter on Windows and Linux. Pressing Enter alone adds a new line.

Promptless opens the task's page, where you can follow the run and see the suggestions it produces. The run continues in the background, so you can close the tab.

## Choose a template

The **Use a template** rail includes four Deep Analysis templates for common project shapes. Each one fills the instructions field with a title line, a description, and `{curly-brace}` placeholders for the context Promptless needs. Edit the text before you submit. Selecting a template also sets **Mode** to the mode it needs, and selecting the selected card again clears the field.

| Template                        | Use it to                                                                       |
| ------------------------------- | ------------------------------------------------------------------------------- |
| Refactor a bad section of docs  | Improve an existing section, using another set of docs as a model.              |
| Add error codes to OpenAPI spec | Add error codes and examples to your API specification.                         |
| Write docs from scratch         | Write new documentation, with guidance on outline, audience, and style.         |
| Audit for consistency           | Review all documentation for consistent terminology, formatting, and structure. |

The rail's other templates, such as **Find doc update from recent merges**, run in **Default** mode.

## Follow a Deep Analysis run

A Deep Analysis run can take several hours and often produces 10 or more suggestions across your documentation. Promptless plans the work across your docs first, then runs the full writing workflow for each part: research, grounding in your source, editing, and review.

The run appears on the Triggers page as `Deep Analysis: <your instructions>`, so you can tell it apart from regular tasks. If you chose a notification channel, Promptless sends the run's suggestions and any blockers there.
