## Overview

Ask Promptless in Slack or Microsoft Teams to change your configuration, and it makes the change for you. Use it when describing a change in chat is faster than editing `promptless.yaml` on the [Configuration page](https://app.gopromptless.ai/configuration) yourself. For example, add a trigger for a new repository while you're discussing it in a channel.

A configuration change is not a documentation suggestion. Asking Promptless to update your docs produces a suggestion that you review and merge. Asking it to update your configuration changes your settings directly, with no suggestion and no pull request.

## Before you start

- The Promptless app in Slack or Microsoft Teams. To connect it, see [Connect Slack](/docs/for-docs/connect/triggers/slack-messages#connect-slack) or [Connect Microsoft Teams](/docs/for-docs/work-the-queue/reviewing-from-slack-and-teams#connect-microsoft-teams).
- For a provider-backed trigger, such as a GitHub PR trigger, the provider's integration connected. Promptless can't add, rename, or change that trigger until it is. See [Connect a provider before you add its triggers](/docs/for-docs/connect/triggers#connect-a-provider-before-you-add-its-triggers).

## Ask Promptless to change your configuration

<Steps>
  1. In Slack or Microsoft Teams, mention `@Promptless` the same way you request documentation updates.

  2. Describe the configuration change in your own words. There is no fixed command syntax.

  3. If Promptless asks a clarifying question, reply in the same thread.
</Steps>

Promptless validates the resulting configuration before it applies the change, so an invalid or unrecognized change isn't saved. It then commits the change to `promptless.yaml` in your [Agent Knowledge Base](/docs/for-docs/get-the-most-out/agent-knowledge-base). Review the result on the [Configuration page](/docs/for-docs/reference/configuration-reference#configuration-editor). To undo a change, revert it like any other commit, or ask Promptless to change it back.

You can also select **Ask Promptless** on the Configuration page. It opens a New Task where you describe the change.

For how to work with Promptless in Slack and Teams, see [Review from Slack and Teams](/docs/for-docs/work-the-queue/reviewing-from-slack-and-teams).

## Choose what to change

Promptless can change any setting `promptless.yaml` supports. These example requests work the same way in Slack and Microsoft Teams:

| Section                                                                             | Example requests                                                                                                                                                                                                                                        |
| ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Triggers](/docs/for-docs/reference/configuration-reference#triggers)               | `@Promptless add a GitHub PR trigger for the acme/api repo`<br />`@Promptless stop watching the #random channel`<br />`@Promptless watch all repos in the acme org for docs changes`<br />`@Promptless only trigger on the docs/ directory in acme/api` |
| [Doc collections](/docs/for-docs/reference/configuration-reference#doc-collections) | `@Promptless add the acme/docs repo as a doc collection`<br />`@Promptless limit the acme/docs collection to the docs/ folder`                                                                                                                          |
| [Context sources](/docs/for-docs/reference/configuration-reference#context-sources) | `@Promptless remove the Notion context source`                                                                                                                                                                                                          |
| [Policies](/docs/for-docs/reference/configuration-reference#policies)               | `@Promptless send suggestion notifications to #docs-review`<br />`@Promptless turn on auto-create PRs for the acme/docs collection`                                                                                                                     |

For every field, see the [Configuration reference](/docs/for-docs/reference/configuration-reference).

## Restrict who can change configuration from chat

By default, anyone who can mention Promptless in a connected Slack or Microsoft Teams channel can ask it to change your configuration. Editing on the [Configuration page](/docs/for-docs/reference/configuration-reference#configuration-editor) is limited to organization admins.

To limit chat changes to specific people:

<Steps>
  1. Open `PROMPTLESS.md` in your [Agent Knowledge Base](/docs/for-docs/get-the-most-out/agent-knowledge-base).

  2. Add an allowlist of the usernames or handles allowed to change configuration through chat.

  3. Select **Save**.
</Steps>

When an allowlist is present, Promptless makes configuration changes from chat only for the listed users.
