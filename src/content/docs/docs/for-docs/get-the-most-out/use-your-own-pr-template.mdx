## Overview

Documentation PRs from Promptless fit your team's review process when they follow the same template as every other PR in the repository. Reviewers find the summary, the verification notes, and the checklist where they expect them. When your documentation repository has a pull request template, or a GitLab merge request template, Promptless writes each documentation PR description to that template.

## Where Promptless looks for your template

Promptless reads your template from the repository's default branch, at these locations:

| Platform | Template locations                                                                                                                                                                      |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GitHub   | `pull_request_template.md`, or any `.md` file in a `PULL_REQUEST_TEMPLATE/` directory. Either can be at the repository root, in `docs/`, or in `.github/`. Names aren't case-sensitive. |
| GitLab   | Any `.md` file in `.gitlab/merge_request_templates/`.                                                                                                                                   |

A GitHub repository with no template of its own uses the default template from your organization's public `.github` repository. When a repository has more than one template, Promptless uses the one whose subject matches the change.

## Know how Promptless fills in your template

Promptless writes one description for each suggestion. It saves that description on the suggestion and uses it as the PR or merge request body. In that description, Promptless:

- Keeps your template's headings and fills them with why the docs changed, what changed, and how Promptless verified the change.
- Checks only the checklist items the change satisfies.
- Removes the instructions your template gives to the person who fills it in.

Suggestion descriptions follow the template when automatic PR creation is off, too. A PR you later create from the dashboard starts from the filled-in template. An existing suggestion picks up the template the next time Promptless updates its description.

By default, the PR body also carries generated extras. An "Open in Promptless" link comes before your filled-in template. The [trigger events](/docs/for-docs/connect/doc-locations/github-repos#trigger-events-in-pull-request-descriptions) and a tip come after it. To have the PR body hold only your filled-in template, open the **Policies** tab on the [Configuration page](https://app.gopromptless.ai/configuration). Turn on **Skip Promptless extras in PR descriptions**, or set [`publishing.suppress_pr_description_extras`](/docs/for-docs/reference/configuration-reference#policies) to `true` in `promptless.yaml`.

## Link each PR to its suggestion

To link a PR to its suggestion in the Promptless dashboard, add `[Open in Promptless]({suggestion_url})` to your template where you want the link. When Promptless saves a suggestion description, it replaces `{suggestion_url}` with the suggestion's dashboard URL. It also replaces the placeholder in a PR description you edit before you create the PR from the dashboard. For how this link works with the extras setting, see [Publishing policy fields](/docs/for-docs/reference/configuration-reference#policies).

### Ask Promptless for the link instead

Teammates who open PRs by hand get the same template, and the placeholder link doesn't work in their PRs. To keep the placeholder out of your template, ask Promptless for the link. You can ask anywhere you already work with Promptless, such as in a Slack message, a PR comment, or a dashboard comment. For example: "End each PR description with an Open in Promptless link." Promptless saves the request in your [Agent Knowledge Base](/docs/for-docs/get-the-most-out/agent-knowledge-base) and follows it on every documentation PR. You can also add the request to `PROMPTLESS.md` in the Knowledge Base yourself.
