Self-hosting runs Promptless on your own infrastructure, so you control your data, security, and compliance. It suits organizations with strict data governance policies or regulatory compliance needs, and teams that want full control over their documentation automation infrastructure. This page explains what self-hosting gives you, the deployment options, and what you need before you start.

## Use cases

- Your data governance policy requires documentation, code analysis, and generated content to stay inside your infrastructure.
- Your environment is air-gapped, or Promptless must run inside your VPC with your own networking and security groups.
- You need Promptless to use your own authentication systems and LLM deployments, and to follow your own maintenance windows and backup policies.

## Why self-host Promptless?

Self-hosting gives enterprise organizations these benefits:

| Area                   | Benefit                                                                                        |
| ---------------------- | ---------------------------------------------------------------------------------------------- |
| Data control           | Your documentation, code analysis, and generated content never leave your infrastructure.      |
| Security               | Promptless runs within your existing security perimeter, with your own authentication systems. |
| Compliance             | Meet strict regulatory requirements such as HIPAA, SOC 2, GDPR, or FedRAMP.                    |
| Air-gapped deployments | Promptless supports isolated environments with no external access.                             |
| Custom authentication  | Integrate with your existing SAML, OIDC, or Active Directory systems.                          |
| Network integration    | Deploy within your VPC, with custom networking and security groups.                            |
| Resource control       | Scale compute and storage to your needs.                                                       |
| Custom LLM models      | Use your own fine-tuned models or private LLM deployments.                                     |
| Deployment flexibility | Choose your cloud provider or on-premises infrastructure.                                      |
| Maintenance windows    | Control when updates and maintenance happen.                                                   |
| Monitoring integration | Use your existing observability and alerting systems.                                          |
| Backup strategies      | Apply your organization's backup and disaster recovery policies.                               |

## Prerequisites for self-hosting

Before you begin a self-hosted deployment, you need:

- An Enterprise license. Self-hosting is available only to Enterprise customers.
- Administrative access to your target deployment environment.
- Infrastructure experience, or dedicated DevOps resources.
- A completed security and compliance review of the deployment architecture.
