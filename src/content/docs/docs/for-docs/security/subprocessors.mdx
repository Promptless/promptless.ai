This page lists the third-party subprocessors behind the Promptless documentation automation service, for a vendor or security review. It also lists the language model options Promptless supports. For more detail about security practices, data handling, or privacy commitments, email [security@gopromptless.ai](mailto\:security@gopromptless.ai) to schedule a call with the team.

## Current subprocessors

Promptless uses these subprocessors to deliver its core service:

| Subprocessor              | Category                    | What Promptless uses it for                                                                                                                                        |
| ------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Amazon Web Services (AWS) | Infrastructure and hosting  | Primary cloud infrastructure: EKS, EC2, S3, RDS (Aurora), and Lambda. The primary data center location is us-east-2, with secondary locations in other US regions. |
| Clerk                     | Authentication and security | User authentication, SSO, identity management, and security token services.                                                                                        |
| DataDog                   | Monitoring and analytics    | Infrastructure monitoring, application performance monitoring, log management, and security monitoring.                                                            |
| Sentry                    | Monitoring and analytics    | Error tracking and monitoring.                                                                                                                                     |

## Language models and AI infrastructure providers

Promptless is model-agnostic. By default, cloud-hosted customers access models through AWS Bedrock. Promptless may recommend models for different parts of the documentation process, based on what produces the best output for each. You make the final choice of architecture. These model options are available:

| Model option                                                      | Available to                       |
| ----------------------------------------------------------------- | ---------------------------------- |
| AWS Bedrock                                                       | Default for cloud-hosted customers |
| Multiple language models, including open-source and custom models | All customers                      |
| Switching between model providers                                 | All customers                      |
| Custom model integration                                          | All customers                      |
| Cloud-provider-hosted model deployments                           | Enterprise customers               |
| Customer-managed model deployments                                | Enterprise customers               |
| Custom model fine-tuning                                          | Enterprise customers               |
| Model performance monitoring and optimization                     | Enterprise customers               |
| Dedicated model resources                                         | Enterprise customers               |

Whatever the model, Promptless does not use customer data to pre-train or fine-tune language models.
