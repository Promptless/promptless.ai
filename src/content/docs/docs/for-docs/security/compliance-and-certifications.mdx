Promptless holds SOC 2 Type II certification, runs annual third-party penetration tests, and notifies customers of security incidents that affect their data. This page collects those details, along with audit logging and session management, for a security or vendor review. It also lists which reports you can request and where to send each request.

## Use cases

- Answer a vendor questionnaire's certification, penetration testing, and incident response questions.
- Request the SOC 2 report or a penetration test summary for your security team.
- Add your security team as a contact for incident notifications.
- Confirm where to set session timeout policies, such as a 24-hour expiry, before you roll Promptless out.

## SOC 2 compliance

Promptless maintains SOC 2 Type II certification. The SOC 2 report covers:

- Security controls and access management
- Data encryption practices
- Incident response procedures
- Change management processes
- Monitoring and logging capabilities

To request a copy of the SOC 2 report, email [help@gopromptless.ai](mailto\:help@gopromptless.ai).

## Penetration testing

Independent security firms run third-party penetration tests on Promptless every year. These assessments evaluate infrastructure, application security, and data protection controls.

Enterprise customers can request a penetration test summary report from [help@gopromptless.ai](mailto\:help@gopromptless.ai).

## Security incident notification

If a security incident affects customer data, Promptless notifies you as follows:

| Aspect     | What happens                                                                                              |
| ---------- | --------------------------------------------------------------------------------------------------------- |
| Timing     | Promptless notifies affected customers within 72 hours of confirming that an incident affects their data. |
| Recipients | Organization administrators and any designated security contacts on file receive the notification.        |
| Content    | A description of the incident, the affected data, the remediation steps taken, and recommended actions.   |

To add a security contact for incident notifications, such as a security team email address, email [security@gopromptless.ai](mailto\:security@gopromptless.ai).

## Audit logging

Promptless provides audit logging for enterprise customers. Audit logs capture security-relevant events, including:

- User authentication events
- Administrative actions, such as team member changes and role changes
- Integration configuration changes
- API key creation and revocation

To request an audit log export, enterprise customers email [help@gopromptless.ai](mailto\:help@gopromptless.ai). Exports come in standard formats that SIEM tools can ingest.

## Session management

Who controls session duration depends on how your users sign in:

| Sign-in method                      | Who controls sessions                                                                                                                     |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Enterprise SSO through SAML or OIDC | Your identity provider. Set session expiry, idle timeouts, and re-authentication requirements in your identity provider's settings.       |
| Google or GitHub sign-in            | The authentication provider. For details on session timeout behavior, email [security@gopromptless.ai](mailto\:security@gopromptless.ai). |

To enforce a specific session timeout policy, such as a 24-hour expiry, use [enterprise SSO](/docs/for-docs/security/single-sign-on). Then set the policy in your identity provider.
