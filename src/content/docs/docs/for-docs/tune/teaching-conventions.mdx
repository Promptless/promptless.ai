Feedback on a Promptless suggestion does two things at once. It fixes the suggestion in front of you. When you save it, it also teaches Promptless a durable convention that it applies to every future suggestion. You can give feedback from the Promptless dashboard in three ways: chat requests, line comments, and close feedback. You can also give it directly in a GitHub PR comment. Every method lets you request changes on the suggestion you're reviewing. Some also let you save that preference so Promptless applies it to future suggestions.

See [Giving feedback to Promptless](/docs/for-docs/work-the-queue/giving-feedback) to pick the method that fits your situation.

## 1. Ask Promptless in the chat

Use the chat on any suggestion to request updates. Type your feedback in the composer at the bottom of the chat and send it. Put several pieces of feedback in one message, and Promptless addresses them all together. Keep the Promptless toggle beside the composer on, which is the default, so Promptless acts on the message. With the toggle off, the message is a comment for your team only.

While the chat is empty, the composer offers example requests to start from. One example reads "Make the tone more conversational, and do that for all future suggestions too." As it shows, you can ask in the same message for Promptless to apply your feedback to future suggestions. To reply to Promptless, send another message. See [Ask Promptless for changes](/docs/for-docs/work-the-queue/web-interface#ask-promptless-for-changes) for the full composer controls.

## 2. Comment on lines

Give feedback on specific lines within a suggestion's diff. Select text in the diff, or select line numbers with the gutter button. Then choose where to write your feedback:

- With the chat shown, select **Add to chat**. The lines attach to your next chat message.
- With the chat hidden, select **Comment** and write in the form that opens on the diff. Keep **Send to Promptless** checked for Promptless to act on the comment.

Either way, the comment becomes a thread on those lines. Line comments are separate from GitHub's inline comments and appear only in the Promptless web interface. See [Comment on lines](/docs/for-docs/work-the-queue/web-interface#comment-on-lines) for replying to and resolving threads.

## 3. Close suggestion feedback

When closing a suggestion, provide feedback about why you're rejecting it. This helps Promptless improve future suggestions.

<img src="https://promptless-customer-doc-assets.s3.us-east-2.amazonaws.com/docs-images/org_3DaVKUzHgjyjaODgCPaDmjXezqp/close-suggestion-feedback-7f0b6b1d.png" alt="Close suggestion dialog with reason checkboxes and optional feedback field" />

Select one or more reasons:

- "I copied this change into my docs editor"
- "This change is incorrect"
- "This change is too insignificant"
- "This change was covered in another Promptless suggestion"
- "This is already in my docs"
- "This change is self-explanatory and doesn't need docs"

You can also provide additional context in the feedback field. Check "Remember this feedback for future suggestions" to save your preferences.

## 4. GitHub PR comments

After Promptless opens a documentation PR, you can leave feedback directly in GitHub. GitHub comments are separate from dashboard feedback. They won't appear in the Promptless web interface, but Promptless will still process them. Tag @Promptless in any line comment to request changes.

<Aside type="note">
  You can also @mention Promptless in comments on source code PRs to request documentation updates. See [Request documentation via PR comments](/docs/for-docs/connect/triggers/github-prs#request-documentation-via-pr-comments) for details.
</Aside>

Promptless reads all previous comments in the thread to understand context. You can give brief instructions like "same change here" or "apply this to the other sections too."

## How feedback improves future suggestions

Every piece of feedback you submit helps Promptless learn your preferences. When you request changes, reject suggestions with explanations, or edit proposed content, Promptless updates its understanding of your documentation standards, writing style, and content preferences.
