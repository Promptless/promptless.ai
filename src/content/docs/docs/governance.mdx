Promptless for Agent Instructions governs the skills, subagents, hooks, commands, rules, and MCP configurations your fleet of coding agents runs on. It collects evidence from real agent sessions, finds where those instructions fail, and opens reviewed pull requests that fix them.

Semgrep, Snyk, and Wiz watch the code your fleet ships; Vanta watches the controls behind it. Promptless for Agent Instructions is that same security and observability posture applied to the instructions your agents read. The instruction files decide what your agents do, yet they drift out of a review process the moment they leave the pull request that added them.

## The problem it solves

Agent instructions rot the way any shared configuration rots. A skill that assumed a tool exists keeps running after the tool is renamed. A rule written for one repository misfires across the fleet. Nobody sees the failure because it happens inside thousands of individual agent sessions, not in a place a reviewer looks. Promptless closes that gap: it reads what actually happened in those sessions, ties each failure back to the specific instruction that caused it, and proposes the fix as a pull request against the repository that owns the instruction.
