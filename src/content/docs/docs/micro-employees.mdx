## Overview

A Promptless micro-employee is an agent that owns one ongoing responsibility for your team, such as triaging support requests or keeping a runbook current. It works in the systems you connect it to and keeps its notes in your organization's Knowledge Base.

With the Promptless micro-employees connector in Claude.ai, you do all of the setup from a conversation:

- Create a micro-employee and describe what it owns.
- Connect it to GitHub and to apps such as Sentry or Notion.
- Send it requests and read its replies.

This page covers adding the connector, approving the connection, and each of those tasks. To work on documentation from Claude.ai instead, see [Use Promptless from Claude.ai or ChatGPT](/docs/for-docs/work-the-queue/claude-and-chatgpt).

## Before you start

- A Claude.ai account on any plan. The Free plan allows one custom connector. On a Team or Enterprise plan, an Owner adds the connector for the organization first.
- A Promptless account. If you don't have a Promptless organization, you create one when you approve the connection.
- The admin role in your Promptless organization, to create micro-employees. Any member can connect apps and talk to micro-employees that already exist.

## Server details

| Item                  | Value                                                                         |
| --------------------- | ----------------------------------------------------------------------------- |
| Server URL            | `https://api.gopromptless.ai/mcp/micro-employees`                             |
| Authentication        | OAuth 2.1 authorization code flow with PKCE (`S256`)                          |
| Client registration   | Dynamic client registration. No client ID or client secret is necessary.      |
| Access token lifetime | 8 hours. Claude refreshes the token automatically.                            |
| Connection lifetime   | 90 days from approval. After 90 days, you approve the connection again.       |
| Data scope            | One Promptless organization, which you select on the approval page            |
| Privacy policy        | [Promptless privacy policy](/docs/for-docs/security/privacy-policy)           |
| Support               | [help@gopromptless.ai](mailto\:help@gopromptless.ai)                          |

This server is separate from the Promptless documentation connector. A connection that you approve for the documentation connector doesn't work here, so add and approve this connector on its own.

## Add the connector to Claude.ai

These steps are for individual plans: Free, Pro, and Max.

<Steps>
  1. In Claude.ai, go to **Customize** > **Connectors**.

  2. Select **+**.

  3. Select **Add custom connector**.

  4. In the name field, enter `Promptless micro-employees`.

  5. In the URL field, enter `https://api.gopromptless.ai/mcp/micro-employees`.

  6. Select **Add**. Claude registers itself with Promptless, so leave **Advanced settings** empty.

  7. On the **Promptless micro-employees** connector, select **Connect**. A Promptless tab opens, where you [approve the connection](#approve-the-connection).
</Steps>

On a Team or Enterprise plan, an Owner adds the connector in **Organization settings** > **Connectors** with the same URL. Each member then selects **Connect** on it in **Customize** > **Connectors** and approves their own connection.

To use the connector, turn on **Promptless micro-employees** from **+** > **Connectors** in a conversation.

## Approve the connection

Promptless uses OAuth, so Claude never receives your Promptless password.

<Steps>
  1. In the Promptless tab, sign in or create a Promptless account. The approval page opens.

  2. Check the web address that the page shows. For Claude, it's `claude.ai` or `claude.com`. If it doesn't match, select **Cancel**.

  3. In the organization picker, select the Promptless organization to connect. If you aren't a member of an organization, enter a name for a new one. You become its admin.

  4. Select **Authorize as \{your email}**.
</Steps>

The tab returns you to Claude.ai, and the connector shows as connected. The connection has your access in the organization that you selected. With it, Claude can create micro-employees as you, send them messages, and read their replies. Claude can also see which systems each micro-employee is connected to.

A new organization starts a 14-day free trial when you approve. To keep using micro-employees after the trial ends, an organization admin adds a card in **Settings** > **Billing** on the [Promptless dashboard](https://app.gopromptless.ai). Until an admin adds a card, Claude can't create micro-employees or send them messages, and messages sent before the trial ended wait.

## Create a micro-employee

Ask Claude to set up a micro-employee, for example: `Set up a Promptless micro-employee that triages new Sentry issues and opens a GitHub issue for each regression.`

Claude asks what the micro-employee should own before it creates one. Give it:

- A job title, such as `Support Engineer`.
- Its responsibilities, in Markdown. Say what it owns, how it should work, and what it should ask a person about.

Promptless saves the micro-employee's configuration and instructions in your organization's Knowledge Base and starts it. If your organization has no Knowledge Base, Promptless creates one. An organization can have up to 10 micro-employees.

A new micro-employee can't reach any of your systems yet. Claude shows a checklist of what to connect next.

## Connect a micro-employee to your systems

You connect systems in the browser, so passwords, API keys, and tokens never pass through the conversation. Ask Claude what a micro-employee is connected to, for example: `What is my Support Engineer connected to?` Claude shows one entry for each system:

- The Knowledge Base, which Promptless provides when it creates the micro-employee.
- GitHub. If your organization hasn't installed the Promptless GitHub App, Claude gives you a link to install it.
- Each app that the micro-employee uses, such as Sentry, Notion, or another remote MCP server.
- Slack, which is optional. To give a micro-employee its own Slack app, [contact Promptless support](mailto\:help@gopromptless.ai). Without Slack, it asks its questions in the Claude conversation where you gave it the work.

### Connect an app

To connect an app, ask Claude for a link, for example: `Connect Sentry to my Support Engineer.`

<Steps>
  1. Open the link that Claude gives you. A Promptless page opens.

  2. Sign in with an account in the micro-employee's Promptless organization.

  3. Check that the page names the micro-employee and app that you asked for. If you didn't ask for this link, close the page.

  4. In **Connection name**, enter a name for this account. Other members of your organization see the name, so choose a different name for each account of the same app.

  5. Enter the app's credentials.

  6. Select the **Connect** button for the app, such as **Connect Sentry**. Promptless checks the credentials with the app before it saves them.
</Steps>

The page shows that the micro-employee can use the app. Return to Claude, and ask the micro-employee to continue.

A link works for 24 hours. A micro-employee can use more than one account of the same app. Each link adds another connection.

### Reconnect a broken app

When an app's credentials stop working, the checklist marks that app, and Claude gives you a reconnect link. The reconnect page replaces the credentials of that connection for every micro-employee that uses it. Only the person who created the connection or an organization admin can reconnect it.

## Talk to a micro-employee

Ask Claude to send the micro-employee a message, for example: `Ask my Support Engineer to look at today's new Sentry issues.` Claude sends the message, then waits and shows each reply as it arrives. A micro-employee often sends a short acknowledgement first and its result later.

Claude follows a conversation for up to 10 minutes after the latest message. For longer work, Claude tells you that the micro-employee is still working. Come back later and ask, for example, `Show my recent micro-employee conversations.` Claude lists them, most recently active first, and you can continue any of them.

A conversation belongs to the person who started it. Other members of your organization can't read or continue it.

## Tools

Claude selects the tool that matches your request. Each tool tells Claude whether it changes data. Claude asks you to approve the first call to each tool. To change this, go to **Customize** > **Connectors**, select **Promptless micro-employees**, and set a tool to **Ask each time**, **Always allow**, or **Blocked**.

| Tool                                | Action                                                                                          | Type         |
| ----------------------------------- | ----------------------------------------------------------------------------------------------- | ------------ |
| `list_micro_employees`              | Lists the organization's micro-employees and whether you can create another one.                | Read-only    |
| `get_micro_employee_setup`          | Shows the systems a micro-employee can reach, with a link for each missing system.              | Read-only    |
| `connect_micro_employee_app`        | Creates a 24-hour link that connects one app to a micro-employee.                               | Read-only    |
| `wait_for_micro_employee_reply`     | Waits up to 30 seconds for new messages in a conversation.                                      | Read-only    |
| `list_micro_employee_conversations` | Lists the conversations you started, most recently active first.                                | Read-only    |
| `create_micro_employee`             | Creates and starts a micro-employee. Only an organization admin can use it.                     | Changes data |
| `send_message_to_micro_employee`    | Starts or continues a conversation with a micro-employee.                                       | Changes data |
| `message_promptless_support`        | Sends a problem report to the Promptless team.                                                  | Changes data |

The link tools are read-only because a link changes nothing until a person opens it and completes the page.

## Reconnect or disconnect

A connection lasts 90 days from approval. After 90 days, select **Connect** on **Promptless micro-employees** in **Customize** > **Connectors**, and approve the connection again.

To disconnect, go to **Customize** > **Connectors**, open the menu next to **Promptless micro-employees**, and select **Remove**.

## Troubleshooting

- **Claude says that an organization admin must create micro-employees**: You're a member, not an admin, of the organization. Ask an admin of the Promptless organization to create the micro-employee. You can then talk to it and connect apps for it.
- **The connect page says that the link is incomplete or has expired**: Links work for 24 hours. Ask Claude for a new link, and open all of it, including everything after the `#` sign.
- **The connect page says that you aren't a member of the organization**: Sign in with an account in the micro-employee's organization. If you don't have one, ask a member to invite you.
- **The connect page says that Promptless couldn't reach the app**: Check the credentials, and connect again.
- **Claude says that the micro-employee is paused**: A paused micro-employee doesn't take messages. Ask Claude to message Promptless support, and the Promptless team can resume it.
- **Claude says that the free trial ended**: An organization admin adds a card in **Settings** > **Billing** on the [Promptless dashboard](https://app.gopromptless.ai). Micro-employees then start on the messages that waited, and Claude can send new ones.
- **Claude says that setup is incomplete after it creates a micro-employee**: The micro-employee exists but didn't start. Ask Claude to message Promptless support with the micro-employee's ID so the team can finish its setup.
- **The approval page says that the request is no longer valid**: Approval requests expire after 30 minutes. Select **Connect** in Claude.ai again.

For other problems, send an email to [help@gopromptless.ai](mailto\:help@gopromptless.ai).
