## Overview

The `marketing:image` script generates the marketing composites Promptless uses in app listings, such as Microsoft Teams and Slack. Each composite has a headline and the Promptless logo on a dark gradient, with a product screenshot floated on the right. Listings require exact pixel dimensions, so the script renders each image to a set size and compresses it under a file-size cap.

Generate a new composite when a listing needs one, and regenerate the current set after an embedded screenshot changes. Composites live in `public/assets/marketing/`. For logos and brand colors, see the [Media kit](/docs/media-kit).

## Before you start

- A local clone of the `promptless.ai` repository with its npm dependencies installed. The script runs in Node and needs no browser.
- The product screenshot to embed, such as one from `public/assets/`.

## Generate a marketing image

1. From the repository root, run the script with a headline, a screenshot, and an output path:

   ```bash
   npm run marketing:image -- \
     --headline "Turn conversations|into docs updates" \
     --screenshot public/assets/integrations-page.png \
     --out public/assets/marketing/teams-listing.png \
     --eyebrow "Promptless for Microsoft Teams"
   ```

   Put `|` or `\n` in the headline to force a line break. Otherwise, the headline wraps to fit its column. The output defaults to 1366×768 pixels under a 1024 KB cap, so a minimal run needs only `--headline`, `--screenshot`, and `--out`.

2. Check the summary that the script prints. It lists the output path, the pixel dimensions, the file size, and the compression format.

   If no PNG fits under the cap, the script writes a `.jpg` file instead. If the JPEG is still over the cap, the script prints a warning and exits with code 2.

3. Add the image and the command that produced it to [Regenerate the current set](#regenerate-the-current-set).

### Script options

The script accepts these options:

| Flag           | Default                         | Notes                                      |
| -------------- | ------------------------------- | ------------------------------------------ |
| `--headline`   | *(required)*                    | `\|` or `\n` for hard breaks; wraps to fit |
| `--screenshot` | *(required)*                    | Product screenshot to embed                |
| `--out`        | *(required)*                    | Output path (`.jpg` if it must fall back)  |
| `--eyebrow`    | *(none)*                        | Small accent label above the headline      |
| `--logo`       | `public/assets/logo_darkbg.svg` | Any SVG or PNG file                        |
| `--width`      | `1366`                          | Exact output width                         |
| `--height`     | `768`                           | Exact output height                        |
| `--max-kb`     | `1024`                          | Size cap; triggers compression fallbacks   |
| `--scale`      | `2`                             | Supersample factor for crispness           |
| `--bg-top`     | `#15171d`                       | Gradient color at the top (almost black)   |
| `--bg-bottom`  | `#000000`                       | Gradient color at the bottom (pure black)  |
| `--fg`         | `#ffffff`                       | Headline color                             |
| `--accent`     | `#8ea2ff`                       | Eyebrow color                              |

Paths resolve relative to the repository root.

### How the script renders

[Satori](https://github.com/vercel/satori) lays out a flexbox tree, so the headline wraps within its column, and emits an SVG with text as vector paths. [`@resvg/resvg-js`](https://github.com/yisibl/resvg-js) rasterizes the SVG with the vendored static Inter TTFs. Then `sharp` downscales the render to the exact size and compresses it. It tries a maximum-effort PNG, then a palette-quantized PNG, then a JPEG, and keeps the first result under the cap. Full notes are in `scripts/marketing-image/README.md`.

## Regenerate the current set

The composites embed screenshots from `public/assets/`. When Promptless updates one of those screenshots, the composites that embed it don't change until you rerun their commands. The command after each image regenerates it.

  --headline "Keep your docs|in sync, automatically" \

### Vercel Marketplace gallery

The Vercel Integration Console takes one to eight gallery images at 16:9, 1920×1080. These two composites pass `--width` and `--height` to override the 1366×768 default. Upload them in the order below: what starts a docs update, then what you review.

A third image, showing the connected integrations, is still missing. It needs a capture from a clean workspace, for the reasons given in [#902](https://github.com/Promptless/promptless.ai/pull/902).

  <img src="/assets/marketing/vercel-code-ships.png" alt="Marketing composite: Your docs update when your code ships" />

  <figcaption>vercel-code-ships.png</figcaption>
</figure>

```bash
npm run marketing:image -- \
  --eyebrow "Promptless Starport" \
  --headline "Your docs update|when your code ships" \
  --screenshot public/assets/promptless_1_listen.png \
  --out public/assets/marketing/vercel-code-ships.png \
  --width 1920 \
  --height 1080
```
