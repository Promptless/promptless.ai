The worker reads its configuration from environment variables, all prefixed `INSTRUCTION_HUB_`. This page covers the variables you need to start and serve it, plus the common optional settings. For the complete enumerated set — analysis variables, Helm observability values, and the credential and endpoint tables — see [Worker configuration and data](/docs/governance/reference/worker-configuration-and-data).

## Required to start and serve

Set these seven variables before the worker starts:

| Variable                                 | Purpose                                                                       |
| ---------------------------------------- | ----------------------------------------------------------------------------- |
| `INSTRUCTION_HUB_RUNTIME_BASE_URL`       | The hosted control-plane base URL the worker calls.                           |
| `INSTRUCTION_HUB_INSTALL_TOKEN`          | The install token the worker authenticates to hosted Promptless with. Secret. |
| `INSTRUCTION_HUB_DEPLOYMENT_NAME`        | The name of this deployment.                                                  |
| `INSTRUCTION_HUB_DEPLOYMENT_INSTANCE_ID` | The identifier of this deployment instance.                                   |
| `INSTRUCTION_HUB_CONFIG_HASH`            | The hash of the deployed configuration.                                       |
| `INSTRUCTION_HUB_CUSTOMER_POSTGRES_DSN`  | The DSN for the Postgres database you own. Secret.                            |
| `INSTRUCTION_HUB_TRACE_OBJECT_S3_BUCKET` | The S3 bucket that holds trace slices and objects.                            |

<Aside type="caution">
  `INSTRUCTION_HUB_INSTALL_TOKEN` and `INSTRUCTION_HUB_CUSTOMER_POSTGRES_DSN` are secrets. Supply them from your secret store rather than plain chart values or a checked-in file.
</Aside>

## Common optional settings

Adjust these to fit how the worker ingests and runs. For their default values, see the optional ingest and runtime table in [Worker configuration and data](/docs/governance/reference/worker-configuration-and-data):

| Variable                                 | Purpose                     |
| ---------------------------------------- | --------------------------- |
| `INSTRUCTION_HUB_BIND_HOST`              | The bind address.           |
| `INSTRUCTION_HUB_PORT`                   | The serving port.           |
| `INSTRUCTION_HUB_STORAGE_BACKEND`        | The trace-object storage backend. |
| `INSTRUCTION_HUB_TRACE_OBJECT_S3_PREFIX` | A key prefix in the bucket. |
| `INSTRUCTION_HUB_MAX_TRACE_BATCH_BYTES`  | The maximum uploaded trace-batch size. |
| `INSTRUCTION_HUB_LOG_LEVEL`              | The log verbosity.          |

To turn on analysis after the worker is serving, set the analysis variable group described in [Enable the Friction Analyzer](/docs/governance/deploy-the-worker/enable-the-friction-analyzer).
