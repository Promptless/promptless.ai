Answers to common questions about Promptless for Agent Instructions. Each answer links to the page that covers the topic in full.

## Common questions

### What leaves my host?

Your host encrypts native trace bytes to your worker's deployment key and sends the ciphertext through the Promptless relay. Hosted Promptless can route the encrypted batch but cannot decrypt its trace content. See [Trust and data model](/docs/governance/start-here/trust-and-data-model).

### Which agents does Promptless support?

Promptless compiles plugins for four targets (Claude, Codex, Cursor, and Gemini) and ingests session traces from three sources (Claude Code, Claude Desktop, and Codex). See [Supported agents](/docs/governance/reference/supported-agents).

### What is the gate before a fix merges?

Human review. A remediation agent opens a pull request against your Instruction Hub, and a person reviews and merges it. There is no automated evaluation gate today. See [Remediate findings](/docs/governance/findings-and-remediation/remediate-findings).

### Where does the pig toolchain live?

The `pig` toolchain is the public Python package `promptless-instruction-hub`, in the `Promptless/instruction-hub-toolchain` repository. It runs in your continuous-integration pipeline, not as a service. See [Set up your Instruction Hub](/docs/governance/get-started/set-up-your-instruction-hub).

### What does the worker need to run?

An existing Kubernetes cluster and a one-time `plih_` bootstrap token. The default Terraform modules create managed Postgres, object storage, secret storage, and workload identity in your AWS, GCP, or Azure account. Before the worker can produce findings, you also configure a model provider. See [Install the analyzer worker](/docs/governance/deploy-the-worker/deploy-the-analyzer-worker) and [Configuration reference](/docs/governance/deploy-the-worker/configuration-reference).

### Does hosted Promptless see my GitHub credentials?

No. The worker never receives GitHub credentials. Findings are projected to GitHub issues by hosted Promptless, and remediation runs with a repository-scoped token in an isolated agent. See [Trust and data model](/docs/governance/start-here/trust-and-data-model).

## Get support

If you do not see your question answered here, reach our support team at [help@gopromptless.ai](mailto\:help@gopromptless.ai). During onboarding, we also set up a shared Slack Connect channel between your team and ours for direct support.
