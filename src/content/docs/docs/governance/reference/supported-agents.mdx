Promptless for Agent Instructions works with two distinct sets of agents: the targets it compiles plugins for, and the sources it ingests traces from. This page lists both as they ship today.

## Compile targets

`pig` compiles a hub to plugins for four targets:

- Claude
- Codex
- Cursor
- Gemini

See [Publish and install plugins](/docs/governance/get-started/publish-and-install-plugins) for how each target is packaged.

## Ingest sources

The host runtime ingests native session traces from three sources:

- Claude Code
- Claude Desktop
- Codex

See [Trace object and sources](/docs/governance/reference/trace-object-and-sources) for each source's capture glob and the object built from it.
