Two command-line tools drive Promptless for Agent Instructions: `pig` compiles and publishes the Instruction Hub in CI, and `promptless-host-runtime` runs on each fleet host. This page lists the subcommands of both.

## `pig`

`pig` — also invoked as `promptless-instruction-hub` — requires Python 3.11 or later. It runs in CI and never as a long-running service.

| Subcommand | Purpose                                                                                                        |
| ---------- | -------------------------------------------------------------------------------------------------------------- |
| `init`     | Scaffold a new hub with `hub.yaml` and the `packages/` layout.                                                 |
| `scan`     | Discover assets and show how they map to packages.                                                             |
| `validate` | Check the manifest and asset references.                                                                       |
| `verify`   | Compile into a temporary directory to confirm the hub builds cleanly.                                          |
| `build`    | Write compiled output to `dist/` and per-target marketplace manifests. Pass `--check` to fail on stale output. |
| `status`   | Report the current build and release state.                                                                    |

See [Compile and publish](/docs/governance/get-started/compile-and-publish) for how these run in the release workflows.

## `promptless-host-runtime`

The `pig` package carries `promptless-host-runtime`, which the toolchain injects into the compiled Claude and Codex plugins. Installing those plugins places it on each host.

| Subcommand | Purpose                                                                                   |
| ---------- | ----------------------------------------------------------------------------------------- |
| `ensure`   | Confirm the runtime is present and ready.                                                 |
| `collect`  | Upload new trace bytes past the local ledger watermark.                                   |
| `enroll`   | Enroll the host with `--host <claude\|codex\|claude-desktop>` through a browser approval. |
| `status`   | Report whether the host is enrolled and collecting.                                       |
| `reset`    | Clear the host's cached enrollment state.                                                 |
| `version`  | Print the runtime version.                                                                |

See [Enroll a host](/docs/governance/get-started/enroll-a-host) for the enrollment flow.
