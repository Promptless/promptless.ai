Instruction Hub governs the instructions your coding agents actually run on — skills, agent definitions, `AGENTS.md` and `CLAUDE.md` files, MCP configuration, hooks, and commands. It reads the sessions those instructions produced, identifies where they caused friction, and proposes fixes as pull requests.

## The two halves

Instruction Hub runs across a boundary you control.

- **The worker** is deployed in your environment. It receives native session ledgers, stores them in your own S3 and Postgres, runs analysis, and holds every raw artifact.
- **Hosted Promptless** issues install tokens, signs the enrollment policy your hosts read, and stores findings, evidence, and remediation records.

## What stays in your environment

Raw trace bodies, digests, prompts, tool activity, model and provider traffic, shell activity, repository contents, and credentials never leave your infrastructure.

What reaches hosted Promptless is the finding record, its evidence occurrences, and a limited trace projection carrying identity, host attribution, lifecycle counters, and analysis status.
