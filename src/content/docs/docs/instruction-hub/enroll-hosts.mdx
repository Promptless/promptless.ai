Every machine running a Promptless-managed agent plugin carries its own credential. There is no shared enrollment secret, and any single host can be revoked without affecting the others.

## Approving a host

<Steps>
  1. **The plugin bootstrap starts enrollment.** It reads the worker's deployment identity and opens hosted Promptless with a loopback callback URL and the host metadata it will display.

  2. **An organization member approves in the browser.** The approval page shows which machine is asking.

  3. **The bootstrap claims the credential.** Approval redirects to the local callback, and the bootstrap polls hosted Promptless for a one-time credential.

  4. **The credential is stored locally.** The plugin uses it for policy reads, check-ins, and trace uploads.
</Steps>

Sessions are one-time and time-boxed. A pending session can be approved once, an approved session can be exchanged for exactly one credential, and a consumed session cannot mint another.

## What the worker trusts

The worker holds no shared plugin secret. It validates each credential against hosted Promptless before returning policy or accepting a check-in or upload.

Authentication requires a concrete host target, so a credential minted for one host family or deployment cannot authenticate as another. Introspection also supplies the host instance ID and label the worker uses for attribution.

The worker caches only active introspection results, and only for as long as hosted Promptless says it may. Revocations and failures are never cached, so the window between revoking a host and the worker rejecting it is limited by that returned lifetime.

## Requiring a minimum host runtime version

The enrollment policy carries an optional version gate. When it is set, the worker checks the version each host reports before accepting check-ins or uploads.

- A SemVer value is treated as a minimum.
- A non-SemVer value, such as a release tag, requires an exact match.
- A missing or unsatisfied version is rejected and not recorded.

When the gate is omitted, the worker records whatever version the host reports.
