import { Aside, Card, CardGrid, LinkCard, Steps } from '@astrojs/starlight/components';

This hidden page renders the Starlight components and HTML patterns the docs use, with placeholder content. Use it to preview how they render on the site. Site search and the sitemap both exclude it.

## Fixtures

The page renders these fixtures, in this order:

| Fixture   | Renders                                                            |
| --------- | ------------------------------------------------------------------ |
| Asides    | Five `<Aside>` blocks: two `note`, two `tip`, and one `caution`    |
| Cards     | A `<CardGrid>` that holds a `<LinkCard>` and a `<Card>`            |
| Steps     | A two-item numbered list inside `<Steps>`                          |
| Accordion | An open `<details>` element with a `<summary>`                     |
| Parameter | A bold, code-formatted parameter name, its type, and a description |
| Figure    | A `<figure>` with an image and a `<figcaption>`                    |
