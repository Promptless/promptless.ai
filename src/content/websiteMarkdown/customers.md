- [How Mautic keeps docs up to date automatically](https://promptless.ai/customers/mautic.md): Mautic's docs had fallen entire release versions behind. Promptless now drafts a docs PR for each code PR on mautic/mautic, and developers and the Education Team review every one. In about four months, 129 Promptless docs PRs merged; Promptless updates averaged 27 days from code merge to docs merge, against 98 days for docs written by hand. Figures from Mautic's own post.
- [How Vellum uses Promptless to draft over 50% of their doc updates](https://promptless.ai/customers/vellum.md): feature owners request doc updates from Promptless directly. As of July 2025, 54% of Vellum's docs PRs in the last month originated from Promptless suggestions, and 60% of its product and engineering team drafted doc updates with Promptless every month.
