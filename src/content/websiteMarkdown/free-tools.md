Use these free tools to quickly catch issues in your docs.

## Agent Score

Score how well AI agents can read your docs site, from 0 to 100, using the open-source afdocs checks. Every scan gets a public report with fixes and score history. See [Agent Score](https://promptless.ai/agent-score.md).

## Broken Link Report

Scan your site and get a broken-link report by email.
