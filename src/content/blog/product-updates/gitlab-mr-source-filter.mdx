The trigger-source filter in the suggestions list now has a GitLab MRs group. Teams with multiple GitLab repositories can filter suggestions by source repository, the same way GitHub users already could.

## The problem

The suggestions list groups everything Promptless produces across your connected repositories. When you have multiple active repos, that list gets long. The trigger-source filter exists to let you narrow it down.

For GitHub users, that filter worked by repository. You could pick one GitHub repo and see only suggestions sourced from it. GitLab users didn't have that option. All GitLab-sourced suggestions showed up as an undifferentiated block with no way to isolate one project's output.

If your team manages documentation across several GitLab merge request sources, you were stuck working through the full list or finding another way to triage.

## What changed

The trigger-source filter now includes a GitLab MRs group alongside the existing GitHub group. Expand it to see your connected GitLab source repositories, and select one or more to narrow the suggestions list to those sources.

Mixed selections work too. You can filter to a specific GitLab repo and a specific GitHub repo at the same time. Those combined selections are preserved in saved, shared, and bookmarked filter URLs, so a filtered view you share with a colleague arrives with your filters applied.

## Who benefits most

Teams with multiple GitLab projects contributing to Promptless suggestions. If your organization has separate repos for different products or services, and each generates its own documentation suggestions, you can now work through one project's queue without the others cluttering the view.

It also helps teams doing a focused review push. Pick the repo that's behind on documentation, filter to it, and work through just that set.

## How to use it

No setup required. Open the suggestions list, expand the trigger-source filter, and look for the GitLab MRs group. Your connected GitLab source repositories appear there.

If you don't see a GitLab MRs group, your account may not have any GitLab merge request sources configured. See [GitLab merge request triggers](/docs/for-docs/connect/triggers) to add one.
