A new **Screenshot Updates** tab in the dashboard sidebar shows an org-wide gallery of every screenshot attached to an open suggestion. If your team uses Promptless Capture, it's the fastest way to see what's waiting without opening suggestions one by one.

## The problem

Promptless Capture regenerates screenshots when code changes affect documented UI. Those updated screenshots land on the suggestions tied to the affected docs. But there was no way to see them all together.

The only way to find out whether a suggestion had screenshot changes was to open it. Screenshot updates got missed, because they're easy to overlook in a suggestion that's otherwise about something else. A UI refresh could update ten screenshots across five suggestions, and a doc reviewer had no way to know without checking each one.

## What it does now

Screenshot Updates is a tab in the left sidebar, between Suggestions and Triggers. A count badge on the nav item shows how many screenshots are on open suggestions. The badge disappears when the count reaches zero.

Inside, screenshots are grouped by doc collection. Newest come first within each group. Each screenshot gets its own card, so a suggestion with five screenshots produces five cards. Hover or focus a card to reveal the suggestion title and the date the screenshot was captured.

![Screenshot Updates selected in the dashboard sidebar with a count badge, beside a gallery grouped by doc collection with collection headers, count chips, and screenshot thumbnail cards](https://promptless-customer-doc-assets.s3.us-east-2.amazonaws.com/docs-images/org_3DaVKUzHgjyjaODgCPaDmjXezqp/screenshot-updates-tab-11af22ad.png)

Click a card and you go directly to that screenshot's suggestion, scrolled to that specific image. From there you can compare it against the previous version and reject it if needed, or publish the suggestion to accept all the changes.

Screenshots whose suggestion isn't tied to a doc collection appear under an **Uncategorized** group. When a collection group has more screenshots than fit in the default view, it clips with a fade and shows a **Show more** toggle.

## Who benefits most

Teams that use Promptless Capture and have many open suggestions at once. The tab makes it possible to scan all pending screenshot changes in one view instead of clicking through suggestions looking for them.

Until Capture has regenerated screenshots on an open suggestion, the tab shows an empty state and the badge stays hidden.

## How to use it

The tab appears in the dashboard sidebar automatically. No configuration needed.

Go to **Screenshot Updates** in the sidebar. The count badge tells you how many are waiting. Click any card to open its suggestion.

Promptless Capture is available to Promptless customers. Reach out to [help@gopromptless.ai](mailto:help@gopromptless.ai) or via Slack to enable it for your organization.
