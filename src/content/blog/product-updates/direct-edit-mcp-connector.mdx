Promptless now has a second MCP server URL: `https://api.gopromptless.ai/mcp/with-direct-edits`. Connect Claude there and six content tools become available alongside the standard set, including two write tools. Claude can search your documentation, read individual files, edit them on an open suggestion's branch, review the full diff, and open the pull request, all in one conversation.

The standard `https://api.gopromptless.ai/mcp` endpoint stays unchanged.

## The problem

The original Promptless MCP server was read-only. From Cursor, VS Code, or any MCP-capable editor, you could submit documentation tasks and check their status. You couldn't edit the files directly.

That meant a targeted revision still followed a heavyweight loop. Spot a broken code example, a mislabeled field, or a section that needs updating after reviewer feedback? Submit a task, wait for Promptless to draft a suggestion, open the resulting PR in GitHub, review the change there. For a one-paragraph fix, that sequence adds more process than the edit warrants.

## What it does now

Connect Claude at the direct-edit URL. Six content tools become available:

- **`list_documentation_files`** — list files in the doc collection or a subdirectory
- **`read_documentation_file`** — read a file from the current suggestion branch
- **`search_documentation`** — search across files using RE2 regex syntax
- **`get_suggestion_diff`** — see a diff of everything changed so far in the session
- **`write_documentation_file`** — replace a file's full content
- **`edit_documentation_file`** — make a targeted edit within a file

Writes commit to an open suggestion's branch. Before each commit, Claude asks for confirmation. Search runs within a 10-second budget and reports any files it couldn't reach. When the editing is done, Claude can open the pull request from within the same session.

## Who benefits most

This works best for a focused scope: one page, one broken example, one section to rewrite. Writers and developers who prefer an interactive editing flow rather than submitting a task and reviewing the draft later can now close that loop from within Claude.

Teams using Promptless to trigger bulk documentation updates don't need to change anything. The standard `/mcp` endpoint handles task submission, status checks, and reading docs. The direct-edit URL is an addition, not a replacement.

## How to use it

In Claude, add a custom connector at `https://api.gopromptless.ai/mcp/with-direct-edits`. Use the same OAuth flow as the standard connector. A token authorized without a specific resource indicator works at both URLs, so connecting at the direct-edit URL doesn't require re-authorizing an existing token.

The direct-edit server also includes the `edit-documentation` workflow skill, which walks Claude through an editing session step by step.

See [Read and edit documentation directly](/docs/for-docs/connect/triggers/mcp#read-and-edit-documentation-directly) for the full setup instructions and tool reference.
