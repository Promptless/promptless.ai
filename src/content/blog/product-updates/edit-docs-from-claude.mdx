Claude can now read and edit your documentation directly, inside a Promptless suggestion branch. Connect the new direct-edit MCP URL, and your Claude conversations gain the ability to list pages, search content, edit files, review diffs, and open a pull request.

## The problem

The Promptless MCP server already let you trigger documentation runs from Claude. You could say "update the authentication page" and Promptless would queue the task. But Claude couldn't actually read your docs or touch the files. If you wanted Claude to improve a draft suggestion, rewrite a section for tone, or work through a round of edits, you had to pull content into the conversation yourself and apply changes by hand.

For teams using Claude as an active collaborator in content work, that gap added friction at exactly the moment it hurt most.

## What changed

There is now a second MCP URL:

```
https://api.gopromptless.ai/mcp/with-direct-edits
```

Connect Claude here and it gets six tools alongside the standard Promptless tools:

- **`list_documentation_files`** lists the files in your doc collection
- **`read_documentation_file`** reads a specific page
- **`search_documentation`** searches across pages using RE2 regex patterns, within a 10-second time budget
- **`get_suggestion_diff`** shows the current diff on an open suggestion branch
- **`write_documentation_file`** creates or replaces a page
- **`edit_documentation_file`** makes targeted edits to a page

All file operations work on the open suggestion's branch, not your main branch. Each write commits before it goes through, so Claude confirms what it is about to change before touching anything. When the edits are ready, Claude can open the pull request.

The standard `/mcp` URL stays unchanged. It has the same tools it always has. You only need the direct-edit URL when you want Claude to work with file content.

## Who benefits most

This is for teams that use Claude for content work, not just for triggering tasks. If you review Promptless suggestions and want Claude to take a pass at tone or consistency, you can now hand it the diff and have it make the edits on the branch. If you're drafting a new page, you can have Claude write it directly into the suggestion.

Teams with a Promptless suggestion already open get the most out of it right away. The tools work within that branch's scope, so Claude sees your actual content and makes changes in the right place.

## How to use it

In Claude, go to **Settings > Integrations** and add a custom connector. Use `https://api.gopromptless.ai/mcp/with-direct-edits` as the server URL. A Promptless API token that works with `/mcp` also works here. The token is bound to one URL only if your MCP client specifies a resource indicator during authorization; otherwise it works at both.

Once connected, you can start with a prompt like:

> "Read the authentication page on suggestion branch 1234 and rewrite the overview section for a developer audience."

Claude will find the page, read it, and make the edit on the branch. You review and merge as usual.

For details on each tool's arguments, limits, and error handling, see [Read and edit documentation directly](/docs/for-docs/connect/triggers/mcp#read-and-edit-documentation-directly).

## What's next

The direct-edit tools use more of Claude's context window than the standard server, since they're loading file content into the conversation. For ongoing monitoring and trigger tasks, `/mcp` is the lighter-weight option. Use the direct-edit URL when you need Claude to actually work with content, then switch back.

If Claude is not yet listed in the Promptless connector directory, you add it as a custom connector using the steps above.
