Promptless can now start documentation work when a LaunchDarkly feature flag changes. This is in beta.

When a flag changes, Promptless reviews documentation covering the affected behavior and opens a suggestion if anything needs updating. You can scope the trigger to a specific LaunchDarkly project, environment, or individual flag.

## The problem

Feature flags control what users see. They're also a reliable signal that documentation is about to diverge from reality: a flag flips, behavior changes, and the docs don't know. The gap closes when someone notices, or when a customer files a ticket.

Teams using LaunchDarkly typically handled this with process. A developer flips a flag and someone remembers to update the docs. Or they don't.

There was no automatic path from "flag changed" to "docs reviewed." Now there is.

## What it does now

Configure a `launchdarkly_flag` trigger in Promptless and choose what to watch: LaunchDarkly projects, environments, specific flags, or any combination. Leave a field empty to match everything in that dimension.

When a flag changes in that scope, Promptless picks it up and reviews your documentation for anything that describes the behavior the flag controls. If the docs need updating, it opens a suggestion. If they're already accurate, it records the check and moves on.

Promptless works from the flag key, project, environment, and change summary LaunchDarkly sends. It doesn't see the flag's before and after values or its targeting rules.

The trigger requires your LaunchDarkly integration to be connected first. You can do that on the Integrations page. Once connected, the trigger is available alongside your other trigger types.

## Who benefits most

This is for teams that use feature flags to roll out user-facing behavior and keep docs describing what users see. If your flags are purely internal infrastructure switches with no user-facing effect, this trigger won't have much to do.

It's also useful for teams where the person flipping flags isn't the person responsible for documentation. Automatic review removes the need to coordinate.

## How to use it

1. Create a LaunchDarkly service token and connect it on the [Integrations page](https://app.gopromptless.ai/integrations). The [LaunchDarkly integration guide](/docs/for-docs/reference/integrations/launchdarkly) lists the token permissions. Promptless creates the flag-change webhook for you.
2. On the [Configuration page](https://app.gopromptless.ai/configuration), open the **Triggers** tab and add **A LaunchDarkly flag** from the **Product & releases** group. You can also add a `launchdarkly_flag` trigger to the `triggers` section of your `promptless.yaml`.
3. Fill in at least one of **Projects**, **Environments**, or **Feature flags**. A field you leave empty matches every value. Promptless matches keys exactly as you type them and doesn't check them against LaunchDarkly, so a misspelled key never matches.

See [LaunchDarkly triggers](/docs/for-docs/connect/triggers/launchdarkly) for the full configuration reference.
