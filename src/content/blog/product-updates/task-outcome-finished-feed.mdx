Documentation tasks submitted via the Promptless API now return a machine-readable outcome. A new endpoint lists finished tasks ordered by when they completed. The Zapier **Documentation Task Finished** trigger uses that endpoint.

## The problem

The Promptless API lets you submit documentation tasks from your own tooling: a Zap, a CI step, a script that fires after a release. You send a request, get a task ID, and Promptless does the work.

What you didn't have was a way to know what happened. Did Promptless create a suggestion? Did it determine no change was needed? Did it get stuck and need more input? There was no structured answer, just a task ID you could look up by hand in the dashboard.

Automations built on top of documentation tasks had to stop at submission. There was no machine-readable way to close the loop.

## What it does now

Every completed task now reports an `outcome` field with one of four values:

- `suggestions_created` — Promptless found changes to make and opened a suggestion
- `no_change_needed` — Promptless reviewed the docs and found them accurate
- `needs_input` — Promptless needs more information before it can proceed
- `failed` — the task couldn't complete

`outcome` appears in three places:

- `GET /v1/triggers/{trigger_event_id}` — the existing per-task status endpoint
- MCP `get_task_status` — for tools using the MCP interface
- `GET /v1/triggers` — a new endpoint that lists finished tasks newest first

The Zapier **Documentation Task Finished** trigger polls the new endpoint. Configure it and you can build a Zap that fires whenever a documentation task resolves, branching on the outcome.

## Who benefits most

Teams running documentation tasks from automation: CI pipelines, Zapier workflows, scripts that call the Promptless API after a deployment or a release. If you've been submitting tasks and checking results by hand in the dashboard, this lets you handle them in the same system where they originated.

It's also useful for internal reporting. You can log every task outcome to a spreadsheet or post a summary to Slack without polling the dashboard manually.

## How to use it

No configuration is needed to start seeing `outcome` on completed tasks. It appears automatically on the per-task status endpoint for every task that finishes from this point on.

For the Zapier **Documentation Task Finished** trigger: open Zapier, find the Promptless app, and add **Documentation Task Finished** as a trigger. Set it up the same way as any other Promptless Zapier trigger.

See [API triggers](/docs/for-docs/connect/triggers/api#finished-tasks) for the full endpoint reference.
