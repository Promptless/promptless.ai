## Public work

These open-source projects and customer docs repositories accept Promptless pull requests in public. A maintainer reviews every pull request, and nothing merges without their approval.

| Project | Docs platform | Pull requests |
| --- | --- | --- |
| Vitess | Hugo | [Promptless PRs on vitessio/website](https://github.com/vitessio/website/pulls?q=is%3Apr+author%3Aapp%2Fpromptless) |
| Helm | Docusaurus | [Promptless PRs on helm/helm-www](https://github.com/helm/helm-www/pulls?q=is%3Apr+author%3Apromptless-for-oss) |
| Runpod docs | Mintlify | [Promptless PRs on runpod/docs](https://github.com/runpod/docs/pulls?q=is%3Apr+author%3Aapp%2Fpromptless) |
| Mautic user documentation | Sphinx | [Promptless PRs on mautic/user-documentation](https://github.com/mautic/user-documentation/pulls?q=is%3Apr+author%3Apromptless-for-oss) |
| Bazel docs | Mintlify | [Promptless PRs on bazel-contrib/bazel-docs](https://github.com/bazel-contrib/bazel-docs/pulls?q=is%3Apr+author%3Aapp%2Fpromptless) |
