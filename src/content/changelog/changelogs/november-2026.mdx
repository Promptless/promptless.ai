**New Features:**

- **Docs evals:** Write the questions readers ask about each doc collection, and have a model you pick answer them from your docs. A judge model grades each answer against the facts it should state. See which questions your docs leave unanswered, get a docs task for each failure, and track each question across models and runs. See [Test whether your docs answer readers' questions](/docs/for-docs/audit/docs-evals).

**Improvements:**

- **Screenshots on every suggestion:** Screenshot thumbnails now appear on each suggestion's row and at the top of the suggestion, replacing the Screenshot Updates tab. Catch a wrong or stale screenshot while you triage, and filter with `has:screenshots` to review every visual change in one pass. See [Review screenshot changes](/docs/for-docs/get-the-most-out/screenshots#review-screenshot-changes).
- **Voice messages in Slack:** Promptless transcribes voice messages and audio files in threads you trigger it from and uses what was said in the suggestion. Talk through a change when that's faster than writing it up. See [Include images and files](/docs/for-docs/connect/triggers/slack-messages#include-images-and-files).
