**New Features:**

- **Use your own model provider keys:** Run docs evals on the AI inference your company already has. Add an OpenRouter, Anthropic, or OpenAI key, or your own endpoint such as a model gateway. See [Add your own model provider keys](/docs/for-docs/audit/model-provider-keys).
- **Test whether your docs answer readers' questions:** Write the questions readers ask and check whether a model answering from your docs states the right facts. Find the questions your docs leave unanswered, get a docs task for each, and rerun to confirm the fix. See [Test whether your docs answer readers' questions](/docs/for-docs/audit/docs-evals).
- **Correct teammates' linked accounts:** Admins can fix which accounts Promptless ties to each teammate, and teammates can verify their own by signing in. The weekly digest @-mentions an assignee only through a verified Slack link, so verified teammates get pinged about the suggestions waiting on them. See [Link teammates' accounts on the People page](/docs/for-docs/work-the-queue/assignment-and-routing#link-teammates-accounts-on-the-people-page).
- **See which doc changes shipped:** The Published page lists recently merged suggestions, with who merged each one and its doc collection. Show leadership what reached readers without searching each docs repo's Git history. See [Measure the impact of Promptless](/docs/for-docs/measure/reporting-and-roi#find-the-signals-promptless-records).
- **Review a suggestion right after setup:** Promptless drafts it from a recent merge your docs don't cover yet, ready in the dashboard. See what Promptless does with your docs on day one, without waiting for the next merge. See [Review your first suggestion](/docs/for-docs/start-here/quickstart#review-your-first-suggestion).

**Improvements:**

- **Screenshots on every suggestion:** Screenshot thumbnails now appear on each suggestion's row and at the top of the suggestion, replacing the Screenshot Updates tab. Catch a wrong or stale screenshot while you triage, and filter with `has:screenshots` to review every visual change in one pass. See [Review screenshot changes](/docs/for-docs/get-the-most-out/screenshots#review-screenshot-changes).
- **Voice messages in Slack:** Promptless transcribes voice messages and audio files in threads you trigger it from and uses what was said in the suggestion. Talk through a change when that's faster than writing it up. See [Include images and files](/docs/for-docs/connect/triggers/slack-messages#include-images-and-files).
- **Slack follow-ups by instruction:** Add an instruction to `PROMPTLESS.md` to have Promptless reply in a suggestion's Slack thread when the suggestion resolves. The instruction can cover merged and closed docs PRs and closed or archived suggestions, or only the cases your team cares about. It replaces the **Suggestion Status Updates** organization setting. See [Post status updates in Slack threads](/docs/for-docs/tune/notifications#post-status-updates-in-slack-threads).
- **Check sources file by file:** Each changed file in a docs PR or MR gets a comment listing its sources and the claims they support. Review a file's evidence in one place, kept current as the suggestion changes. See [Check sources on the docs PR](/docs/for-docs/work-the-queue/reviewing-prs#check-sources-on-the-docs-pr).
- **Plans for larger doc changes:** When a suggestion adds or restructures pages, its description explains the approach Promptless chose and the options it rejected. Ask for the plan before Promptless writes, or require your approval for every plan. See [Read the plan behind a larger change](/docs/for-docs/work-the-queue/reviewing-prs#read-the-plan-behind-a-larger-change).
