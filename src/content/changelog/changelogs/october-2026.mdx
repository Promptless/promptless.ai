**New Features:**

- **Clone and push your Agent Knowledge Base with Git:** You can now clone your organization's Agent Knowledge Base from `https://api.gopromptless.ai/v1/knowledge-base.git` with a Promptless API key. Edit its files in your own editor, scripts, or CI, and push them back to `main`. Any active key can clone and fetch. Pushing needs an organization admin's key or a key created on **Settings > API Access**. Pushed commits show up in the dashboard, and the next Promptless session reads them. See [Clone and push the Knowledge Base with Git](/docs/for-docs/get-the-most-out/agent-knowledge-base#clone-and-push-the-knowledge-base-with-git).
- **Collect Cursor sessions as native traces:** Cursor joins Claude Code, Claude Desktop, and Codex as a native trace source for Promptless Instruction Governance. Analyzer releases 0.3.3 and later report Cursor support, and the default enrollment policy then includes Cursor. Rebuild your hub with trace collection enabled and refresh the Cursor `pig` plugin; an enrolled Cursor host uploads its desktop Agent sessions to your analyzer. Pilot on one host first. See [Enroll your hosts](/docs/governance/get-started/enroll-your-hosts#cursor-collection).

**Improvements:**

- **PIG 0.3.4 configures the collector Ingress in the bootstrap chart:** PIG 0.3.4 is now the stable release for AWS. You set the trace collector's hostname, ingress class, TLS Secret, and annotations in the `pig-supervisor` chart's `ingress` values. Helm or your GitOps workflow owns the Ingress. Existing installations complete a one-time handoff that keeps the same Ingress and load balancer. Azure and Google Cloud remain experimental. See [Upgrade an existing installation to 0.3.4](/docs/governance/deploy-the-worker/manage-updates-and-recovery#upgrade-an-existing-installation-to-034).
- **Worker chart 0.3.5 uses `pig` Helm values:** The manually managed worker chart reads its settings from the top-level `pig` key. The analyzer receives them as `PIG_*` environment variables. When you upgrade a manual installation from 0.3.4, rename `instructionHub` to `pig` in your values file. Secret references under `secrets` are unchanged. See [Upgrade a manual installation](/docs/governance/deploy-the-worker/manual-helm#upgrade-a-manual-installation). A supervisor-managed 0.3.4 installation needs a one-time supervisor bootstrap before it can update to 0.3.5 or later. See [Upgrade a 0.3.4 installation to 0.3.5 or later](/docs/governance/deploy-the-worker/manage-updates-and-recovery#upgrade-a-034-installation-to-035-or-later).
- **PIG 0.3.6 is the stable release for AWS:** PIG 0.3.6 uses database schema revision 5, which adds cloud agent enrollment. It supports PostgreSQL 15–18 on Kubernetes 1.30 or later. [Install with Helm](/docs/governance/deploy-the-worker/deploy-the-analyzer-worker) covers each step through a first verified session: release digests, collector Ingress values, and enabling analysis. Azure and Google Cloud remain experimental.
