**New Features:**

* **Keep your documentation in Heretto CCMS:** You can now point a doc collection at a Heretto CCMS folder. Promptless suggests updates to the folder's DITA and XML files, and you review them in the Promptless dashboard. When you select **Publish to Heretto**, Promptless writes the changed files back to Heretto. It checks every file first, and publishes nothing if a file changed in Heretto after the suggestion was written, is locked, or would be deleted. Contact Promptless to connect your Heretto tenant, then add the collection with `platform: heretto` in YAML mode. See [Heretto CCMS](/docs/for-docs/connect/doc-locations/heretto-ccms).
