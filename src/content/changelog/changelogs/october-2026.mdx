**Improvements:**

* **Place the Open in Promptless link in your PR description:** Add `[Open in Promptless]({suggestion_url})` to your repository's PR or merge request template. You can also ask for the link in your Agent Knowledge Base guidance. Promptless replaces `{suggestion_url}` with the suggestion's dashboard URL, so the link lands where you put it, such as below your PR checklist. This works with `publishing.suppress_pr_description_extras` on, so you can keep a link to the suggestion while omitting the other generated extras. See [Place the suggestion link yourself](/docs/for-docs/connect/doc-locations/github-repos#place-the-suggestion-link-yourself).
