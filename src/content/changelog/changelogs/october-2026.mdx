**Improvements:**

* **Attach files to a task reply:** You can now attach files to a reply on a New Task conversation page. Select the paperclip or paste an image, the same way you do when you submit a New Task. A reply to a running task delivers its files to that task, and a follow-up task receives every file attached earlier in the conversation. Each message lists the files sent with it, and task messages read over the API or MCP include an `attachments` list. See [Task conversations](/docs/for-docs/work-the-queue/web-interface#task-conversations).
