**Improvements:**

* **Faster suggestion page:** The suggestion page loads faster.

* **Undo individual changes:** On the **Review Suggestion** tab, each separate change has its own **Undo**. Use it to restore the original text of one change and keep the rest of the suggestion. See [Undo a suggested change](/docs/for-docs/work-the-queue/web-interface#undo-a-suggested-change).

* **Comments and citations in place:** Comments and citations sit in the diff under the lines they refer to, as in a GitHub pull request review. Collapse them to one line when you're done reading. To read the diff without citations, select **Hide citations** in the actions bar. To start a comment, hover over a line number and select **+**, or select text in the diff and select **Comment**. See [Comments and citations in the diff](/docs/for-docs/work-the-queue/web-interface#comments-and-citations-in-the-diff).

* **Docs PR link in the suggestion header:** While a suggestion's docs PR is open, the header's **Docs PR** row links to it. The link shows which repository the suggestion targets. See [Suggestion overview](/docs/for-docs/work-the-queue/web-interface#suggestion-overview).

* **Shorter suggestion descriptions:** A long description shows its first 10 lines. Select **show more** to read the rest.

* **Refreshed review layout:** Each file header has separate **Preview**, **Edit**, **Reject**, and **Viewed** controls. A progress ring in the actions bar tracks how many files you've marked **Viewed**. See [Review the changed files](/docs/for-docs/work-the-queue/web-interface#review-the-changed-files).
