**Improvements:**

* **Faster suggestion page:** The suggestion page loads faster.

* **Docs PR link in the suggestion header:** While a suggestion's docs PR is open, the header's **Docs PR** row links to it. The link shows which repository the suggestion targets. See [Suggestion overview](/docs/for-docs/work-the-queue/web-interface#suggestion-overview).

* **Shorter suggestion descriptions:** A long description shows its first 10 lines. Select **show more** to read the rest.

* **Review progress and save all:** A progress ring in the actions bar tracks how many files you've marked **Viewed**. Press ⌘S (Ctrl+S on Windows and Linux) to save every edited and rejected file in one step. See [Review the changed files](/docs/for-docs/work-the-queue/web-interface#review-the-changed-files).
