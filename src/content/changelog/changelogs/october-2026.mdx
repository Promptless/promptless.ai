**New Features:**

* **See what shipped PIG fixes recovered:** The Instruction Hub now has an **Impact** page that lists every fix whose pull request has merged, newest first. Each row shows the pull request, Instruction Hub, and merge time. Thirty days after the merge, each fix shows the agent time and tokens it recovered per analyzed session, compared with the 30 days before. The page for proposed fixes is now labeled **Fixes** and sits first in the Instruction Hub sidebar. See [Measure what a fix recovered](/docs/governance/findings-and-remediation/remediate-findings#measure-what-a-fix-recovered).
