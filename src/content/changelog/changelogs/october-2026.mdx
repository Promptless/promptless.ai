**Improvements:**

* **Reply to Promptless without tagging it:** Promptless now acts on replies in a GitHub review thread or GitLab merge request discussion it has commented in. This works in both comment trigger modes. The thread can be on any open pull request or merge request, including source PRs and MRs. Start a reply with `aside` or `/aside` to keep Promptless from acting on it. Comment trigger modes also cover an existing docs PR or MR that Promptless pushes changes to at your request. See [Replies in threads Promptless joined](/docs/for-docs/work-the-queue/reviewing-prs#replies-in-threads-promptless-joined).
