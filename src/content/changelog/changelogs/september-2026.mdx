**Bug Fixes:**

* **Draft-until-merge for auto-created documentation PRs is now consistent across GitHub, GitHub Enterprise, and GitLab:** A documentation pull request or merge request linked to an open source PR opens as a draft and is promoted to ready for review when the source PR merges. This draft-until-merge behavior was already described in earlier changelogs; it now works the same way across all three providers. See [Documentation PRs open as drafts until the source PR merges](/docs/for-docs/tune/release-timing#documentation-prs-open-as-drafts-until-the-source-pr-merges).
