**Improvements:**

* **More backfill windows for pull request triggers:** Backfill suggestions now offers 7-, 14-, and 30-day lookback windows on GitHub PR, GitLab merge request, and Bitbucket PR triggers, so you can preview and run a backfill over a recent stretch of pull requests. See [Backfill suggestions](/docs/for-docs/connect/triggers#backfill-suggestions).
