**Improvements:**

* **Resume a pending Slack admin-approval install:** When your Slack workspace requires an admin to approve the Promptless app, Promptless keeps your pending request so you can leave and come back—the pending state persists across page reloads and sessions. This resumable handoff is now available from both onboarding and the Integrations settings page. Connecting opens Slack in a secondary window while the dashboard keeps a pending card. Once an admin approves, you return and select **Continue installing Slack App** to finish the connection. If you close the window before finishing, your request stays pending so you can resume it. See [Slack integration](/docs/for-docs/reference/integrations/slack#when-admin-approval-is-required).
