**Improvements:**

* **Provider-backed triggers check their integration before they save:** You can now count on every provider-backed trigger having its integration connected before it takes effect. When you add, rename, or modify a GitHub, GitLab, Bitbucket, Slack, Microsoft Teams, ClickUp, or Jira trigger, Promptless confirms the matching integration is connected first—in Form mode, in YAML mode, and on direct Agent Knowledge Base edits alike. Schedule triggers need no integration. See [Connect a provider before you add its triggers](/docs/for-docs/connect/triggers#connect-a-provider-before-you-add-its-triggers).

* **Pick up an incomplete Slack connection:** You can now see when a Slack install was started but not finished—commonly while you wait for an admin to approve the app—and either **Complete connection** to finish the install once it's approved, or **Start over** to cancel the attempt. The incomplete state shows on the Integrations page and during onboarding. See [Slack connection states](/docs/for-docs/reference/integrations/slack#slack-connection-states).
