{/* Add a Slack or Microsoft Teams passive listening trigger, from the
    Configuration page or as YAML. Embedded in the passive channel listening,
    Slack messages, and Review from Slack and Teams pages. The host page
    supplies the heading. */}

import { Steps } from '@astrojs/starlight/components';

<Steps>
  1. Optional. For a private or Slack Connect channel, add Promptless to the channel in Slack. See [Add Promptless to a channel](/docs/for-docs/reference/integrations/slack#add-promptless-to-a-channel). Promptless joins a public channel on its own when you add the channel to a trigger.

  2. On the [Configuration page](https://app.gopromptless.ai/configuration), open the **Triggers** tab.

  3. Select **Add an automatic or scheduled trigger**, then select **A Slack channel** or **A Microsoft Teams channel**.

  4. Under **Which channels should Promptless watch?** or **Which Teams channels should Promptless watch?**, choose the channels to monitor:

     - For Slack, choose channels from the list, or enter channel names without the `#` prefix.

     - For Teams, choose channels from the list, or paste a channel's conversation ID, which looks like `19:...@thread.tacv2`.

  5. Select **Add trigger**.
</Steps>

Promptless tracks Slack channel renames, so renaming a monitored channel doesn't break the trigger. To stop monitoring a channel, edit or remove its trigger on the **Triggers** tab.

The Configuration page stores each trigger in `promptless.yaml`. To manage triggers as configuration, edit the YAML directly. This example has one `slack_listen` trigger and one `msteams_listen` trigger:

```yaml
triggers:
  support-channels:
    trigger_type: slack_listen
    match:
      - channels:
          - slack-connect-acme
          - docs-feedback
  teams-support:
    trigger_type: msteams_listen
    match:
      - channel_ids:
          - 19:abc123@thread.tacv2
```

For every match field, see the [Configuration Reference](/docs/for-docs/reference/configuration-reference#triggers).
