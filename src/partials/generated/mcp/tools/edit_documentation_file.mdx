Replace exact text in one file on an open suggestion's branch, as one commit attributed to you. Each edit's `old_text` must occur exactly once in the file, so include enough surrounding lines to make it unique; the call is refused, with the match count, when it does not. Edits apply in order. Read the file first so `old_text` matches it verbatim.

- **Annotation:** Changes existing content
