Send additional customer instructions to an existing task submitted through the API, MCP, or the dashboard's New Task page, without creating another task. Other sources return unsupported_task_source. Only received or processing tasks accept messages. Finished tasks, including blockers and clarification requests, return task_finished and are not reopened. Reuse an `idempotency_key` when retrying the same message during active work.
