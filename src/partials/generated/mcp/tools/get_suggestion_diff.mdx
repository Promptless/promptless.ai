Show what a suggestion changes: one unified diff per file against the collection's base branch, plus the head commit to pass as `expected_head_sha` when editing. Use it to review a suggestion before labelling, editing, or opening its pull request. Diff text is capped in total; when truncated is true, later files carry no diff text.
