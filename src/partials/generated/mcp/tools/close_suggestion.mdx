Close a suggestion and its documentation pull request, ending the review without shipping it. Use it to reject a proposal while triaging `search_suggestions` results. The pull request is closed on GitHub or GitLab first, so a suggestion whose host refuses the close stays open and the call reports why. Closing cannot be undone from here, and a suggestion that already merged is refused rather than closed. Use `request_changes` instead when the proposal is worth keeping but needs rework.
