Ask Promptless to update your documentation. Promptless researches the affected docs and proposes changes when needed. Returns a `trigger_event_id` right away, but the work itself takes several minutes. The response includes the `next_call` for following the submitted work with `wait_for_task_update`.

- **Annotation:** Changes data
- **Server paths:** `/mcp`, `/mcp/with-direct-edits`

| Argument                    | Type            | Required | Description                                                                                                                                                                                                                                                       |
| --------------------------- | --------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `instructions`              | string          | Yes      | What changed and what the documentation should say about it. Include the detail a technical writer would need: behavior before and after, affected surfaces, and any naming or terminology to use.                                                                |
| `context`                   | object          | No       | Supporting material for the task, such as diffs, PR links, ticket ids, or file paths.                                                                                                                                                                             |
| `attachments`               | array of object | No       | Links to material that explains the change, such as a screenshot, design file, or spec. Nothing is uploaded — tool arguments are JSON only — so each entry is a URL Promptless may open while researching, and one it cannot reach or authenticate to is skipped. |
| `attachments[].url`         | string          | Yes      | Where the material lives.                                                                                                                                                                                                                                         |
| `attachments[].description` | string          | No       | What the link shows, in a sentence.                                                                                                                                                                                                                               |
| `doc_collection_id`         | string          | No       | Id of the doc collection to target, from `list_doc_collections`.
