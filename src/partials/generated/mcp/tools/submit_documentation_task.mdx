Start a Promptless task that updates documentation, sets up a doc collection, or changes Promptless configuration. A Promptless agent does the work, which takes several minutes and can open a pull request in the docs repository. Returns a `trigger_event_id` at once, with `next_call` to follow the task and `conversation_url` where the person can watch and reply. For setup, omit `doc_collection_id`.

- **Annotation:** Destructive
- **Server paths:** `/mcp`, `/mcp/with-direct-edits`
