Search this organization's documentation suggestions by keyword, review status, and label. Use it to check whether a suggestion for a change already exists before submitting a new task, to find a suggestion id to request changes on, to pull a labelled queue such as the P0 suggestions, or to review past suggestions. Results are capped; when truncated is true, narrow the query.

- **Annotation:** Read-only
- **Server paths:** `/mcp`, `/mcp/with-direct-edits`

| Argument | Type            | Required | Description                                                                                                                 |

| `query`  | string          | No       | Free text to match against a suggestion's title and description.                                                            |
