List this organization's recent documentation tasks, newest first, each with the `trigger_event_id` needed to check it. Use it when a task id was not kept, or to see what Promptless has been working on.

- **Annotation:** Read-only
- **Server paths:** `/mcp`, `/mcp/with-direct-edits`

**Arguments**

| Argument | Type    | Required | Description                                                                                             |
| -------- | ------- | -------- | ------------------------------------------------------------------------------------------------------- |
| `limit`  | integer | No       | How many tasks to return. Defaults to 20; anything above 100 is capped at it. Minimum: 1. Maximum: 100. |
| `status` | string  | No       | Restrict results to tasks in this lifecycle state. One of `received`, `processing`, or `completed`.     |

| `tasks[].status`           | string          | One of `received`, `processing`, `completed`, or `skipped`.                                                           |
