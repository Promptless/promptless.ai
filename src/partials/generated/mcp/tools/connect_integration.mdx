Call this when an app is missing or disconnected. It returns a deeplink that starts the connection flow for that app and returns the person to Promptless. The flow assumes the person can grant Promptless access to that app. If they cannot, some apps let them request approval from an admin, and others need an API key from an admin. After they finish, call `get_account_status` to confirm.

- **Annotation:** Changes data
- **Server paths:** `/mcp`, `/mcp/with-direct-edits`
- **Unclaimed organizations:** Available before a person claims an organization an agent created.
