Return a link that a person opens in a browser to connect or reconnect one app, such as GitHub or Slack, to this organization. The call itself connects nothing. Use it when an app is missing or disconnected. The person must be able to grant Promptless access to that app. If they cannot, some apps let them request approval from an admin, and others need an API key from an admin. The link works for 24 hours. Afterwards, call `get_account_status` to confirm.

- **Annotation:** Read-only
- **Server paths:** `/mcp`, `/mcp/with-direct-edits`
- **Unclaimed organizations:** Available before a person claims an organization an agent created.
