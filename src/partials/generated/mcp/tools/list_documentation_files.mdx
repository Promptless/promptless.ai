List the files in a doc collection's repository, inside the paths Promptless maintains, at the collection's default branch or at a suggestion's branch. Use it to find a page's path before reading or editing it. Results are sorted and capped; when truncated is true, narrow with `path_prefix`.

- **Annotation:** Read-only
- **Server paths:** `/mcp/with-direct-edits`

**Arguments**

| Argument            | Type    | Required | Description                                                                                                                                            |
| ------------------- | ------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `doc_collection_id` | string  | No       | Which doc collection to read, from `list_doc_collections`. Optional when the organization has exactly one collection or when `suggestion_id` is given. |
| `suggestion_id`     | string  | No       | Read the suggestion's branch instead of the collection's default branch, to see content as the suggestion proposes it.                                 |
| `path_prefix`       | string  | No       | Only list files whose path starts with this prefix, such as docs/api/.                                                                                 |
| `limit`             | integer | No       | How many paths to return. Defaults to 500. Minimum: 1. Maximum: 2,000.                                                                                 |
