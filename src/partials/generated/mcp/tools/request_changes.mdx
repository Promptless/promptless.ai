Ask Promptless to change a suggestion it already produced, the same as the Request Changes button in the Promptless dashboard. Any changes apply to that suggestion and its existing pull request if one is open. To make the edit yourself instead, edit that pull request directly — its URL is the suggestion's `docs_pr_url`. Takes a suggestion id from `search_suggestions` or `get_task_status` and returns a `trigger_event_id` for the new task. Use `submit_documentation_task` when no suggestion exists yet, and when the suggestion is closed or merged and can no longer be changed. The response includes `next_call` for following the submitted work with `wait_for_task_update`.

- **Annotation:** Changes data
- **Server paths:** `/mcp`, `/mcp/with-direct-edits`
