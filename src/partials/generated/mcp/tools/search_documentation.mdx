Find lines matching a substring or an RE2 regular expression (syntax similar to grep -E) across a doc collection's text files (Markdown, MDX, reStructuredText, YAML, JSON, HTML, and similar), at the default branch or at a suggestion's branch. Each match carries the file path, line number, and line text. Use it to find every page that mentions a feature, flag, or endpoint before changing it. The scan reads at most 400 files within a time budget; `files_skipped` reports how many were left unread, and truncated reports that more lines matched than were returned.

- **Annotation:** Read-only
- **Server paths:** `/mcp/with-direct-edits`

| Argument            | Type    | Required | Description                                                                                                                                            |
| ------------------- | ------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `doc_collection_id` | string  | No       | Which doc collection to read, from `list_doc_collections`. Optional when the organization has exactly one collection or when `suggestion_id` is given. |
| `suggestion_id`     | string  | No       | Read the suggestion's branch instead of the collection's default branch, to see content as the suggestion proposes it.                                 |
| `query`             | string  | Yes      | Text to find, or a regular expression when regex is true.                                                                                              |
| `regex`             | boolean | No       | Treat query as an RE2 regular expression, similar to grep -E. Defaults to false.                                                                       |

| `path_prefix`       | string  | No       | Only search files whose path starts with this prefix.                                                                                                  |
| `limit`             | integer | No       | How many matching lines to return. Defaults to 50. Minimum: 1. Maximum: 200.                                                                           |
