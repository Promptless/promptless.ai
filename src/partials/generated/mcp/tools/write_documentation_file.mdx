Create or replace one file on an open suggestion's branch with the full content given, as one commit attributed to you. Use it for a new page or a rewrite; use `edit_documentation_file` for changes to part of a page. The path must lie inside the collection's maintained paths. Open the pull request with `update_suggestion` afterwards.

- **Annotation:** Changes existing content
- **Server paths:** `/mcp/with-direct-edits`

| Argument            | Type   | Required | Description                                                                                                                                               |
