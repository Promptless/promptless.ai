Change a suggestion's own fields and open its documentation pull request. Set the title, labels, or assignees, and pass `open_pull_request` to publish the branch as a pull request you can review and edit directly. Every argument is optional except `suggestion_id`; an omitted field is left alone. Supplying labels or assignees replaces the whole list, so read the current values from `search_suggestions` or `get_task_status` first. A new title is also pushed to the suggestion's pull request while that pull request is open, so the two never disagree; if the host rejects the push, the stored title is left unchanged. Opening is idempotent: a suggestion already carrying a pull request returns it rather than opening a second, and draft state follows the organization's source-pull-request policy. Use `request_changes` to ask Promptless to rewrite the documentation itself.

- **Annotation:** Changes existing content
- **Server paths:** `/mcp`, `/mcp/with-direct-edits`

| `suggestion_id`     | string          | Yes      | Id of the suggestion to update, from `search_suggestions` or `get_task_status`.                                                                |
