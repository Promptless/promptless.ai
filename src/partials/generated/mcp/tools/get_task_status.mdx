Check the state of any documentation task in this organization and read the suggestions it produced. It covers tasks you submitted here and tasks that started in Slack, GitHub, or the Promptless dashboard. A finished task can legitimately produce nothing, so read resolution and the suggestions list rather than assuming a pull request exists. This call returns one status snapshot; finished indicates completion, and suggestions can appear while work continues. Each response includes the latest 100 conversation messages, oldest first. Track message IDs to relay new Dispatch messages once, including messages in the final response.
