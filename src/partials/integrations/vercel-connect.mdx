{/* Connect Vercel to Promptless through OAuth for read-only Starport deploy
    monitoring. Embedded in the Vercel integration and Starport connections
    pages; the host page supplies the heading. */}

import { Aside, Steps } from '@astrojs/starlight/components';

An organization admin connects Vercel once, through OAuth, for the whole organization.

<Steps>
  1. On the Promptless [Integrations](https://app.gopromptless.ai/integrations) page, select **Connect Vercel**.

  2. On Vercel, approve read-only access for Promptless.

  3. On the Integrations page, confirm that Vercel shows as connected.
</Steps>

<Aside type="note" title="Monitoring is separate from your Starport deploy">
  Your Starport site deploys to Vercel from CI, using the credentials in [Starport configuration](/docs/for-docs/starport/configuring-starport#configure-deploy-settings). This connection only reads the result.
</Aside>
