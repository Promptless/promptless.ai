{/* Connect a Heretto CCMS tenant to Promptless. Embedded in the Heretto and
    Contentful doc locations page. The host page supplies the heading. */}

import { Steps } from '@astrojs/starlight/components';

Promptless signs in to Heretto as one Heretto user, with that user's API token. Use a user who can open the folders Promptless documents and edit the content in them. Heretto credits every change Promptless proposes to this user, so a dedicated user, such as `promptless@acme.com`, makes those changes easy to recognize.

<Steps>
  1. In Heretto, sign in as the user Promptless connects as.

  2. Open `https://<your-heretto-host>/tools/token-management/tokens.xql`, for example `https://acme.heretto.com/tools/token-management/tokens.xql`, create an API token, and copy it.

  3. In the Promptless dashboard, open the [Integrations](https://app.gopromptless.ai/integrations) page and select **Connect Heretto**.

  4. In **Heretto host**, enter your tenant's hostname, for example `acme.heretto.com`. Enter only the host, with no `https://` and no path.

  5. Enter the Heretto **Username** and paste the **API token**.

  6. Select **Connect**. Promptless checks the credentials against Heretto's REST API before it saves them. The Heretto card then shows the host and user.
</Steps>

Your Promptless organization has one Heretto connection. Connecting again replaces it. To check the stored credentials later, select **Check access** on the Heretto card.
