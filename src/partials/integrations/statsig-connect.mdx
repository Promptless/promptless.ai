{/* Connect Statsig to Promptless with a read-only Console API key. Embedded in
    the Statsig integration page; the host page supplies the heading. */}

import { Steps } from '@astrojs/starlight/components';

You need an admin role in your Promptless organization, and a Statsig account that can create Console API keys for the project.

<Steps>
  1. In Statsig, open the project's [API keys settings](https://console.statsig.com/api_keys) and create a Console API key with read-only access.

  2. Copy the key.

  3. On the Promptless [Integrations](https://app.gopromptless.ai/integrations) page, select **Connect Statsig**.

  4. Paste the key into the modal, and select **Connect**.
</Steps>

Promptless reads the key's project before it saves the connection. Statsig then shows as connected on the Integrations page.
