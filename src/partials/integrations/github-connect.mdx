{/* Connect a GitHub organization to Promptless through the Promptless GitHub App.
    Embedded in the GitHub integration, GitHub PRs, GitHub commits, GitHub issues,
    and GitHub repos pages; the host page supplies the heading. */}

import { Aside, Steps } from '@astrojs/starlight/components';

You need an admin role in your Promptless organization to start a GitHub connection. GitHub then asks you to authorize the Promptless GitHub App with your GitHub account. The connection completes only if that account administers the organization or account you connect. For a GitHub organization, that's an organization owner. For a personal account, it's the account owner.

On GitHub Enterprise Server, or on GitHub Enterprise Cloud when a policy blocks third-party apps, connect through a custom GitHub App. See [GitHub Enterprise integration](/docs/for-docs/reference/integrations/github-enterprise).

<Steps>
  1. In the Promptless dashboard, open the [Integrations](https://app.gopromptless.ai/integrations) page.

  2. Select **Connect GitHub**.

  3. In GitHub, select the organization to install Promptless into.

     <img src="/assets/github-select-org.png" alt="GitHub Organization Selection" />

  4. Select the repositories Promptless can access. These are typically your source code repositories and, if your docs live in GitHub, your documentation repository.

     <img src="/assets/github-select-repos.png" alt="Repository Selection" />

  5. On the Integrations page, confirm that the organization appears on its own card.
</Steps>

The connection link stays valid for one hour. If it expires before you finish, start the connection again from the Integrations page.

Some GitHub organizations require an owner's approval to install a third-party app. If yours does and you aren't an owner, GitHub asks you to request approval. To connect in that case:

<Steps>
  1. Complete GitHub's approval request flow. Promptless tracks the request.

  2. Ask a GitHub organization owner to approve the Promptless GitHub App in the organization's **Third-party Access** settings.

  3. After the owner approves, start a new connection from the Integrations page. Approval installs the app in GitHub, but it doesn't connect the app to Promptless.

  4. Share the new connection link with a GitHub organization owner. The owner authorizes the app to complete the connection within the hour.
</Steps>

If GitHub can't reuse the approved installation, uninstall the Promptless GitHub App in GitHub, and connect again.

<Aside type="tip">
  To find who can approve, open **Third-party Access** > **Pending requests** in your GitHub organization settings. It shows who has owner permissions.
</Aside>

If your GitHub organization enforces an IP allow list, GitHub blocks requests from Promptless until an owner allows them. See [Organization IP allow lists](/docs/for-docs/reference/integrations/github#organization-ip-allow-lists).
