{/* Connect a Fluid Topics portal to Promptless with an analytics API key.
    Embedded in the Fluid Topics doc-gaps page; the host page supplies the
    heading. */}

import { Steps } from '@astrojs/starlight/components';

A Promptless organization admin connects one Fluid Topics portal for the whole organization. The connection uses a Fluid Topics API key with the `ANALYTICS_USER` or `ADMIN` role, because Fluid Topics accepts either for analytics web services. Give the key `ANALYTICS_USER`, which reads portal analytics and nothing else. `ADMIN` also works, but it gives the key far more access than Promptless needs.

<Steps>
  1. In Fluid Topics, under **Administration** > **Integration** > **API keys**, create an API key and give it the `ANALYTICS_USER` role. Only a Fluid Topics user with the `ADMIN` role can create API keys.

  2. On the Promptless [Integrations page](https://app.gopromptless.ai/integrations), select **Connect Fluid Topics**.

  3. In **Portal URL**, enter the HTTPS address of your portal, such as `https://docs.example.com`.

  4. In **API key**, paste the key.

  5. Select **Connect**. Promptless reads one day of analytics with the key before it saves the connection. The Fluid Topics card then shows your portal and the first characters of the key.
</Steps>

To confirm later that the key still works, select **Check access** on the Fluid Topics card. To use a different key, select **Disconnect Fluid Topics** on the card, then connect again with the new key.
