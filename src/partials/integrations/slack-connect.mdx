{/* Install the Promptless Slack app in a Slack workspace, including the
    admin-approval path. Embedded in the Slack integration and Slack messages
    pages; the host page supplies the heading. */}

import { Steps } from '@astrojs/starlight/components';

<Steps>
  1. On the [Integrations page](https://app.gopromptless.ai/integrations), select **Connect Slack**. Slack opens in a new window. If your browser blocks the window, allow pop-ups for Promptless and select **Connect Slack** again.

  2. In the Slack window, select the workspace where you want to install Promptless.

  3. Review and approve the permissions the Promptless Slack app requests. Promptless needs them to respond to the right events in Slack and to notify your team when updates are available. For what each permission does, see [Key permissions](/docs/for-docs/reference/integrations/slack#key-permissions).

  4. On the Integrations page, verify that Slack shows as connected.
</Steps>

Some Slack workspaces require an admin to approve apps before anyone can install them. If you aren't a workspace admin, Slack sends your request to an admin, and setup waits for their approval. The steps are the same from onboarding and from the Integrations page, and your pending request persists across page reloads and sessions.

<Steps>
  1. In the Slack window, follow Slack's prompts to send the request. Slack may notify you when an admin approves Promptless.

  2. Wait for the admin's decision. Until you finish the install, a pending card in onboarding or on the Integrations page shows that Promptless isn't installed in Slack yet. Promptless can't see the admin's decision, so the card stays pending.

  3. After an admin approves, select **Continue in Slack** on the pending card. Slack runs authorization again and connects Promptless.
</Steps>

If you close the window or lose your network connection before you finish, the request stays pending. Select **Continue in Slack** to try again. If Slack reports that the attempt was denied or failed, Promptless clears the request, and you start a new one.
