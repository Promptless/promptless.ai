{/* Connect the read-only Promptless GitHub App. Embedded in the GitHub (read-only)
    integration and GitHub repos pages; the host page supplies the heading. */}

import { Steps } from '@astrojs/starlight/components';

You need an admin role in your Promptless organization to connect an integration.

<Steps>
  1. In the Promptless dashboard, open the [Integrations](https://app.gopromptless.ai/integrations) page.

  2. Select **Connect GitHub (read-only)**.

  3. In GitHub, grant the app access to the repositories you want Promptless to work with. For open-source publishing, include the public repository whose docs you want to keep current.
</Steps>

The integration appears on the Integrations page as its own **GitHub (read-only)** card. To change which repositories Promptless can access, select **Configure in GitHub** on that card. It opens the app's installation page in GitHub.
