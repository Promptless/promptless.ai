    supplies the heading. */}

A Promptless organization admin connects one GitBook site for the whole organization. The connection uses a GitBook API token, which has the same access as the GitBook user who creates it. Create the token with a user who can open the site and its insights. Promptless only reads analytics with it.

<Steps>
  1. In GitBook, open your account settings and, under **Developer tools**, select **Create new API token**.

  2. In GitBook, open the site and copy its organization ID and site ID from the URL. The organization ID follows `/o/`, and the site ID follows `/sites/` and starts with `site_`.

  3. On the Promptless [Integrations page](https://app.gopromptless.ai/integrations), select **Connect GitBook Analytics**.

  4. In **API token**, paste the token.

  5. In **Organization ID** and **Site ID**, enter the IDs you copied.

  6. Select **Connect**. Promptless reads the site and its insights with the token before it saves the connection. The GitBook Analytics card then shows your site and the first characters of the token.
</Steps>

To confirm later that the token still works, select **Check access** on the GitBook Analytics card. To use a different token or site, select **Disconnect GitBook Analytics** on the card, then connect again.
