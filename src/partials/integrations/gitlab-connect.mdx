{/* Connect a GitLab group to Promptless. Embedded in the GitLab integration,
    GitLab merge requests, and GitLab projects pages; the host page supplies the
    heading. */}

import { Steps } from '@astrojs/starlight/components';

You need the **Owner** role on the GitLab group to create its access token, and an admin role in your Promptless organization to connect it. If you aren't a group Owner, ask one to create the token.

<Steps>
  1. In GitLab, go to your group's **Settings > Access Tokens** and select **Add new token**.

  2. Name the token, for example "Promptless", and set an expiration date. The maximum is one year.

  3. Select the **`api`** scope and the **Maintainer** role.

  4. Select **Create group access token**, and copy the token. GitLab shows it only once. The token starts with `glpat-`. For more details, see [GitLab's group access token documentation](https://docs.gitlab.com/user/group/settings/group_access_tokens/).

  5. In the Promptless dashboard, open the [Integrations](https://app.gopromptless.ai/integrations) page.

  6. Start the connection. For a gitlab.com group, select **Connect GitLab** on the **GitLab** tile. For a self-hosted instance, select **Connect Self-hosted GitLab** on the **Self-hosted GitLab** tile, and enter your **Instance hostname**. Enter only the host, with no `https://` and no path.

  7. In the **Group path** field, enter the group's full path, for example `acme/platform`.

  8. Paste the token into the **Access token** field, and select **Connect**.

     <img src="https://promptless-customer-doc-assets.s3.us-east-2.amazonaws.com/docs-images/org_3DaVKUzHgjyjaODgCPaDmjXezqp/gitlab-connect-modal-aeb67dd0.png" alt="Connect GitLab modal with Group path and Access token fields and a Connect button" />
</Steps>

The token must be a group access token with the **`api`** scope and the **Maintainer** role. Promptless uses it to create the merge-request webhooks, and a read-only `read_api` token or a Developer-role token can't create them. For why, see [Token scope considerations](/docs/for-docs/reference/integrations/gitlab#token-scope-considerations).

The group gets its own card on the [Integrations](https://app.gopromptless.ai/integrations) page. To connect another group, select **Connect GitLab** or **Connect Self-hosted GitLab** again and repeat these steps with that group's token.
