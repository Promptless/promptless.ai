Promptless reads and writes a Contentful space through the Promptless app installed in it. You don't give Promptless a Contentful token. You need to be an admin of the space to install the app.

<Steps>
  1. In the Promptless dashboard, open the [Integrations](https://app.gopromptless.ai/integrations) page and select **Connect Contentful**.

  2. In the **Connect a Contentful space** dialog, select **Install in Contentful**. Contentful opens the Promptless app.

  3. In Contentful, choose the space and environment that hold your documentation.

  4. Back in the Promptless dialog, select **Copy** to copy the connect code. The code expires after 15 minutes. If it expires, select **Generate a new code**.

  5. On the Promptless app's configuration screen in Contentful, paste the code into **Connect code** and select **Install**. If the app is already installed in the space, select **Save** instead.
</Steps>

When the space connects, the Promptless dialog shows its space ID. The configuration screen in Contentful shows **Connected to** and your Promptless organization's name. Each connected space gets its own card on the Integrations page, with its **Space**, its **Environment**, and an **Open in Contentful** link. To connect another space, select **Connect Contentful** again and use a new connect code.
