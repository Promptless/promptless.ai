{/* Connect a Mintlify project's analytics to Promptless with an admin API key.
    Embedded in the GitBook and Mintlify doc-gaps page. The host page supplies
    the heading. */}

import { Steps } from '@astrojs/starlight/components';

A Promptless organization admin connects one Mintlify project for the whole organization. The connection uses a Mintlify admin API key with read access. Assistant API keys can't read analytics. Mintlify fixes a key's access, IP allowlist, and expiry when you create it, so choose them as the first step describes.

<Steps>
  1. In the Mintlify dashboard, on the API keys page of your organization settings, create an admin API key with read access and no IP allowlist. Choose no expiration, or plan to connect a new key before this one expires. Admin API keys start with `mint_`.

  2. On the same page, copy your project ID.

  3. On the Promptless [Integrations page](https://app.gopromptless.ai/integrations), select **Connect Mintlify Analytics**.

  4. In **Admin API key**, paste the key.

  5. In **Project ID**, enter the project ID.

  6. Select **Connect**. Promptless reads analytics with the key before it saves the connection. The Mintlify Analytics card then shows your project and the first characters of the key.
</Steps>

Each analysis spends some of the 100 analytics requests an hour that Mintlify allows your Mintlify organization, and your own tools share that budget. To confirm later that the key still works, select **Check access** on the Mintlify Analytics card. To use a different key, select **Disconnect Mintlify Analytics** on the card, then connect again with the new key.
